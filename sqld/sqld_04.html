이 단원 출제 비중

DDL/DML/TCL은 문법 구분 문제가 자주 출제됩니다

DDL/DML/TCL, SQL 명령의 뼈대를 구분하는 단원

시험에서는 명령어 분류, 실행 결과, COMMIT/ROLLBACK 동작을 섞어 출제합니다. 이 단원에서 헷갈리는 포인트를 표와 문제로 확실히 잡아봅시다.

🎯 학습목표

  1. DDL, DML, TCL의 역할 차이를 구분한다
  2. CREATE/ALTER/DROP과 INSERT/UPDATE/DELETE/SELECT를 정확히 분류한다
  3. COMMIT/ROLLBACK/SAVEPOINT의 동작을 설명한다
  4. 예상문제 15문항을 통해 미니 강의형 해설로 실수를 줄인다
1. DDL (Data Definition Language)

DDL은 데이터베이스 객체(테이블, 인덱스, 뷰 등)의 구조를 정의/변경/삭제하는 명령어입니다.

명령의미예시
CREATE객체 생성CREATE TABLE student (...)
ALTER객체 구조 변경ALTER TABLE student ADD email VARCHAR2(50)
DROP객체 삭제DROP TABLE student
TRUNCATE테이블 데이터 전체 삭제(구조 유지)TRUNCATE TABLE student
주의: DDL은 보통 자동 커밋(Auto Commit) 특성이 있어 ROLLBACK이 되지 않는 경우가 많습니다.
2. DML (Data Manipulation Language)

DML은 테이블 안의 데이터(행)를 조회/삽입/수정/삭제하는 명령어입니다.

명령의미예시
SELECT데이터 조회SELECT * FROM student
INSERT데이터 삽입INSERT INTO student VALUES (...)
UPDATE데이터 수정UPDATE student SET grade='A'
DELETE데이터 삭제DELETE FROM student WHERE id=1
핵심: DML 결과는 COMMIT 전까지 취소(ROLLBACK) 가능하다는 점이 자주 출제됩니다.
3. TCL (Transaction Control Language)

TCL은 트랜잭션 경계를 제어하는 명령어입니다.

명령역할
COMMITDML 변경 사항 영구 반영
ROLLBACK마지막 COMMIT 이후 변경 사항 취소
SAVEPOINT중간 복구 지점 지정
실전 포인트: SAVEPOINT를 잡아두면 전체 롤백이 아니라 특정 지점까지 부분 롤백이 가능합니다.
예제 1: 명령 분류 퀵체크
SQL분류설명
CREATE TABLE emp (...)DDL테이블 구조 생성
INSERT INTO emp VALUES (...)DML행 삽입
UPDATE emp SET sal=sal*1.1DML행 수정
ROLLBACKTCL트랜잭션 취소
예제 2: COMMIT/ROLLBACK 흐름
순서실행문결과
1INSERT INTO emp VALUES (1001, 'KIM')삽입되었지만 아직 확정 아님
2ROLLBACK1번 삽입 취소
3INSERT INTO emp VALUES (1002, 'LEE')삽입 대기
4COMMIT1002 행 확정
SQLD 출제진이 좋아하는 함정 7가지

🪤 함정 1. TRUNCATE는 DML이다?

TRUNCATE는 DDL로 분류합니다. DELETE와 혼동하기 쉬운 대표 함정입니다.

🪤 함정 2. SELECT는 DML이 아니다?

시험 기준 분류에서는 SELECT도 DML 범주로 다룹니다.

🪤 함정 3. DDL도 ROLLBACK 가능하다?

대부분 DBMS에서 DDL은 자동 커밋 특성이 있어 일반적으로 롤백 대상이 아닙니다.

🪤 함정 4. DELETE와 TRUNCATE는 완전히 같다?

둘 다 삭제지만 성격이 다릅니다. DELETE는 DML, TRUNCATE는 DDL입니다.

🪤 함정 5. COMMIT은 데이터 조회 명령이다?

COMMIT은 TCL로 트랜잭션 확정 명령입니다.

🪤 함정 6. SAVEPOINT 후 ROLLBACK은 전체만 가능?

SAVEPOINT 지점까지 부분 롤백이 가능합니다.

🪤 함정 7. DROP과 TRUNCATE 차이 무시

DROP은 객체 자체 삭제, TRUNCATE는 데이터만 전체 삭제(구조 유지)입니다.
