관계형 vs 비관계형 데이터베이스

지금까지 배운 "테이블·PK·FK"는 사실 데이터베이스의 한 종류일 뿐입니다. 완전히 다르게 생긴 데이터베이스도 있다는 걸 알아봅니다.

STEP 1

같은 학생 정보, 완전히 다르게 생겼다

지금까지 배운 방식(관계형)과, 또 다른 방식(비관계형/NoSQL)으로 똑같은 학생 정보를 저장하면 이렇게 다릅니다.

🗄️ 관계형 DB — 표(테이블) 여러 개로 나눠 저장
STU_IDNAMECLUB_ID
S2023001박준서C01
CLUB_ID동아리명
C01밴드부
📦 비관계형(NoSQL) DB — 문서 하나에 다 몰아넣기
{ "이름": "박준서", "동아리": { "이름": "밴드부", "장소": "음악실" } }
👀 관계형은 정보를 여러 표로 쪼개서 저장하고 필요할 때 연결(JOIN)합니다. 비관계형은 관련된 정보를 한 덩어리(문서)에 몰아서 저장합니다.

관계형 데이터베이스가 특히 강한 부분은 무엇일까요?

오늘의 핵심 정리

기억할 것 3가지

  • 관계형 DB는 데이터를 여러 테이블로 나눠 저장하고 PK·FK로 연결합니다 — 정확성과 일관성이 중요한 데이터(계좌, 학사정보)에 강합니다.
  • 비관계형(NoSQL) DB는 관련 정보를 한 덩어리로 저장합니다 — 구조가 자주 바뀌거나 데이터 양이 폭발적으로 많은 서비스(SNS 피드, 로그)에 강합니다.
  • 이 강의는 관계형 DB(SQL)를 중심으로 진행합니다. 실무에서 가장 널리 쓰이고, 백엔드 개발의 기본기이기 때문입니다.
