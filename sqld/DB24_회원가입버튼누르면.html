오늘의 핵심 정리

기억할 것 3가지

  • 버튼 클릭 한 번은 프론트엔드 → HTTP → 백엔드 API → 커넥션 → SQL → JSON 응답 → 화면 표시까지 여러 계층을 순서대로 통과합니다.
  • 각 계층은 서로 다른 역할을 맡습니다 — 프론트는 보여주고 전달, 백엔드는 검증하고 저장, 데이터베이스는 진짜 정보를 지킵니다.
  • 이 흐름 하나에 1~23번 시간에 배운 테이블·PK/FK·SQL·HTTP·API·커넥션 지식이 전부 녹아있습니다 — 이제 여러분은 이 전체 그림을 볼 수 있습니다!
