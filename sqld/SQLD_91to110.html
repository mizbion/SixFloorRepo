🥇 RANK vs DENSE_RANK vs ROW_NUMBER

실제 EMP 데이터에는 급여가 겹치는 사원들이 있습니다(3000·1250·1100). 동점자가 있을 때 세 함수가 어떻게 다르게 순위를 매기는지 확인해보세요. (Q98번 관련)
💡 SAL=3000(SCOTT·FORD), SAL=1250(WARD·MARTIN), SAL=1100(ADAMS·CHOI)이 동점 구간입니다. RANK는 동점 다음 순위를 건너뛰고, DENSE_RANK는 건너뛰지 않고, ROW_NUMBER는 동점이어도 무조건 순서를 매깁니다.

🔑 기본키(PK)로 중복·NULL 막기

PRODUCTS와 같은 구조로 새 테이블을 만들고, PK 위반 상황을 직접 넣어봅니다. (Q99번 관련)
CREATE TABLE PRODUCTS_TEST (
  PROD_ID VARCHAR(10) NOT NULL,
  PROD_NAME VARCHAR(100),
  CONSTRAINT PK_TEST PRIMARY KEY (PROD_ID)
);

🔢 COUNT(*) vs COUNT(PK칼럼)

STU_ID는 PK라서 NULL이 있을 수 없습니다. 그래서 COUNT(*)와 COUNT(STU_ID)는 항상 같습니다. TEL처럼 NULL 허용 칼럼과 비교해보세요. (Q107번 관련)
