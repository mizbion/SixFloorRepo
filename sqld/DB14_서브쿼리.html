서브쿼리 — 질문 속의 질문

"평균보다 학년이 높은 학생은?" 이런 질문에 답하려면, SQL 문장 안에 또 다른 SQL 문장이 필요합니다.

STEP 1

"평균보다 학년이 높은 학생"을 어떻게 찾을까?

이 질문에 답하려면 사실 질문이 2단계입니다. ① 평균 학년이 몇인지 먼저 알아야 하고, ② 그 값보다 높은 학생을 찾아야 합니다. 버튼을 눌러 확인해보세요.

STEP 2

바깥 질문과 안쪽 질문

색칠된 부분을 클릭해서 어디가 "바깥(메인) 쿼리"이고 어디가 "안쪽(서브) 쿼리"인지 확인해보세요.

SELECT NAME, YEAR FROM STUDENTS
WHERE YEAR > (SELECT AVG(YEAR) FROM STUDENTS)
괄호 안쪽(서브쿼리)을 클릭해보세요.
STEP 3

결과가 여러 개라면? IN을 쓴다

"밴드부(C01)에 속한 학생들이 듣는 과목"처럼, 서브쿼리 결과가 여러 개일 수도 있습니다. 이때는 = 대신 IN을 씁니다.

SELECT NAME, SUB_ID FROM ENROLL
WHERE STU_ID IN (
  SELECT STU_ID FROM STUDENTS WHERE CLUB_ID = 'C01'
);
STEP 4

서브쿼리, 세 군데에 넣을 수 있다

각 카드의 "실행 과정 보기" 버튼을 눌러서 단계별로 확인해보세요.

STEP 5

확인 퀴즈

서브쿼리에 대한 설명으로 옳은 것은?

오늘의 핵심 정리

기억할 것 3가지

  • 서브쿼리는 SQL 문장 안에 괄호로 들어가는 또 다른 SQL 문장입니다. 안쪽부터 먼저 실행되어 값을 만들고, 그 값을 바깥 쿼리가 사용합니다.
  • 서브쿼리 결과가 값 1개면 =, >, < 같은 일반 비교연산자를, 값 여러 개면 IN을 씁니다.
  • 서브쿼리는 WHERE, FROM, SELECT 절 어디에나 들어갈 수 있는 유연한 도구입니다.
