오늘의 핵심 정리

기억할 것 3가지

  • SELECT *는 모든 칼럼을, SELECT 칼럼명, 칼럼명은 원하는 칼럼만 골라서 보여줍니다.
  • 칼럼이 많아지고 화면이 복잡해질수록, 필요한 칼럼만 골라 보는 습관이 중요합니다 (실무에서도 SELECT *는 잘 안 씁니다).
  • AS로 결과 화면에 표시될 이름에 별칭을 붙일 수 있습니다.
