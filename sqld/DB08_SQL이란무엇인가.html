데이터베이스 × 백엔드 연계 · 08

SQL이란 무엇인가

사람의 말을 데이터베이스가 알아듣는 명령으로 바꿔주는 언어, SQL을 소개합니다. 2부 "SQL로 데이터와 대화하기"의 시작입니다.

STEP 1

"3학년 학생만 보여줘"를 컴퓨터에게 시키려면?

사람은 이렇게 편하게 말하지만, 데이터베이스는 정해진 규칙의 언어로만 알아듣습니다. 버튼을 눌러 번역 과정을 확인해보세요.

🗣️ "STUDENTS 테이블에서, 학년이 3인 학생들의 이름을 보여줘"
⬇️ SQL로 번역하면...
SELECT NAME FROM STUDENTS WHERE YEAR = 3;
SQL은 Structured Query Language(구조화된 질의 언어)의 줄임말입니다. 데이터베이스에게 "질문(Query)"을 던지는 전용 언어입니다.
STEP 2

방금 그 문장, 부위별로 뜯어보면?

색칠된 단어를 클릭해서 각각 무슨 역할을 하는지 확인해보세요.

SELECT NAME FROM STUDENTS WHERE YEAR = 3;
색칠된 부분을 눌러보세요.
STEP 3

SQL도 종류가 나뉜다

데이터를 "조회/수정"하는 것 말고도, SQL은 하는 역할에 따라 4가지로 나뉩니다.

STEP 4

확인 퀴즈

SQL에 대한 설명으로 옳은 것은?

오늘의 핵심 정리

기억할 것 3가지

  • SQL은 데이터베이스에게 질문하고 명령을 내리는 전용 언어입니다.
  • SQL 문장은 SELECT(무엇을) - FROM(어디서) - WHERE(어떤 조건으로) 처럼 정해진 순서와 규칙을 가진 "구조화된" 언어입니다.
  • SQL은 하는 일에 따라 DML(조회·수정) / DDL(구조 관리) / DCL(권한) / TCL(거래 확정) 4가지로 나뉩니다.
