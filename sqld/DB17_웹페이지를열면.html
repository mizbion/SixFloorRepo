웹페이지를 열면 무슨 일이 일어날까

주소창에 주소를 치고 엔터를 누르는 그 짧은 순간, 실제로는 여러 단계가 아주 빠르게 지나갑니다.

STEP 1

www.school.com/students 를 입력하면?

버튼을 눌러 한 단계씩 진행하며 무슨 일이 일어나는지 확인해보세요.

STEP 2

요청과 응답, 그 안에는 무엇이 들어있을까

택배 상자에 송장이 붙어있듯, 요청과 응답에도 정해진 정보가 담겨 있습니다.

📤 요청 (Request)
메서드GET
주소/students
보내는 사람 정보브라우저 종류 등
📥 응답 (Response)
상태 코드200 (성공)
내용HTML 화면 데이터
STEP 3

서버가 보내는 짧은 신호, 상태 코드

클릭해서 각 상태 코드가 무슨 뜻인지 확인해보세요.

200 OK 404 Not Found 500 Server Error
코드를 클릭해보세요.
STEP 4

매번 똑같은 것 vs 매번 달라지는 것

웹페이지의 모든 요소가 다 데이터베이스를 거치는 건 아닙니다. 아래 요소들을 눌러서 "정적"인지 "동적"인지 확인해보세요.

화면 요소를 하나씩 클릭해보세요.
STEP 5

확인 퀴즈

서버가 요청받은 페이지를 찾지 못했을 때 보통 어떤 상태 코드를 보낼까요?

오늘의 핵심 정리

기억할 것 3가지

  • 웹페이지 로딩은 요청 → 서버 처리(DB 조회 포함) → 응답 → 화면 렌더링 순서로 이뤄집니다.
  • 요청에는 "무엇을, 어떻게" 원하는지가, 응답에는 "성공했는지"를 알려주는 상태 코드와 실제 내용이 담겨 있습니다.
  • 상태 코드 200은 성공, 404는 "찾을 수 없음", 500은 "서버 내부 오류"를 뜻합니다.
