핵심 개념 — 괄호 완전 정리 🔑

가장 많이 헷갈리는 부분을 먼저 잡아봐요

⚠️
대괄호 [ ] 의 두 가지 의미 — 이것이 가장 중요!
① 리스트 생성: a = [1, 2, 3] → 새 리스트를 만든다
② 인덱싱: a[0]   t[0] → 어떤 자료형이든 요소를 꺼낼 때
→ 인덱싱 [ ]은 리스트뿐 아니라 튜플·문자열에도 똑같이 사용합니다!
괄호 완전 정리
# ① 대괄호 [] — 리스트 만들기
my_list = [10, 20, 30]

# ② 소괄호 () — 튜플 만들기
my_tuple = (10, 20, 30)

# ③ 인덱싱 [] — 리스트/튜플 모두 동일!
print(my_list[0])    # → 10  (리스트에서 꺼내기)
print(my_tuple[0])   # → 10  (튜플에서 꺼내기 — 똑같이 []!)
print(my_tuple[1])   # → 20  (튜플도 인덱싱은 대괄호)
💡
핵심 공식
( ) → 튜플 생성할 때만  |  [ ] → 리스트 생성 + 모든 자료형 인덱싱
my_tuple[0] — 소괄호로 만든 튜플에서 대괄호로 꺼낸다 ✅
02

인덱싱 — 공통 규칙

리스트든 튜플이든 꺼내는 방법은 같다!

인덱싱은 자료형[번호] 형태로 요소를 꺼냅니다.
번호는 0부터 시작하고, 음수(-1, -2...)는 뒤에서부터 셉니다.
인덱싱 공통 규칙
fruits = ['사과', '바나나', '포도']   # 리스트
week   = ('월', '화', '수')          # 튜플

# 두 자료형 모두 인덱싱은 대괄호 []!
print(fruits[0])    # → '사과'
print(week[0])      # → '월'  ← 튜플도 인덱싱은 []
print(fruits[-1])   # → '포도'
print(week[-1])     # → '수'
⚠️
자주 하는 실수!
week(0) → ❌ 소괄호로 인덱싱하면 오류 (함수 호출 문법)
week[0] → ✅ 인덱싱은 반드시 대괄호

리스트 vs 튜플 — 한눈에 비교

무엇이 같고 무엇이 다른지 정리!

핵심 비교
# 리스트 — 변경 가능 (mutable)
my_list = [1, 2, 3]
my_list[0] = 99           # ✅ 수정 가능
my_list.append(4)          # ✅ 추가 가능

# 튜플 — 변경 불가 (immutable)
my_tuple = (1, 2, 3)
# my_tuple[0] = 99  ← ❌ TypeError!

# 인덱싱은 둘 다 대괄호 [ ] !
print(my_list[0])    # → 99
print(my_tuple[0])   # → 1   ← 튜플도 [] 로 꺼냄!
📋 리스트
생성: [1, 2, 3]
✅ 수정·추가·삭제 가능
✅ 인덱싱 a[0]
✅ sort, append 등
🔒 튜플
생성: (1, 2, 3)
❌ 수정·추가·삭제 불가
✅ 인덱싱 t[0] ← []
✅ count, index만

연습 T1
튜플 만들기 & type 확인
소괄호 ( )로 만들어요. type은 'tuple'이에요.
예제
t = (10, 20, 30)

연습 T2
튜플 인덱싱 — 대괄호!
튜플을 소괄호로 만들었어도 꺼낼 때는 반드시 t[번호] 대괄호!
예제
t = ('월', '화', '수', '목', '금')
print(t[0])    # → '월'   ← [] 대괄호!

print(t[-1])   # → '금'
튜플 입력 (쉼표 구분)
결과값을 입력하고 눌러보세요
연습 T3
튜플 슬라이싱
슬라이싱도 리스트와 똑같이 t[시작:끝]으로!
예제
t = (1, 2, 3, 4, 5)
print(t[1:4])   # → (2, 3, 4)
print(t[:3])    # → (1, 2, 3)

결과값을 입력하고 눌러보세요
연습 T4
언패킹 — 여러 변수에 한꺼번에
튜플의 값을 변수에 나눠 담는 것을 언패킹이라고 해요.
예제
t = ('홍길동', 18, '서울')
name, age, city = t     # 언패킹!

튜플 입력 (쉼표 구분)
결과값을 입력하고 눌러보세요
연습 T5
수정하면 오류!
튜플은 한 번 만들면 바꿀 수 없어요 — 이게 튜플의 핵심!
예제
t = (1, 2, 3)
print(t[0])   # → 1  (읽기는 OK)
# t[0] = 99  ← TypeError 발생!
# 튜플은 수정 불가 — immutable!
튜플 입력 (쉼표 구분)
결과값을 입력하고 눌러보세요

튜플 연결 · 반복
수정은 불가지만 +로 이어붙이거나 *로 반복은 돼요!
예제

b = (3, 4)
print(a + b)    # → (1, 2, 3, 4)
print(a * 3)    # → (1, 2, 1, 2, 1, 2)
튜플 입력 (쉼표 구분)
결과값을 입력하고 눌러보세요

결과값을 입력하고 눌러보세요

예제

결과값을 입력하고 눌러보세요
연습 T9
in — 포함 확인
값 in 튜플로 포함 여부를 True/False로 확인해요.
예제
