01

튜플(Tuple)이란?

소괄호 ( )로 만드는 변경 불가 자료형

🔒
튜플 = 잠긴 상자
튜플은 소괄호 ( )로 만들고, 리스트와 비슷하지만
한 번 만들면 내용을 바꿀 수 없어요! — 이를 불변(immutable)이라고 해요.
튜플 생성
# 소괄호로 만들어요
t1 = (1, 2, 3)
t2 = ('사과', '바나나', '포도')
t3 = ('홍길동', 18, '서울')   # 혼합 가능!

# ⚠️ 요소가 1개면 반드시 쉼표 필요!
t4 = (42,)    # ✅ 튜플
t5 = (42)     # ❌ 그냥 숫자 42

print(type(t1))   # → <class 'tuple'>
print(len(t1))    # → 3
⚠️
요소 1개짜리 튜플 — 쉼표 필수!
t = (42,) → ✅ 튜플    t = (42) → ❌ 그냥 숫자
튜플 입력 (쉼표 구분)
결과값을 입력하고 눌러보세요
02

리스트 vs 튜플 비교

닮았지만 다른 두 자료형의 결정적 차이

⚖️
무엇이 다를까?
📋 리스트 (List)

생성: [ ] 대괄호

✅ 요소 추가 · 수정 · 삭제 가능

🔄 mutable — 변경 가능

→ 값이 자주 바뀔 때

🔒 튜플 (Tuple)

생성: ( ) 소괄호

❌ 추가 · 수정 · 삭제 모두 불가

🔐 immutable — 변경 불가

→ 절대 바뀌면 안 될 때

수정 시도 → 오류 발생!
t = (1, 2, 3)
t[0] = 99    # ← 이렇게 하면 오류!
❌ TypeError
'tuple' object does not support item assignment
💡
튜플은 언제 쓸까요?
• 요일, 방위, 월 이름처럼 절대 바뀌지 않는 데이터
• 함수에서 여러 값을 한꺼번에 반환할 때
• 실수로 값이 바뀌는 것을 방지하고 싶을 때
Q1. 튜플을 만드는 괄호는?  ① [ ]  ② { }  ③ ( )
Q2. t = (5,)의 자료형은?
03

인덱싱 — 꺼내기

리스트와 똑같이 0부터 시작하는 인덱스!

🔍
인덱싱 · 슬라이싱
튜플도 리스트처럼 0부터 시작하는 인덱스를 사용해요.
t[0] → 첫 번째  |  t[-1] → 마지막
👆 요소를 클릭해보세요! (🔒 수정 불가)
요소를 클릭하면 인덱스 정보가 나타납니다
인덱싱 · 슬라이싱
t = ('월', '화', '수', '목', '금')

print(t[0])     # → '월'
print(t[-1])    # → '금'
print(t[1:4])   # → ('화', '수', '목')
튜플 (쉼표 구분)
인덱스 번호
결과인덱스를 입력하고 눌러보세요

04

패킹 · 언패킹 ⭐

튜플의 가장 강력하고 실용적인 기능!

📦
여러 값을 묶고, 한번에 꺼내기!
패킹: 여러 값을 하나의 튜플로 묶기
언패킹: 튜플의 값을 여러 변수에 한꺼번에 꺼내기
📦 패킹 → 🎁 언패킹
"홍길동"
18
"서울"
→
name = "홍길동"
age = 18
city = "서울"
패킹 · 언패킹
# 패킹: 여러 값 → 하나의 튜플
person = ('홍길동', 18, '서울')

# 언패킹: 튜플 → 여러 변수
name, age, city = person

print(name)    # → 홍길동
print(age)     # → 18

# 두 변수 값 교환 (파이썬만의 멋진 기능!)
a, b = 10, 20
a, b = b, a
print(a, b)    # → 20 10
💡
언패킹 — 변수 개수 = 요소 수
a, b = (1, 2, 3) → ❌ 변수 2개, 요소 3개로 오류
a, b, c = (1, 2, 3) → ✅ 정상
튜플 (쉼표 구분)
결과튜플을 입력하고 눌러보세요

05

튜플 연산과 메서드

+, *, in 그리고 count · index

➕
더하고 · 곱하고 · 찾기
튜플 연산
a = (1, 2, 3)
b = (4, 5)

print(a + b)         # → (1, 2, 3, 4, 5)  이어붙이기
print(a * 3)         # → (1, 2, 3, 1, 2, 3, 1, 2, 3)  반복
print(2 in a)         # → True  포함 여부
print(len(a))          # → 3

t = (1, 2, 2, 3, 2)
print(t.count(2))     # → 3  (2가 몇 번?)
print(t.index(3))     # → 3  (3이 몇 번째?)
⚠️
튜플에는 없는 메서드들
append() remove() sort() → 모두 ❌
튜플은 변경 불가라서 리스트처럼 내용을 바꾸는 메서드가 없어요.
숫자 튜플
찾을 값
결과값을 입력하고 눌러보세요

실전① RGB 색상 저장 🎨

절대 바뀌면 안 되는 데이터엔 튜플!

🎨
RGB 색상 믹서
색상값은 0~255 — 절대 바뀌면 안 돼요!
핵심 코드
# RGB 색상값 — 불변이어야 해서 튜플로!
RED   = (255, 0,   0)
GREEN = (0,   255, 0)
BLUE  = (0,   0,   255)

# 언패킹으로 꺼내기
r, g, b = RED
print(f"Red: R={r}, G={g}, B={b}")
R (0~255)
G (0~255)
B (0~255)

실전② 학생 정보 관리 🎓

이름·생년월일·학번처럼 바뀌지 않는 정보는 튜플로!

🎓
학생 카드 만들기
리스트 안에 튜플 + 언패킹 반복문
핵심 코드
# 학생 기본 정보 — 튜플로 고정!
student = ('홍길동', '2007-03-15', 'A반')
name, birth, cls = student   # 언패킹!

# 여러 학생을 리스트로 관리
students = [
    ('홍길동', 85, 'A반'),
    ('김철수', 92, 'B반'),
]
for name, score, cls in students:
    print(f"{name}({cls}): {score}점")
