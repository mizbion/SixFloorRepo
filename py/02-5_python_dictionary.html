딕셔너리란? & 생성하기

key-value 쌍으로 이루어진 자료형

🗂️ 딕셔너리란?

딕셔너리는 키(key)와 값(value)이 쌍으로 저장되는 자료형입니다.
마치 실제 사전처럼 단어(key)로 찾으면 뜻(value)이 나오는 구조예요!
💡 리스트는 숫자 인덱스[0]로 접근, 딕셔너리는 키["이름"]로 접근합니다.
딕셔너리 구조 시각화
"name"
→
"철수"
"age"
→
18
"grade"
→
"A"
"score"
→
92

📝 딕셔너리 생성하기

중괄호 { }를 사용하고, 키: 값 형식으로 작성합니다.
여러 쌍은 쉼표 ,로 구분합니다.
기본 생성 
# 기본 딕셔너리 생성
student = {"name": "철수", "age": 18, "score": 92}

# 빈 딕셔너리
empty = {}

print(student)
# → {'name': '철수', 'age': 18, 'score': 92}
다양한 값 타입 
# 값으로 다양한 타입 사용 가능
game = {
    "title": "리그 오브 레전드",
    "level": 30,
    "items": ["검", "방패"]
}
print(game["title"])  # → 리그 오브 레전드
⚠️
키(key) 규칙: 키는 중복될 수 없어요! 같은 키를 두 번 쓰면 뒤의 값이 덮어씁니다.
{"name": "철수", "name": "영희"} → {"name": "영희"}
2

값 접근하기

키로 값을 꺼내는 두 가지 방법

🔍 대괄호 vs get() 메서드

값 접근 방법 
student = {"name": "철수", "age": 18}

# 방법 1: 대괄호 사용
print(student["name"])   # → 철수

# 방법 2: get() 메서드 (더 안전!)
print(student.get("name"))  # → 철수
print(student.get("grade", "없음")) # → 없음
✅
get() 추천! 없는 키를 대괄호로 접근하면 오류가 나지만,
.get("키", 기본값)은 없는 키일 때 기본값을 반환합니다.
❌
student["grade"] → 키가 없으면 KeyError 발생!
처음엔 .get()을 습관처럼 쓰는 게 좋아요.

항목 추가 & 삭제

딕셔너리는 자유롭게 수정 가능

➕ 추가하기 / ✏️ 수정하기

추가 & 수정 
student = {"name": "철수", "age": 18}

# 새 항목 추가 (없는 키 = 추가)
student["score"] = 95

# 기존 값 수정 (있는 키 = 수정)
student["age"] = 19

print(student)
# → {'name': '철수', 'age': 19, 'score': 95}

🗑️ 삭제하기

항목 삭제 
student = {"name": "철수", "age": 18, "score": 95}

# del로 삭제
del student["score"]
print(student)  # → {'name': '철수', 'age': 18}

# pop()으로 삭제 (삭제된 값 반환)
age = student.pop("age")
print(age)     # → 18
💡 del은 그냥 삭제, pop()은 삭제하면서 값을 가져올 때 사용!

주요 메서드

딕셔너리를 더 잘 다루는 방법들

🛠️ 자주 쓰는 메서드 4가지

메서드 설명 반환값
.keys() 모든 키를 가져옴 dict_keys
.values() 모든 값을 가져옴 dict_values
.items() 키-값 쌍을 튜플로 가져옴 dict_items
"키" in 딕셔너리 키 존재 여부 확인 True / False
메서드 예제 
student = {"name": "철수", "age": 18, "score": 95}

print(student.keys())    # → dict_keys(['name', 'age', 'score'])
print(student.values())  # → dict_values(['철수', 18, 95])
print("name" in student) # → True
print("grade" in student)# → False
items() 활용 
student = {"국어": 90, "수학": 85, "영어": 92}

# for문과 items() 조합
for subject, score in student.items():
    print(f"{subject}: {score}점")
# → 국어: 90점
# → 수학: 85점
# → 영어: 92점
