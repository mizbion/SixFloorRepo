숫자형의 종류

파이썬에서 숫자를 표현하는 자료형은 크게 네 가지입니다. 가장 많이 사용하는 것은 정수형과 실수형입니다.

종류 영문 파이썬 예시 설명
정수형int123, -345, 0소수점 없는 숫자
실수형float1.23, -3.14, 4.2e10소수점이 있는 숫자
8진수octal0o1770o로 시작
16진수hexadecimal0xFF, 0xABC0x로 시작

정수형 (int)

소수점이 없는 숫자입니다. 양수, 음수, 0 모두 정수형입니다. 파이썬의 정수형은 자리수 제한이 없어 매우 큰 수도 표현 가능합니다.

Python — 정수형 
# 정수형 변수 선언
a = 123       # 양의 정수
b = -178      # 음의 정수
c = 0         # 0도 정수형
big = 999999999999999999  # 자리수 제한 없음!

print(type(a))   # 자료형 확인
<class 'int'>

print(a, b, c)
123 -178 0
💡 type() 함수 type(변수)를 사용하면 해당 변수의 자료형을 확인할 수 있습니다. 학습 중 자료형이 헷갈릴 때 바로 확인해보세요.

실수형 (float)

소수점이 포함된 숫자입니다. 과학적 표기법(지수 표현)도 사용할 수 있습니다.

Python — 실수형 
# 일반 실수
a = 1.2
b = -3.45
c = 0.0

# 지수 표현 (e 또는 E 사용 가능)
d = 4.24e10      # 4.24 × 10¹⁰ = 42400000000.0
e = 4.24E10      # 위와 동일
f = 1.5e-3       # 1.5 × 10⁻³ = 0.0015

print(d)         42400000000.0
print(f)         0.0015
print(type(a))   <class 'float'>
⚠️ 부동소수점 주의 컴퓨터는 실수를 이진수로 저장하기 때문에 아주 미세한 오차가 발생할 수 있습니다.
0.1 + 0.2 == 0.3의 결과가 False가 될 수 있습니다. (실제로 0.30000000000000004)

8진수 · 16진수

실무에서는 자주 쓰이지 않지만, 하드웨어 제어나 색상 코드 등 특수한 상황에서 활용됩니다.

Python — 8진수 · 16진수 
# 8진수: 0o 또는 0O 로 시작
a = 0o177        # 8진수 177 → 십진수 127
print(a)          127
# 계산: 1×8² + 7×8¹ + 7×8⁰ = 64 + 56 + 7 = 127

# 16진수: 0x 로 시작 (A=10, B=11, C=12, D=13, E=14, F=15)
b = 0xFF          # 16진수 FF → 십진수 255
c = 0xABC         # 16진수 ABC → 십진수 2748
print(b, c)       255 2748
# 계산: 10×16² + 11×16¹ + 12×16⁰ = 2560 + 176 + 12 = 2748

# 십진수 → 다른 진수로 변환하는 내장함수
print(oct(127))    0o177
print(hex(255))    0xff
📌 활용 팁 16진수는 웹 색상 코드(#FF0000 = 빨강), 메모리 주소 표현 등에 실제로 많이 사용됩니다.

숫자형 연산자

파이썬에서 사용할 수 있는 주요 숫자 연산자를 정리했습니다. 사칙연산은 물론, 다른 언어에서 보기 드문 편리한 연산자들도 있습니다.

+
덧셈
3 + 4 → 7
-
뺄셈
10 - 3 → 7
*
곱셈
3 * 4 → 12
/
나눗셈
7 / 4 → 1.75
**
제곱
3 ** 4 → 81
%
나머지
7 % 3 → 1
//
몫
7 // 4 → 1

사칙 연산

수학에서 사용하는 사칙연산과 동일합니다. 단, 나눗셈(/)은 항상 실수형(float)을 반환합니다.

Python — 사칙 연산 
a = 3
b = 4

print(a + b)    7
print(a - b)    -1
print(a * b)    12
print(a / b)    0.75   # 결과는 항상 float!

# 정수 나눗셈도 float 반환
print(10 / 2)   5.0    # 5가 아니라 5.0

제곱 연산 **

x ** y는 x의 y제곱을 계산합니다. 다른 언어의 Math.pow(x, y)와 동일한 역할을 합니다.

Python — 제곱 연산 
print(3 ** 4)     81      # 3⁴ = 81
print(2 ** 10)    1024    # 2¹⁰ = 1024
print(2 ** 0.5)   1.4142135623730951  # √2

# 응용: 큰 수의 제곱도 쉽게
print(10 ** 20)   100000000000000000000

나머지 연산 %

나눗셈을 수행한 후 나머지를 반환합니다. 짝수/홀수 판별, 주기적인 반복 처리 등에 매우 자주 사용됩니다.

Python — 나머지 연산 
print(7 % 3)    1   # 7 = 3×2 + 1
print(3 % 7)    3   # 3 = 7×0 + 3
print(10 % 5)   0   # 나머지 없음

# 실전 활용: 짝수/홀수 판별
n = 14
if n % 2 == 0:
    print(n, "은(는) 짝수")
else:
    print(n, "은(는) 홀수")
14 은(는) 짝수
💡 활용 예 n % 2 == 0 → 짝수 판별  |  n % 3 == 0 → 3의 배수 판별  |  시계처럼 반복(0~23시: hour % 24)

몫 연산 //

나눗셈을 수행한 후 정수 몫만 반환합니다. /와의 차이를 꼭 구분하세요.

Python — 몫 연산 
print(7 / 4)    1.75   # 일반 나눗셈 → float
print(7 // 4)   1      # 몫만 반환 → int

print(10 // 3)  3      # 10 = 3×3 + 1
print(-7 // 2)  -4     # 음수는 더 작은 정수로 내림

# 실전 활용: 분 → 시간·분 변환
total_min = 137
hours = total_min // 60
mins  = total_min % 60
print(f"{total_min}분 = {hours}시간 {mins}분")
137분 = 2시간 17분

복합 연산자

산술 연산자와 대입 연산자(=)를 결합한 형태입니다. 코드를 더 간결하게 작성할 수 있습니다.

Python — 복합 연산자 
a = 10

a += 3    # a = a + 3  → 13
a -= 2    # a = a - 2  → 11
a *= 4    # a = a * 4  → 44
a /= 2    # a = a / 2  → 22.0 (float!)
a //= 3   # a = a // 3 → 7.0
a %= 4    # a = a % 4  → 3.0
a **= 2   # a = a ** 2 → 9.0

print(a)  9.0

실전 예제

예제 1 — 거스름돈 계산기

%와 //를 활용하여 금액을 지폐/동전 단위로 분해합니다.

Python — 거스름돈 계산기 
money = 4870  # 거스름돈 금액

won1000 = money // 1000
money   = money %  1000
won500  = money // 500
money   = money %  500
won100  = money // 100
money   = money %  100
won10   = money // 10

print(f"1000원: {won1000}개")  1000원: 4개
print(f"500원:  {won500}개")   500원:  1개
print(f"100원:  {won100}개")   100원:  3개
print(f"10원:   {won10}개")    10원:   7개

예제 2 — 원의 넓이와 둘레

**를 사용한 제곱 연산으로 원의 넓이와 둘레를 계산합니다.

Python — 원의 넓이와 둘레 
pi = 3.14159
r  = 5        # 반지름

area = pi * r ** 2         # 넓이 = π × r²
circumference = 2 * pi * r  # 둘레 = 2πr

print(f"반지름 {r}인 원")
print(f"넓이:  {area:.2f}")           넓이:  78.54
print(f"둘레:  {circumference:.2f}")   둘레:  31.42

예제 3 — 성적 평균 계산

복합 연산자를 활용한 누적 합산과 평균 계산입니다.

Python — 성적 평균 
kor = 85
eng = 92
math = 78
sci = 88

total = 0
total += kor
total += eng
total += math
total += sci

avg = total / 4

print(f"총점: {total}점")       총점: 343점
print(f"평균: {avg:.1f}점")    평균: 85.8점

핵심 요약

숫자형 종류

int — 정수 (소수점 없음)

float — 실수 (소수점 포함)

0o... — 8진수

0x... — 16진수

핵심 연산자

** — 제곱 (x의 y승)

% — 나머지

// — 몫 (정수)

/ — 나눗셈 (항상 float)

복합 연산자

+= -= *= /=

//= %= **=

a op= b ≡ a = a op b

주의사항

/는 항상 float 반환

float 부동소수점 오차 주의
