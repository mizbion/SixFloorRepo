if문 연습 & 평가

📝 연습 예제 20개 ✏️ 평가 10문항 🔍 실행결과 맞추기 🧩 조건 채워넣기

① 기본 if — 조건이 참일 때만 실행

조건식이 True면 들여쓴 블록을 실행하고, False면 아무것도 실행하지 않습니다.

예제 01 나이 확인 
# 예제 01 — 기본 if
age = 20

if age >= 18:
    print("성인입니다.")

print("프로그램 종료")
▶ 실행 결과
성인입니다.
프로그램 종료
예제 02 양수 확인 
# 예제 02 — 양수 확인
number = -5

if number > 0:
    print("양수입니다.")

print("확인 완료")
▶ 실행 결과
확인 완료
예제 03 비밀번호 확인 
# 예제 03 — 비밀번호 확인
password = "python123"

if password == "python123":
    print("로그인 성공!")
    print("환영합니다.")

print("로그인 시도 완료")
▶ 실행 결과
로그인 성공!
환영합니다.
로그인 시도 완료
예제 04 점수 합격 여부 
# 예제 04 — 점수 합격 여부
score = 75

if score >= 60:
    print("합격입니다!")

if score >= 90:
    print("우수상 대상입니다!")

print("채점 완료")
▶ 실행 결과
합격입니다!
채점 완료

② if-else — 참/거짓 두 갈래

조건이 True면 if 블록, False면 else 블록을 실행합니다. 반드시 둘 중 하나만 실행됩니다.

예제 05 홀수 짝수 
# 예제 05 — 홀수 짝수
num = 7

if num % 2 == 0:
    print(num, "은 짝수입니다.")
else:
    print(num, "은 홀수입니다.")
▶ 실행 결과
7 은 홀수입니다.
예제 06 시험 합격 여부 
# 예제 06 — 시험 합격 여부
score = 55

if score >= 60:
    print("합격입니다.")
    print("수고하셨습니다!")
else:
    print("불합격입니다.")
    print("다음에 도전하세요!")
▶ 실행 결과
불합격입니다.
다음에 도전하세요!
예제 07 최댓값 구하기 
# 예제 07 — 두 수 중 큰 값
a = 15
b = 30

if a > b:
    print("a가 더 큽니다:", a)
else:
    print("b가 더 큽니다:", b)
▶ 실행 결과
b가 더 큽니다: 30
예제 08 할인 적용 
# 예제 08 — 회원 할인
is_member = False
price = 10000

if is_member:
    price = price * 0.9
    print("회원 할인 적용:", price)
else:
    print("정가:", price)
▶ 실행 결과
정가: 10000

③ if-elif-else — 여러 조건 나누기

elif로 조건을 여러 개 연결합니다. 위에서 아래로 순서대로 검사하여 처음 True인 블록만 실행됩니다.

예제 09 성적 등급 
# 예제 09 — 성적 등급
score = 85

if score >= 90:
    print("A등급")
elif score >= 80:
    print("B등급")
elif score >= 70:
    print("C등급")
else:
    print("D등급")
▶ 실행 결과
B등급
예제 10 요금 계산 
# 예제 10 — 나이별 요금
age = 13

if age < 7:
    print("무료")
elif age < 19:
    print("청소년 요금: 1000원")
else:
    print("성인 요금: 2000원")
▶ 실행 결과
청소년 요금: 1000원
예제 11 BMI 판정 
# 예제 11 — BMI 체중 판정
bmi = 22.5

if bmi < 18.5:
    print("저체중")
elif bmi < 25:
    print("정상 체중")
elif bmi < 30:
    print("과체중")
else:
    print("비만")
▶ 실행 결과
정상 체중
예제 12 계절 판별 
# 예제 12 — 월별 계절
month = 11

if month in [3, 4, 5]:
    print("봄입니다.")
elif month in [6, 7, 8]:
    print("여름입니다.")
elif month in [9, 10, 11]:
    print("가을입니다.")
else:
    print("겨울입니다.")
▶ 실행 결과
가을입니다.

④ 중첩 if — if 안에 또 if

if 블록 안에 또 다른 if를 쓸 수 있습니다. 들여쓰기 단계에 주의하세요!

예제 13 놀이공원 입장 
# 예제 13 — 중첩 if
age = 16
has_ticket = True

if age >= 8:
    if has_ticket:
        print("입장 가능합니다!")
    else:
        print("티켓이 없습니다.")
else:
    print("8세 미만은 보호자 동반")
▶ 실행 결과
입장 가능합니다!
예제 14 게임 캐릭터 레벨 
# 예제 14 — 레벨 & 아이템
level = 30
has_weapon = False

if level >= 20:
    print("던전 입장 가능")
    if has_weapon:
        print("전투 준비 완료!")
    else:
        print("무기를 장착하세요!")
else:
    print("레벨이 부족합니다.")
▶ 실행 결과
던전 입장 가능
무기를 장착하세요!
예제 15 쇼핑 할인 계산 
# 예제 15 — 등급별 추가 할인
grade = "gold"
total = 50000

if grade == "gold":
    if total >= 50000:
        total -= 5000
        print("5000원 추가 할인!")
    print("최종 금액:", total)
else:
    print("일반 회원 금액:", total)
▶ 실행 결과
5000원 추가 할인!
최종 금액: 45000
예제 16 날씨 & 기온 
# 예제 16 — 날씨 & 기온
weather = "맑음"
temp = 32

if weather == "맑음":
    if temp >= 30:
        print("맑고 더운 날씨")
        print("자외선 차단제 필수!")
    else:
        print("맑고 시원한 날씨")
else:
    print("우산을 챙기세요.")
▶ 실행 결과
맑고 더운 날씨
자외선 차단제 필수!

⑤ 논리연산자 — and, or, not

and: 둘 다 참  |  or: 하나라도 참  |  not: 참↔거짓 반전

예제 17 and 연산자 
# 예제 17 — and 연산자
age = 20
has_id = True

if age >= 18 and has_id:
    print("입장 가능합니다.")
else:
    print("입장이 불가합니다.")
▶ 실행 결과
입장 가능합니다.
예제 18 or 연산자 
# 예제 18 — or 연산자
is_student = False
is_senior = True

if is_student or is_senior:
    print("할인 요금이 적용됩니다.")
else:
    print("정상 요금입니다.")
▶ 실행 결과
할인 요금이 적용됩니다.
예제 19 not 연산자 
# 예제 19 — not 연산자
is_raining = False

if not is_raining:
    print("오늘은 운동하기 좋아요!")
    print("공원으로 출발~")
else:
    print("비가 오니 실내 운동을.")
▶ 실행 결과
오늘은 운동하기 좋아요!
공원으로 출발~
예제 20 복합 조건 
# 예제 20 — and + or 복합
score = 72
bonus = True

if score >= 90 or (score >= 70 and bonus):
    print("장학금 대상입니다!")
else:
    print("장학금 대상 아님")
▶ 실행 결과
장학금 대상입니다!
