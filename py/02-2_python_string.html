문자열 만들기

파이썬에서 문자열(String)은 따옴표로 둘러싸인 문자들의 나열입니다. 숫자 "123"도 따옴표로 감싸면 문자열입니다. 생성 방법은 총 4가지가 있습니다.

① 큰따옴표
a = "Hello World"
b = "Python is fun"
c = "123"   # 숫자도 따옴표 안에 있으면 문자열!
print(type(c))   <class 'str'>
활용 상황문자열 안에 작은따옴표(')가 포함될 때 사용합니다.
예: food = "Python's favorite food"
② 작은따옴표
a = 'Hello World'
b = 'Python is fun'

# 문자열 안에 큰따옴표가 있을 때 유용!
say = '"Python is easy." he says.'
print(say)   "Python is easy." he says.
활용 상황문자열 안에 큰따옴표(")가 포함될 때 사용합니다.
③ 큰따옴표 3개 — 여러 줄 문자열
multiline = """
Life is too short
You need Python
"""

print(multiline)

Life is too short
You need Python

④ 작은따옴표 3개 — 여러 줄 문자열

04

인덱싱 (Indexing)

인덱싱은 문자열에서 특정 위치의 문자 하나를 가져오는 방법입니다. 파이썬은 0부터 번호를 매깁니다.

양수 인덱스 (0부터 시작)
음수 인덱스 (뒤에서부터)
Python — 인덱싱
a = "Life is too short"

# 양수 인덱스 (앞에서부터, 0부터 시작)
print(a[0])    L
print(a[1])    i
print(a[5])    i

# 음수 인덱스 (뒤에서부터)
print(a[-1])   t   # 마지막 문자
print(a[-2])   r   # 뒤에서 두 번째
print(a[-5])   s
⚠️ 문자열은 변경 불가 (immutable) a[0] = 'X'처럼 인덱싱으로 특정 문자를 바꾸는 것은 오류가 납니다.
수정이 필요하면 슬라이싱으로 새 문자열을 만들어야 합니다.
05

슬라이싱 (Slicing)

슬라이싱은 문자열의 일부 구간을 잘라내는 방법입니다. a[시작:끝] 형태로 사용하며, 끝 번호의 문자는 포함하지 않습니다.

핵심 규칙 a[start:end] → start ≤ 포함 범위 < end
끝 인덱스의 문자는 포함되지 않습니다!

🖱 아래 버튼을 눌러 슬라이싱 결과를 확인해보세요

Python — 슬라이싱
a = "Life is too short"

print(a[0:4])    Life    # 0,1,2,3 → 4 미포함
print(a[5:7])    is
print(a[12:17])  short

# 시작/끝 생략 가능
print(a[:4])     Life    # 처음부터 4 미포함까지
print(a[8:])     too short  # 8부터 끝까지
print(a[:])      Life is too short  # 전체

# 음수 인덱스도 사용 가능
print(a[-5:])    short   # 뒤에서 5번째부터 끝까지

실전: 슬라이싱으로 문자열 분리하기

Python — 날짜 문자열 분리
# 날짜 코드에서 연·월·일 추출
date_code = "20231225Sunny"

year    = date_code[:4]    # → '2023'
month   = date_code[4:6]   # → '12'
day     = date_code[6:8]   # → '25'
weather = date_code[8:]    # → 'Sunny'

print(f"연도: {year}, 월: {month}, 일: {day}, 날씨: {weather}")
연도: 2023, 월: 12, 일: 25, 날씨: Sunny

# 슬라이싱으로 문자열 수정 (Pithon → Python)
wrong = "Pithon"
fixed = wrong[:1] + 'y' + wrong[2:]
print(fixed)   Python

문자열 포매팅

문자열 안에 변수 값을 삽입하는 방법입니다. 파이썬 3.6 이상에서는 f-string을 가장 많이 사용합니다.

방식문법지원 버전권장
% 포매팅"이름: %s" % name모든 버전레거시
format() 함수"이름: {}".format(name)Python 2.7+가능
f-stringf"이름: {name}"Python 3.6+⭐ 권장

% 포맷 코드

코드의미
%s문자열 (어떤 값이든 자동 변환)
%d정수
%f실수 (소수점)
%c문자 1개
%%% 문자 자체
% 포매팅
# 기본 사용
print("I eat %d apples." % 3)          I eat 3 apples.
print("I eat %s apples." % "five")   I eat five apples.

# 여러 값
n, day = 10, "three"
print("I ate %d apples. Sick for %s days." % (n, day))
I ate 10 apples. Sick for three days.

# 정렬과 소수점
print("%10s" % "hi")              hi   # 오른쪽 정렬, 10자리
print("%-10s|" % "hi")    hi        |  # 왼쪽 정렬
print("%.2f" % 3.14159)   3.14         # 소수점 2자리

# %를 문자로 표현
print("정답률: %d%%" % 98)  정답률: 98%
format() 함수
# 인덱스로 삽입
print("I eat {0} apples".format(3))             I eat 3 apples
print("{0} + {1} = {2}".format(3, 4, 7))         3 + 4 = 7

# 이름으로 삽입
print("안녕, {name}! 나이는 {age}살.".format(name="지수", age=20))
안녕, 지수! 나이는 20살.

# 정렬
print("{0:<10}".format("hi"))   hi          # 왼쪽
print("{0:>10}".format("hi"))           hi  # 오른쪽
print("{0:^10}".format("hi"))       hi      # 가운데
print("{0:=^10}".format("hi"))  ====hi====  # 가운데 + 채우기

# 소수점
print("{0:.4f}".format(3.14159))  3.1416
f-string (Python 3.6+) ⭐ 권장
# 기본: 변수를 {} 안에 직접 삽입
name = "홍길동"
age  = 25
print(f"이름: {name}, 나이: {age}")
이름: 홍길동, 나이: 25

# {} 안에서 연산도 가능!
print(f"내년이면 {age + 1}살")   내년이면 26살

# 소수점 제어
pi = 3.141592
print(f"원주율: {pi:.2f}")        원주율: 3.14

# 정렬
print(f'{"hi":<10}|')           hi        |
print(f'{"hi":>10}|')                   hi|
print(f'{"hi":^10}|')               hi    |

# 천 단위 콤마 삽입
money = 1500000
print(f"잔액: {money:,}원")      잔액: 1,500,000원

# 딕셔너리 활용
student = {'name': '김철수', 'score': 95}
print(f"{student['name']}의 점수: {student['score']}점")
김철수의 점수: 95점
💡 f-string이 권장되는 이유가장 읽기 쉽고, 식(expression)을 직접 쓸 수 있으며, 속도도 가장 빠릅니다.

문자열 내장 함수

문자열 변수에 점(.)을 붙여 호출하는 함수들입니다. 원본 문자열은 변경되지 않고 처리 결과를 반환합니다.

.count()
특정 문자 개수 세기
.find()
위치 찾기 (없으면 -1)
.index()
위치 찾기 (없으면 오류)
.join()
사이에 문자 삽입
.upper()
대문자로 변환
.lower()
소문자로 변환
.strip()
양쪽 공백 제거
.replace()
문자열 교체
.split()
기준으로 분리 → 리스트
.isalpha()
알파벳만? True/False
.isdigit()
숫자만? True/False
.startswith()
특정 문자로 시작?
Python — 문자열 내장 함수 전체 예제
a = "Python is the best choice"

# count: 특정 문자 개수
print(a.count('t'))          3

# find: 위치 (없으면 -1 반환)
print(a.find('b'))           14
print(a.find('z'))           -1   # 없으면 -1

# index: 위치 (없으면 오류 발생!)
print(a.index('t'))          4

# join: 사이에 문자 삽입
print("-".join("ABCD"))       A-B-C-D
print(", ".join(["사과","바나나","포도"]))  사과, 바나나, 포도

# upper / lower
print("hello".upper())       HELLO
print("HELLO".lower())       hello

# strip / lstrip / rstrip: 공백 제거
s = "  hello  "
print(s.strip())              hello
print(s.lstrip())             hello  
print(s.rstrip())               hello

# replace: 문자열 교체
print("Life is short".replace("Life", "Your leg"))
Your leg is short

# split: 문자열 분리 → 리스트 반환
print("Life is too short".split())
['Life', 'is', 'too', 'short']
print("a:b:c:d".split(':'))
['a', 'b', 'c', 'd']

# 확인 함수들
print("Python".isalpha())     True
print("Python3".isalpha())    False  # 숫자 포함
print("12345".isdigit())      True
print("12.3".isdigit())       False  # 점(.) 포함
print("Life is short".startswith("Life"))   True
print("Life is short".endswith("short"))   True
⚠️ 중요: 원본은 변하지 않습니다 a.upper()를 해도 a의 값은 그대로입니다. 변경된 값을 사용하려면 반드시 변수에 재대입해야 합니다.
a = a.upper() ← 이렇게 해야 a가 바뀝니다.

예제 2 — 이메일 유효성 기본 검사

Python — 이메일 검사
emails = ["user@example.com", "badformat", "test@naver.com"]

for email in emails:
    has_at   = "@" in email
    has_dot  = email.endswith(".com") or email.endswith(".net")
    parts    = email.split("@")
    valid    = has_at and has_dot and len(parts) == 2
    status   = "✓ 유효" if valid else "✗ 오류"
    print(f"{email:25} → {status}")
user@example.com          → ✓ 유효
badformat                 → ✗ 오류
test@naver.com            → ✓ 유효

예제 3 — 이름 포맷 정리

Python — 이름 정규화
# 입력값이 지저분할 때 정리하기
raw_name = "  hong GIL dong  "

cleaned = raw_name.strip()            # 공백 제거
lower   = cleaned.lower()             # 소문자로
parts   = lower.split()               # 단어 분리
proper  = " ".join(p.capitalize() for p in parts)  # 첫 글자 대문자

print(f"원본:  '{raw_name}'")
print(f"정리:  '{proper}'")
원본:  '  hong GIL dong  '
정리:  'Hong Gil Dong'
