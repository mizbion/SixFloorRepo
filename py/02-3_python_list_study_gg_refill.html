01

리스트(List)란?

여러 값을 하나의 변수에 담는 자료형

📦
리스트 = 마법 상자
리스트는 대괄호 [ ] 로 만들고, 값들을 쉼표(,) 로 구분해요.
숫자, 문자열, 심지어 다른 리스트도 담을 수 있어요!
리스트 생성 
# 빈 리스트
a = []

# 숫자 리스트
scores = [85, 92, 78, 96, 70]

# 문자열 리스트
fruits = ['사과', '바나나', '포도', '딸기']

# 혼합 가능!
info = ['홍길동', 18, True]

print(len(scores))   # → 5  (요소 개수)
print(type(scores))  # → <class 'list'>
💡
리스트가 필요한 이유
학생 5명의 점수를 저장한다면?
s1=85, s2=92, s3=78... 변수 5개 → 불편!
scores=[85, 92, 78, 96, 70] 리스트 1개 → 깔끔! ✅
리스트 입력 (쉼표로 구분)
결과위 값을 바꾸고 눌러보세요
02

인덱싱 — 하나씩 꺼내기

리스트에서 원하는 요소를 꺼내는 방법

🔍
인덱스는 0부터 시작!
파이썬은 0부터 셉니다. a[0]이 첫 번째 요소예요.
음수 인덱스는 뒤에서부터: a[-1] = 마지막 요소
👆 아래 요소를 클릭해보세요!
요소를 클릭하면 인덱스 정보가 나타납니다
인덱싱 예제 
fruits = ['사과', '바나나', '포도', '딸기', '망고']

print(fruits[0])    # → '사과'   (첫 번째)
print(fruits[2])    # → '포도'   (세 번째)
print(fruits[-1])   # → '망고'   (마지막)
print(fruits[-2])   # → '딸기'   (뒤에서 두 번째)
⚠️
리스트는 수정 가능! (문자열과 다르게)
fruits[0] = '수박' → ✅ 가능!
인덱스 범위를 벗어나면 IndexError 가 발생해요.
리스트
인덱스 번호
결과인덱스를 입력하고 눌러보세요
✏️

03

슬라이싱 — 잘라내기

리스트의 일부를 한번에 꺼내는 방법

✂️
a[시작 : 끝] — 끝은 포함 안 됨!
a[1:4] → 1번, 2번, 3번 (4번은 미포함!)
a[:3] → 처음부터 2번까지  |  a[2:] → 2번부터 끝까지
슬라이싱 예제 
a = ['월', '화', '수', '목', '금', '토', '일']

print(a[0:5])   # → ['월', '화', '수', '목', '금']  평일!
print(a[5:])    # → ['토', '일']  주말!
print(a[:3])    # → ['월', '화', '수']
print(a[::-1])  # → ['일', '토', ... '월']  뒤집기!
리스트 (쉼표 구분)
시작
끝
결과값을 입력하고 눌러보세요
04

리스트 연산

더하기, 곱하기, 그리고 유용한 내장 함수들

➕
+ 연결 · * 반복 · in 포함 확인
리스트 연산 
a = [1, 2, 3]
b = [4, 5, 6]

print(a + b)          # → [1, 2, 3, 4, 5, 6]  연결!
print(a * 3)          # → [1, 2, 3, 1, 2, 3, 1, 2, 3]  반복!
print(3 in a)          # → True  (포함 확인)
print(9 not in a)      # → True  (없음 확인)

# 통계 함수
scores = [85, 92, 78, 96, 70]
print(len(scores))     # → 5      개수
print(sum(scores))     # → 421    합계
print(max(scores))     # → 96     최대
print(min(scores))     # → 70     최소
숫자 리스트 (쉼표 구분)
결과숫자 리스트를 입력하고 눌러보세요
