if문 기본 구조

조건이 참(True)일 때만 실행되는 블록

🔀 if문이란?

if 조건: 다음 줄에 들여쓰기(4칸 또는 Tab)로 실행할 코드를 작성합니다.
조건이 True면 실행, False면 건너뜁니다.
시작
↓
조건식 (score >= 60)
True ✓
↓
print("합격")
False ✗
↓
(건너뜀)
↓
계속 실행
기본 if문
# 기본 if문 구조
score = 75

if score >= 60:
    print("합격입니다! 🎉")

# → 합격입니다! 🎉
⚠️
들여쓰기(indentation) 필수!
파이썬은 들여쓰기로 코드 블록을 구분합니다. if 아래 실행할 코드는 반드시 4칸 들여쓰기해야 합니다.

📝 다양한 if문 예제

예제 1 — 용돈
money = 5000

if money >= 3000:
    print("편의점 갈 수 있어!")

# → 편의점 갈 수 있어!
예제 2 — 나이
age = 18

if age >= 18:
    print("성인입니다")

# → 성인입니다
예제 3 — 비밀번호
pw = "python123"
input_pw = "python123"

if pw == input_pw:
    print("로그인 성공!")

# → 로그인 성공!
예제 4 — 배터리
battery = 15

if battery <= 20:
    print("충전하세요! 🔋")

# → 충전하세요! 🔋

비교 연산자

두 값을 비교해 True / False 반환

⚖️ 6가지 비교 연산자

연산자의미예시결과
==같다5 == 5True
!=다르다5 != 3True
>크다7 > 3True
<작다2 < 8True
>=크거나 같다5 >= 5True
<=작거나 같다4 <= 4True
비교 연산자 활용
a = 10;  b = 7

print(a == b)   # → False
print(a != b)   # → True
print(a >  b)   # → True
print(a >= 10)  # → True
💡
= vs == 헷갈리지 마세요!
=은 변수에 값을 저장, ==은 두 값이 같은지 비교합니다.

elif & else

여러 조건을 순서대로 검사하기

🌿 if - elif - else 구조

if → 첫 번째 조건 검사
elif → 앞 조건이 False일 때 다음 조건 검사 (여러 개 가능)
else → 위 모든 조건이 False일 때 실행
성적 등급 판별
score = 78

if score >= 90:
    print("A등급 🏆")
elif score >= 80:
    print("B등급 🥈")
elif score >= 70:
    print("C등급 🥉")
else:
    print("D등급 📚")

# → C등급 🥉
✅
조건은 위에서 아래로 순서대로 검사합니다. 첫 번째로 True인 조건의 블록만 실행되고 나머지는 모두 건너뜁니다.

📝 elif/else 다양한 예제

요일 판별
day = "토"

if day == "토" or day == "일":
    print("주말이에요! 😄")
else:
    print("평일이에요 😅")

# → 주말이에요! 😄
BMI 판별
bmi = 22.5

if bmi < 18.5:
    print("저체중")
elif bmi < 25:
    print("정상 체중 ✅")
else:
    print("과체중")

# → 정상 체중 ✅
편의점 할인 시스템
price = 8500
member = True

if price >= 10000 and member:
    discount = 0.15
    print("회원 1만원 이상 → 15% 할인")
elif price >= 5000 and member:
    discount = 0.10
    print("회원 5천원 이상 → 10% 할인")
else:
    discount = 0
    print("할인 없음")

print(f"최종 가격: {price * (1 - discount):.0f}원")
# → 회원 5천원 이상 → 10% 할인
# → 최종 가격: 7650원

논리 연산자

and / or / not 으로 조건 결합하기

🔗 and / or / not

연산자의미결과가 True인 경우
and그리고양쪽 조건이 모두 True
or또는양쪽 조건 중 하나라도 True
not부정조건이 False일 때
and 예제
score = 85
attend = True

if score >= 70 and attend:
    print("장학금 대상!")
# 성적도 좋고 출석도 해야 함
# → 장학금 대상!
or 예제
lang = "Python"

if lang == "Python" or \
   lang == "Java":
    print("개발 언어 맞음")
# 둘 중 하나면 OK
# → 개발 언어 맞음
not 예제 + 실전 조합
is_raining = False
has_umbrella = True

if not is_raining:
    print("우산 없어도 괜찮아요! ☀️")

if is_raining and not has_umbrella:
    print("우산을 사세요 ☔")
else:
    print("걱정 없어요 😊")

# → 우산 없어도 괜찮아요! ☀️
# → 걱정 없어요 😊

중첩 if & in 연산자

if 안에 if, 그리고 멤버십 검사

📦 중첩 if (Nested if)

if 블록 안에 또 다른 if를 넣을 수 있습니다. 들여쓰기 단계마다 4칸씩 더 들여씁니다.
놀이공원 입장 시스템
age = 17
height = 165

if age >= 13:            # 1단계: 나이 확인
    if height >= 140:     # 2단계: 키 확인
        print("모든 놀이기구 탑승 가능! 🎢")
    else:
        print("키가 140cm 이상이어야 합니다")
else:
    print("13세 이상만 입장 가능합니다")

# → 모든 놀이기구 탑승 가능! 🎢
💜
중첩이 3단계 이상 깊어지면 코드 읽기가 어려워집니다. 가능하면 and로 조건을 합치는 것이 더 좋습니다.

🔍 in / not in 연산자

리스트, 튜플, 문자열 안에 값이 있는지 / 없는지 확인합니다.
리스트에서 in
menu = ["떡볶이", "순대", "튀김"]
order = "순대"

if order in menu:
    print(f"{order} 주문 완료! ✅")
else:
    print("메뉴에 없어요")

# → 순대 주문 완료! ✅
문자열에서 in
email = "student@school.kr"

if "@" in email:
    print("유효한 이메일 ✅")
else:
    print("이메일 형식 오류 ❌")

# → 유효한 이메일 ✅
not in 예제
banned = ["욕설1", "욕설2", "스팸"]
msg = "안녕하세요!"

if msg not in banned:
    print("메시지 전송 완료 📨")
else:
    print("금지된 메시지입니다")

# → 메시지 전송 완료 📨
