숫자형 (int · float)

정수, 실수, 그리고 자주 쓰는 연산자를 짧게 복습해요

🔢
int vs float — 차이가 뭐야?
정수형 (int): 소수점 없는 숫자  1 -5 100
실수형 (float): 소수점 있는 숫자  3.14 -0.5 1.0
⚠️ 나눗셈 / 은 결과가 항상 float!
int / float 확인 
a = 10
b = 3

print(type(a))       # → <class 'int'>
print(type(3.14))    # → <class 'float'>
print(a / b)         # → 3.3333...  (float!)
print(a // b)        # → 3          (몫, int)
print(type(a / b))   # → <class 'float'>

인덱싱 — 한 글자 꺼내기
파이썬은 0부터 셉니다. 음수 인덱스는 뒤에서부터!
a[0] → 첫 글자  |  a[-1] → 마지막 글자
아래 글자를 클릭해보세요 👇
글자를 클릭하면 인덱스가 표시됩니다
인덱싱 
a = "Python"

print(a[0])    # → P  (첫 번째)
print(a[1])    # → y
print(a[-1])   # → n  (마지막)
print(a[-2])   # → o  (뒤에서 두 번째)
단어 입력
인덱스 번호
결과인덱스를 입력하고 눌러보세요

슬라이싱 — 일부 잘라내기
a[시작:끝] — 끝 인덱스는 포함하지 않아요!
a[:3] → 처음~2번  |  a[3:] → 3번~끝  |  a[:] → 전체
슬라이싱 핵심 예제 
a = "Python"

print(a[0:3])   # → Pyt  (0,1,2번 — 3 미포함)
print(a[2:])    # → thon (2번부터 끝)
print(a[:4])    # → Pyth (처음부터 3번)
print(a[::-1])  # → nohtyP (뒤집기!)

f-string — 변수를 문자열 안에!
f-string: 문자열 앞에 f를 붙이고, 변수는 {변수명}으로!
중괄호 안에서 계산식도 바로 쓸 수 있어요.
f-string 활용 
name = "홍길동"
age  = 18
score = 87.5

print(f"이름: {name}")                  # → 이름: 홍길동
print(f"나이: {age}살")                  # → 나이: 18살
print(f"내년이면 {age + 1}살")           # → 내년이면 19살
print(f"점수: {score:.1f}점")            # → 점수: 87.5점

자주 쓰는 문자열 메서드
문자열 메서드 
a = "  Hello Python  "

a.upper()         # → "  HELLO PYTHON  " (대문자)
a.lower()         # → "  hello python  " (소문자)
a.strip()         # → "Hello Python"     (앞뒤 공백 제거)
a.replace("Hello", "Hi")  # → "  Hi Python  "
a.split()         # → ['Hello', 'Python'] (공백 기준 분리)
len(a)            # → 18 (전체 길이)
"Python" in a    # → True (포함 여부)
