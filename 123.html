출력(print) 실습

print() 함수의 다양한 사용법을 배워봅시다

총 10개
P1 첫 번째 출력 print()
가장 기본적인 출력입니다. print() 안에 큰따옴표나 작은따옴표로 텍스트를 감싸면 화면에 출력됩니다.
Python
print("안녕하세요, 파이썬!")
▶ 출력 결과
안녕하세요, 파이썬!
P2 여러 줄 출력
print()를 여러 번 쓰면 줄이 바뀌면서 차례로 출력됩니다.
Python
print("이름: 홍길동")
print("나이: 17살")
print("학교: 미래고등학교")
▶ 출력 결과
이름: 홍길동
나이: 17살
학교: 미래고등학교
P3 구분선 만들기 * 반복
문자열에 * 숫자를 곱하면 그 문자를 여러 번 반복합니다. 구분선을 만들 때 자주 씁니다.
Python
print("=" * 30)
print("   환영합니다!")
print("=" * 30)
▶ 출력 결과
==============================
   환영합니다!
==============================
P4 이어서 출력하기 end=""
print()는 기본적으로 줄바꿈을 합니다. end=""를 추가하면 줄바꿈 없이 이어서 출력합니다.
Python
print("하나", end=" ")
print("둘", end=" ")
print("셋")
▶ 출력 결과
하나 둘 셋
💡 end="\n"이 기본값(줄바꿈)입니다. end=""로 바꾸면 줄바꿈이 사라져요.
P5 여러 값 한번에 출력 쉼표
print() 안에 쉼표(,)로 값을 여러 개 쓰면 자동으로 공백을 사이에 넣어서 출력합니다.
Python
print("이름:", "김파이")
print("나이:", 20)
print("점수:", 95, "점")
▶ 출력 결과
이름: 김파이
나이: 20
점수: 95 점
P6 구분자 바꾸기 sep=
쉼표로 여러 값을 출력할 때 사이에 넣을 구분자를 sep=으로 직접 지정할 수 있습니다.
Python
print("2025", "07", "15", sep="-")
print("010", "1234", "5678", sep="-")
▶ 출력 결과
2025-07-15
010-1234-5678
P7 변수 출력하기
변수에 값을 저장한 뒤 print()로 출력할 수 있습니다. 변수는 따옴표 없이 씁니다.
Python
이름 = "이파이"
나이 = 18
print(이름)
print(나이)
▶ 출력 결과
이파이
18
💡 변수는 데이터를 저장하는 상자예요. = 기호로 값을 넣습니다.
P8 f-string으로 출력 f"..."
따옴표 앞에 f를 붙이고 {변수}를 쓰면 변수 값이 자동으로 들어갑니다.
Python
이름 = "박코딩"
나이 = 17
print(f"안녕하세요! 저는 {이름}이고, {나이}살입니다.")
▶ 출력 결과
안녕하세요! 저는 박코딩이고, 17살입니다.
💡 {} 중괄호 안에 변수명을 쓰면 그 자리에 값이 들어가요.
P9 숫자 계산 결과 출력
print() 안에서 바로 사칙연산을 할 수 있습니다. 숫자에는 따옴표를 붙이지 않습니다.
Python
print(10 + 5)   # 더하기
print(10 - 3)   # 빼기
print(4  * 3)   # 곱하기
print(10 / 2)   # 나누기
▶ 출력 결과
15
7
12
5.0
P10 이모지로 꾸민 출력
이모지와 특수문자를 자유롭게 사용해서 출력 결과를 예쁘게 꾸밀 수 있습니다.
Python
print("🌟 오늘의 메뉴 🌟")
print("─" * 16)
print("🍕 피자")
print("🍜 라면")
print("🧃 주스")
print("─" * 16)
▶ 출력 결과
🌟 오늘의 메뉴 🌟
────────────────
🍕 피자
🍜 라면
🧃 주스
────────────────

입력(input) 실습

input() 함수로 사용자에게 값을 받아봅시다

총 10개
I1 첫 번째 입력 input()
input()을 실행하면 입력 대기 상태가 됩니다. 사용자가 입력하고 Enter를 누르면 그 값을 변수에 저장합니다.
Python
이름 = input("이름을 입력하세요: ")
print("안녕하세요,", 이름)
▶ 실행 예시 (입력: 김철수)
이름을 입력하세요: 김철수
안녕하세요, 김철수
💡 input() 괄호 안의 문자열은 사용자에게 보여주는 안내문입니다.
I2 입력값 f-string으로 출력
입력받은 값을 f-string과 함께 사용하면 더 자연스러운 문장을 만들 수 있습니다.
Python
이름 = input("이름: ")
학교 = input("학교: ")
print(f"반갑습니다! {이름}님은 {학교} 학생이군요!")
▶ 실행 예시
이름: 이수진
학교: 한빛고등학교
반갑습니다! 이수진님은 한빛고등학교 학생이군요!
I3 여러 항목 입력받기
input()을 여러 번 사용하면 여러 정보를 순서대로 입력받을 수 있습니다.
Python
이름 = input("이름: ")
나이 = input("나이: ")
취미 = input("취미: ")
print()
print("=== 입력한 정보 ===")
print(f"이름: {이름} / 나이: {나이} / 취미: {취미}")
▶ 실행 예시
이름: 장민준
나이: 16
취미: 농구

=== 입력한 정보 ===
이름: 장민준 / 나이: 16 / 취미: 농구
I4 숫자로 변환하기 int()
input()은 항상 문자열(str)을 반환합니다. 숫자로 계산하려면 int()로 변환해야 합니다.
Python
나이 = int(input("나이를 입력하세요: "))
내년나이 = 나이 + 1
print(f"내년에는 {내년나이}살이 됩니다!")
▶ 실행 예시
나이를 입력하세요: 17
내년에는 18살이 됩니다!
💡 int(input(...)) 처럼 input()을 int()로 바로 감싸면 한 번에 변환됩니다.
I5 두 수 더하기
두 숫자를 입력받아 합계를 계산합니다. 두 값 모두 int()로 변환해야 덧셈이 됩니다.
Python
a = int(input("첫 번째 숫자: "))
b = int(input("두 번째 숫자: "))
print(f"{a} + {b} = {a + b}")
▶ 실행 예시
첫 번째 숫자: 23
두 번째 숫자: 47
23 + 47 = 70
I6 문자열은 그냥 붙여쓰기 str 연결
input()의 반환값은 문자열이라서, 변환 없이 +로 연결하면 숫자가 아닌 문자열로 붙습니다. 아래를 비교해보세요.
Python
a = input("숫자 입력: ")   # str로 저장됨
b = input("숫자 입력: ")   # str로 저장됨
print("str 연결:", a + b)               # 문자 붙이기
print("int 계산:", int(a) + int(b))   # 숫자 더하기
▶ 실행 예시 (입력: 3, 5)
숫자 입력: 3
숫자 입력: 5
str 연결: 35
int 계산: 8
💡 input()은 항상 문자열! 계산하려면 꼭 int()로 바꾸세요.
I7 자기소개 프로그램
여러 입력을 받아 자기소개를 예쁘게 출력합니다. 지금까지 배운 내용의 종합 예제입니다.
Python
print("=== 자기소개 ===")
이름   = input("이름: ")
나이   = input("나이: ")
취미   = input("취미: ")
좋아하는것 = input("좋아하는 것: ")
print()
print(f"안녕하세요! 저는 {이름}이고 {나이}살입니다.")
print(f"취미는 {취미}이고, {좋아하는것}을(를) 좋아해요!")
▶ 실행 예시
=== 자기소개 ===
이름: 최유리
나이: 16
취미: 독서
좋아하는 것: 고양이

안녕하세요! 저는 최유리이고 16살입니다.
취미는 독서이고, 고양이을(를) 좋아해요!
I8 태어난 연도 계산
나이를 입력받아 태어난 연도를 계산합니다. int() 변환과 사칙연산을 함께 사용합니다.
Python
나이     = int(input("나이를 입력하세요: "))
올해     = 2025
태어난해 = 올해 - 나이
print(f"태어난 연도는 약 {태어난해}년입니다.")
▶ 실행 예시
나이를 입력하세요: 18
태어난 연도는 약 2007년입니다.
I9 간단한 주문 프로그램
메뉴와 수량을 입력받아 주문 내역을 출력합니다. 단가 × 수량으로 금액을 계산합니다.
Python
print("☕ 카페 주문")
메뉴   = input("메뉴 이름: ")
단가   = int(input("단가(원): "))
수량   = int(input("수량: "))
금액   = 단가 * 수량
print(f"주문: {메뉴} × {수량}잔 = {금액}원")
▶ 실행 예시
☕ 카페 주문
메뉴 이름: 아메리카노
단가(원): 4500
수량: 3
주문: 아메리카노 × 3잔 = 13500원
I10 나만의 명함 만들기
입력한 정보를 바탕으로 명함 형식으로 출력하는 종합 예제입니다.
Python
이름 = input("이름: ")
학교 = input("학교: ")
꿈   = input("장래희망: ")
한마디 = input("한마디: ")

print()
print("┌" + "─" * 28 + "┐")
print(f"│  🪪  {이름:<22}│")
print(f"│  🏫  {학교:<22}│")
print(f"│  🚀  {꿈:<22}│")
print(f"│  💬  {한마디:<22}│")
print("└" + "─" * 28 + "┘")
▶ 실행 예시
이름: 정하늘
학교: 창의고등학교
장래희망: 게임 개발자
한마디: 열심히 하겠습니다!

┌────────────────────────────┐
│  🪪  정하늘                │
│  🏫  창의고등학교          │
│  🚀  게임 개발자           │
│  💬  열심히 하겠습니다!    │
└────────────────────────────┘
💡 {변수:<22} 는 왼쪽 정렬 후 22칸을 채우는 포맷입니다. 명함 테두리를 맞추는 데 유용해요.
