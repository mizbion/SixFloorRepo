프롬프트 엔지니어링 기술 활용

출제 비중 40%, 가장 중요한 과목입니다. N-shot·CoT 같은 프롬프트 기법, 모델 실습(텍스트·코드·이미지·데이터), 확장 프로그램이 집중 출제됩니다.

🎯 학습목표

  1. N-shot(Zero/One/Few-shot)과 생각의 사슬(CoT) 기법을 구분한다
  2. 멀티모달 프롬프트와 프로그래밍 언어 식별법을 안다
  3. 이미지 생성 AI 3종의 업무 활용 작성법을 구분한다
  4. 데이터 시각화 8종의 용도를 안다
  5. 주요 확장 프로그램(AIPRM·WebChatGPT·DeepL·SlidesAI)의 기능을 안다
1. N-shot 프롬프팅 (최빈출!)

프롬프트 안에 예시(shot)를 몇 개 넣느냐에 따라 나뉩니다. 예시 개수가 핵심입니다.

기법예시 개수설명
Zero-shot
제로샷		0개예시 없이 작업 설명만으로 결과 생성
One-shot
원샷		1개입력-출력 예시 1개로 작업 패턴 제시
Few-shot
퓨샷		2~10개소수 예시로 맥락·패턴을 명확히 전달
⚠️ 암기 필수: Zero=0개, One=1개, Few=2~10개. 예시 개수를 바꿔 출제합니다.
2. 생각의 사슬 (CoT, Chain of Thought)

복잡한 문제를 작은 단위로 나눠 순차적으로(단계별로) 해결하게 하는 기법입니다.

특징설명
체계성복잡한 문제를 논리적 단계로 구조화
명확성각 단계별 목표·실행 방안을 구체적으로 제시
💡 트리거 문장: "단계별로 생각해 보자(Let's think step by step)"를 붙이면 CoT가 작동합니다. 수학·논리 문제에서 정확도가 올라갑니다.
3. 멀티모달 프롬프트

둘 이상의 데이터 유형(텍스트·이미지·오디오·비디오 등)을 결합한 프롬프트입니다. 단일 모달보다 풍부한 정보·맥락을 제공해 더 정확한 결과를 얻습니다.

💡 포인트: "이미지 + 텍스트를 함께 입력" 같은 게 멀티모달. 'multi(여러) + modal(양식)'.

AI-POT 4과목 단골 함정 9가지

🪤 함정 1. N-shot 예시 개수

Zero=0, One=1, Few=2~10개. "Few-shot은 예시 1개"라고 하면 오답(그건 One-shot).

🪤 함정 2. CoT 트리거 문장

"단계별로 생각해 보자"가 CoT의 트리거. 단순 분류·요약과 혼동시킵니다.

🪤 함정 3. 프로그래밍 언어 단서

Python=if __name__, JSON=중괄호, HTML=태그, Java=// 주석. 단서를 바꿔 출제.

🪤 함정 4. 확장 프로그램 기능

AIPRM(프롬프트), WebChatGPT(웹검색), DeepL(번역), SlidesAI(PPT). 기능 뒤바꾸기 주의.

🪤 함정 5. 시각화 용도

비율=파이, 분포=히스토그램, 상관=산점도, 값 농도=히트맵. 용도를 섞어 출제.

🪤 함정 6. 이미지 AI 작성법

미드저니=키워드+파라미터, SD=긴 묘사+네거티브, 달리=스타일·의도. 작성법을 뒤바꿈.

🪤 함정 7. 멀티모달 정의

'둘 이상의 데이터 유형 결합'이 핵심. 텍스트만 쓰면 단일 모달.

🪤 함정 8. Zero-shot ≠ 학습 안 함

Zero-shot은 '예시를 안 줌'이지 '학습을 안 함'이 아닙니다. 모델은 이미 사전학습됨.

🪤 함정 9. DALL·E 어원

DALL·E = 화가 살바도르 '달리' + 픽사 로봇 '월-E'의 합성어. 어원을 묻기도 합니다.

개념 복습
미드저니=키워드+파라미터, SD=긴 묘사+네거티브, 달리=스타일·의도.
