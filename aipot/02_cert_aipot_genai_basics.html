1. 생성형 AI와 LLM

생성형 AI는 기존 데이터를 학습한 뒤 글·사진·음성·영상 등 새로운 콘텐츠를 창작하는 AI입니다. 그중 텍스트 기반이 LLM(거대 언어 모델)으로, 수십억~수천억 개의 파라미터를 가집니다.

💡 LLM 핵심: 방대한 데이터셋으로 학습 + 입력 텍스트에 자연스러운 응답 생성 + 대규모 파라미터. GPT가 대표적입니다.
2. 생성형 AI의 한계 — 환각과 편향성
현상정의대표 사례
환각
Hallucination		실재하지 않는 정보를 그럴듯하게 생성미국 법원 가짜 판례 인용 / 메타 갤럭티카 폐쇄
편향성
Bias		학습 데이터에 내재된 사회·문화적 편향을 그대로 반영아마존 채용 AI 성차별 / COMPAS 인종차별
⚠️ 출제 포인트: 사례와 현상을 짝짓는 문제가 나옵니다. "가짜 판례=환각", "채용 차별=편향성"으로 묶어 외우세요.
3. 자연어 처리(NLP)의 4단계

인간 언어를 컴퓨터가 이해·처리하는 기술. 순서가 시험에 나옵니다.

4. 모델 아키텍처 — 트랜스포머·GPT·BERT
모델구조특징
트랜스포머인코더-디코더병렬처리 가능, 어텐션 메커니즘 기반
GPT디코더만자기회귀적(앞→뒤 순차 생성)
BERT인코더만양방향 문맥 이해 특화
💡 암기: "GPT = 디코더(Generate, 생성)", "BERT = 인코더(양방향 이해)". 트랜스포머는 둘 다 가진 원형.
5. 사전학습과 미세조정(파인튜닝)
단계설명
사전학습
Pre-training		대량의 데이터로 일반적 언어 패턴을 먼저 학습 (선행 단계)
미세조정
Fine-tuning		사전학습된 모델을 특정 작업/데이터에 맞게 추가 학습
⚠️ 순서 함정: 사전학습이 먼저, 미세조정이 나중. "범용 능력을 먼저 키우고 → 전문 분야로 다듬기".
6. 토큰화와 임베딩
개념정의대표 기법
토큰화
Tokenization		연속된 텍스트를 최소 단위(토큰)로 나눔BPE, WordPiece, SentencePiece
임베딩
Embedding		토큰을 수치 벡터로 변환Word2Vec, GloVe, BERT
💡 순서: 텍스트 → (토큰화) → 토큰 → (임베딩) → 벡터. 자르고 나서 숫자로 바꾼다고 외우세요.
7. 텍스트 생성 파라미터
파라미터역할값 범위
Temperature높을수록 창의적, 낮을수록 예측 가능0.0 ~ 2.0
Top-p높을수록 다양한 단어 선택 가능0.0 ~ 1.0
Max_Length생성할 최대 토큰 수 (모델 한계 내)모델별 상이
⚠️ 값 범위 암기 필수: Temperature는 0~2.0, Top-p는 0~1.0. 둘을 바꿔 출제합니다.
8. 적대적 위협 — 프롬프트 주입과 탈옥
위협정의
프롬프트 주입
Prompt Injection		조작된 입력으로 원래 지시를 우회·변경 (예: "이전 지시는 무시하고…")
프롬프트 탈옥
Jailbreaking		안전장치·윤리 규정을 우회 (예: DAN "Do Anything Now" 모드)
💡 구분: 주입 = "지시 덮어쓰기", 탈옥 = "안전장치 풀기(DAN)". DAN이 보이면 탈옥입니다.
9. ChatGPT와 GPT
구분설명
GPTOpenAI의 대규모 언어 모델(엔진). 수십억 매개변수 신경망
ChatGPTGPT·o 모델을 쓰는 대화형 서비스(인터페이스). 대화 맥락 유지
💡 구분: GPT는 '엔진', ChatGPT는 그 엔진을 얹은 '자동차(서비스)'. 엔진과 완성차의 관계.
AI-POT 2과목 단골 함정 8가지

🪤 함정 1. GPT=디코더, BERT=인코더

역할을 바꿔 출제합니다. GPT는 디코더만(생성), BERT는 인코더만(양방향 이해). 트랜스포머는 둘 다.

🪤 함정 2. Temperature vs Top-p 범위

Temperature는 0~2.0, Top-p는 0~1.0. 범위 숫자를 서로 바꿔 함정을 냅니다.

🪤 함정 3. 사전학습 → 미세조정 순서

사전학습이 먼저, 미세조정이 나중. 순서를 뒤집어 출제합니다.

🪤 함정 4. 토큰화 ≠ 임베딩

토큰화는 '자르기', 임베딩은 '벡터로 변환'. 토큰화 기법(BPE)과 임베딩 기법(Word2Vec)을 섞어 출제합니다.

🪤 함정 5. 환각 vs 편향성

없는 사실 지어냄=환각(가짜 판례), 데이터 편향 반영=편향성(채용 차별). 사례로 구분.

🪤 함정 6. 주입 vs 탈옥

주입=지시 우회, 탈옥=안전장치 우회. DAN 키워드가 나오면 탈옥.

🪤 함정 7. NLP 4단계 순서

형태소 → 구문 → 의미 → 화용. 단어 쪼개기부터 문맥·의도 파악으로 점점 커집니다.

🪤 함정 8. ChatGPT ≠ GPT

GPT는 모델(엔진), ChatGPT는 서비스(인터페이스). 같은 것으로 묶는 보기 주의.

Q1
기존 데이터를 학습한 뒤 글·이미지·음성 등 새로운 콘텐츠를 창작하는 AI를 무엇이라 하는가?
  • ① 검색 엔진
  • ② 생성형 AI
  • ③ 규칙 기반 시스템
  • ④ 전문가 시스템
정답 ②
생성형 AI
개념 복습
생성형 AI는 학습한 데이터를 바탕으로 새로운 콘텐츠를 창작합니다. 검색 엔진은 기존 정보를 찾아줄 뿐 창작하지 않습니다.

Q2
LLM(거대 언어 모델)에 대한 설명으로 옳지 않은 것은?
  • ① 텍스트 기반 생성형 AI이다
  • ② 수십억~수천억 개의 파라미터를 가진다
  • ③ 정해진 IF-THEN 규칙으로만 응답한다
  • ④ 입력에 자연스러운 응답을 생성한다
정답 ③
IF-THEN은 규칙 기반 시스템

LLM은 방대한 데이터로 학습해 확률적으로 응답을 생성합니다. IF-THEN 규칙으로 동작하는 건 규칙 기반 시스템(1과목)입니다.
암기 팁
LLM 3요소: 방대한 데이터 + 자연스러운 응답 + 대규모 파라미터.
Q3
실재하지 않는 정보를 그럴듯하게 생성하는 현상은? (예: 가짜 판례 인용 사건)
  • ① 환각(Hallucination)
  • ② 편향성(Bias)
  • ③ 과적합
  • ④ 토큰화
정답 ①
환각
개념 복습
환각은 없는 사실을 진짜처럼 지어내는 것. 미국 법원 가짜 판례, 메타 갤럭티카 폐쇄가 대표 사례입니다.
암기 팁
"없는 걸 지어냄 = 환각". 가짜 판례 키워드가 보이면 환각.
Q4
아마존 채용 AI의 성차별, COMPAS의 인종차별 사례와 관련된 생성형 AI의 한계는?
  • ① 환각
  • ② 편향성
  • ③ 과소적합
  • ④ 프롬프트 주입
정답 ②
편향성
개념 복습
편향성은 학습 데이터에 내재된 사회·문화적 편향을 AI가 그대로 학습·반영하는 것. 채용·사법 차별 사례가 대표적입니다.
암기 팁
"차별 사례 = 편향성, 거짓 정보 = 환각".
Q5
자연어 처리(NLP)의 4단계 순서로 옳은 것은?
  • ① 의미 → 구문 → 형태소 → 화용
  • ② 구문 → 형태소 → 화용 → 의미
  • ③ 화용 → 의미 → 구문 → 형태소
  • ④ 형태소 → 구문 → 의미 → 화용
정답 ④
형태소 → 구문 → 의미 → 화용
개념 복습
가장 작은 단위(형태소)부터 시작해 문장 구조(구문), 뜻(의미), 맥락·의도(화용)로 점점 범위가 커집니다.
암기 팁
"형-구-의-화". 작은 것 → 큰 것 순서.
Q6
트랜스포머의 '디코더만'을 활용하며 자기회귀적 방식으로 텍스트를 생성하는 모델은?
  • ① GPT
  • ② BERT
  • ③ CNN
  • ④ RNN
정답 ①
GPT (디코더만)
개념 복습
GPT는 트랜스포머의 디코더만 써서 앞 단어로 다음 단어를 순차 생성(자기회귀). BERT는 인코더만 써서 양방향 문맥을 이해합니다.
암기 팁
"GPT=디코더=생성, BERT=인코더=이해".
Q7
BERT에 대한 설명으로 옳은 것은?
  • ① 트랜스포머의 디코더만 사용한다
  • ② 자기회귀적으로 텍스트를 생성한다
  • ③ 인코더만 활용하며 양방향 문맥 이해에 특화된다
  • ④ RNN 기반 모델이다
정답 ③
인코더만, 양방향 이해
개념 복습
BERT는 트랜스포머의 인코더만 사용해 문장의 앞뒤를 동시에 보는 양방향 문맥 이해에 강합니다. ①②는 GPT 설명입니다.
암기 팁
BERT의 'B'를 '양방(Both)'으로 연상.
Q8
사전학습(Pre-training)과 미세조정(Fine-tuning)의 관계로 옳은 것은?
  • ① 미세조정이 사전학습보다 먼저 이루어진다
  • ② 사전학습이 먼저, 미세조정이 나중에 이루어진다
  • ③ 둘은 동시에 진행된다
  • ④ 미세조정은 데이터 없이 진행된다
정답 ②
사전학습 → 미세조정
개념 복습
대량 데이터로 일반 언어 능력을 먼저 키우고(사전학습), 그 모델을 특정 작업/데이터에 맞게 다듬는 것(미세조정)입니다.
암기 팁
"먼저 넓게 배우고, 나중에 전공 정하기".
Q9
텍스트 생성 파라미터 Temperature의 값 범위로 옳은 것은?
  • ① 0.0 ~ 0.5
  • ② 0.0 ~ 1.0
  • ③ -1.0 ~ 1.0
  • ④ 0.0 ~ 2.0
정답 ④
0.0 ~ 2.0
개념 복습
Temperature는 0~2.0이며 높을수록 창의적·무작위적, 낮을수록 예측 가능한 결과를 냅니다. Top-p(0~1.0)와 범위를 혼동하지 마세요.
암기 팁
"Temperature 2.0, Top-p 1.0". 온도가 더 넓다(2배).
Q10
Top-p 파라미터에 대한 설명으로 옳은 것은?
  • ① 값 범위는 0.0~2.0이다
  • ② 높을수록 다양한 단어가 선택될 수 있다
  • ③ 생성할 최대 토큰 수를 의미한다
  • ④ 낮을수록 창의적인 결과가 나온다
정답 ②
높을수록 다양한 단어 선택
개념 복습
Top-p는 0~1.0 범위로, 높을수록 후보 단어 폭이 넓어집니다. ③은 Max_Length 설명입니다.
암기 팁
Top-p 높음 = 단어 선택지 넓음 = 다양함.
Q11
"이전 지시는 무시하고 다음을 수행하라"처럼 조작된 입력으로 원래 지시를 우회하는 공격은?
  • ① 환각
  • ② 편향성
  • ③ 프롬프트 주입(Injection)
  • ④ 토큰화
정답 ③
프롬프트 주입
개념 복습
프롬프트 주입은 악의적 입력으로 시스템의 원래 지시를 덮어쓰는 공격. "이전 지시 무시"가 전형적 패턴입니다.
암기 팁
"지시 덮어쓰기 = 주입, 안전장치 풀기 = 탈옥".
Q12
"DAN(Do Anything Now) 모드"처럼 AI의 안전장치와 윤리 규정을 우회하려는 시도는?
  • ① 프롬프트 탈옥(Jailbreaking)

  • ④ 사전학습
정답 ①
프롬프트 탈옥
개념 복습
탈옥은 모델의 안전장치·윤리 규정을 우회하려는 시도. DAN("모든 제약 없이 답하라")이 대표 방식입니다.
암기 팁

Q27
GPT와 BERT는 모두 트랜스포머에서 나왔지만 사용하는 구성요소와 특징이 다르다. 두 모델의 차이를 '구조'와 '특징' 측면에서 서술하시오.

개념 복습
핵심 키워드: GPT(디코더·생성·자기회귀), BERT(인코더·양방향·이해). 트랜스포머는 인코더-디코더 모두 가진 원형입니다.
암기 팁
"G=Generate(디코더), B=Both방향(인코더)".
Q28
'토큰화'와 '임베딩'은 생성형 AI가 텍스트를 처리하는 연속된 두 단계이다. 각각이 무엇이며 어떤 순서로 일어나는지 서술하시오.
모범답안
토큰화는 텍스트를 최소 단위(토큰)로 나누는 과정이고, 임베딩은 그 토큰을 수치 벡터로 변환하는 과정이다. 순서는 토큰화 → 임베딩이다.
개념 복습
텍스트 → (토큰화) → 토큰 → (임베딩) → 벡터. 토큰화 기법은 BPE 등, 임베딩 기법은 Word2Vec 등입니다.
암기 팁
"자르고 나서 숫자로 바꾼다".

암기 팁
"주입=지시 바꾸기, 탈옥=규정 풀기".
