💡 중요성: ① AI 활용 효율 극대화 ② 결과물 정확도·품질 향상 ③ 불필요한 반복 작업 감소
2. 프롬프트의 5대 구성요소 (최빈출!)

이 5가지는 이름·역할·순서를 모두 외워야 합니다. 가장 자주 나오는 단답·객관식 소재입니다.

구성요소역할
지시 (Instruction)명확한 지시와 요구사항 전달
맥락 (Context)배경 정보와 관련 상황 제공
입력 (Input Data)처리할 구체적인 데이터
제약조건 (Constraint)생성 결과물의 제한사항 설정
출력형식 (Output Format)원하는 결과물의 형태
⚠️ 암기: 지·맥·입·제·출 (지시-맥락-입력-제약-출력). 영문 첫 글자 I·C·I·C·O.

4. 합성 데이터 (Synthetic Data)

실제 데이터를 모방하지만 실제 인간의 데이터는 포함하지 않는 인공 데이터입니다. 예: 엑셀 파일을 올려 머리말·내용의 '형태'만 학습시키고 가상 데이터 출력을 지시하는 것.

💡 포인트: "실제 데이터를 닮았지만 진짜 개인정보는 없는 가짜 데이터" = 합성 데이터. 개인정보 보호에 활용됩니다.

7. 명확성과 구체성의 원칙
원칙요소
명확성모호함 제거 + 직접적 지시 + 일관적 용어
구체성상세한 정보 + 정량적 표현 + 예시와 사례
💡 구분: 명확성=헷갈리지 않게(모호함 제거), 구체성=자세하게(숫자·예시). 둘은 짝이지만 다릅니다.
8. 구분기호 (Delimiter)

프롬프트를 구조적으로 작성할 때 쓰는 기호입니다. 1급에서 특히 자주 나오지만 2급도 대비하세요.

기호용도
큰따옴표 " "문자열 구분
중괄호 { }변수·파라미터·플레이스홀더·JSON
삼중 백틱 ```코드 블록
꺾쇠괄호 < >XML·HTML
AI-POT 3과목 단골 함정 8가지

🪤 함정 1. 프롬프트 5대 구성요소 누락

지시·맥락·입력·제약조건·출력형식. "5개 중 아닌 것"을 묻습니다. 'AI모델'이나 '알고리즘' 같은 보기가 함정.

🪤 함정 2. Midjourney = Discord

미드저니는 Discord 기반이고 파라미터가 --로 시작. 웹 기반(DALL·E)과 혼동시킵니다.

🪤 함정 3. Stable Diffusion만 로컬·오픈소스

4개 이미지 AI 중 로컬 실행·오픈소스는 Stable Diffusion. 나머지는 웹/API/앱 기반.

🪤 함정 4. 명확성 vs 구체성

명확성=모호함 제거, 구체성=상세·정량·예시. 두 원칙의 요소를 서로 바꿔 출제합니다.

🪤 함정 5. 합성 데이터 정의

"실제 데이터를 모방하되 진짜 개인정보는 없는" 데이터. '실제 데이터의 일부'라고 하면 오답.

🪤 함정 6. GitHub Copilot = 코드 생성

일반 Copilot(멀티모달)과 GitHub Copilot(코드 생성)을 구분. GitHub Copilot은 코드 편집기 통합.

🪤 함정 7. 구분기호 용도

중괄호{ }=변수/JSON, 삼중백틱```=코드블록, 큰따옴표=문자열. 용도를 바꿔 출제.

🪤 함정 8. 개발사-모델 짝

OpenAI=GPT, Google=Gemini, Anthropic=Claude, MS=Copilot. 짝을 어긋나게 출제합니다.

합성 데이터는 실제 데이터를 모방하지만 실제 인간의 데이터는 포함하지 않는 인공 데이터이다. 진짜 개인정보가 들어있지 않으므로, 데이터의 형태·패턴은 활용하면서도 개인정보 유출 위험 없이 분석·학습에 쓸 수 있다.
개념 복습
예: 엑셀 파일의 머리말·내용 '형태'만 학습시켜 가상 데이터를 생성. 실제 값이 아니므로 안전합니다.
암기 팁
"형태는 진짜 같고 내용은 가짜 = 합성 데이터 = 개인정보 안전".
