JAVA PROGRAMMING · LESSON 02

자바 프로그램 구조와 출력문

오늘은 자바 코드의 뼈대를 정확히 읽고, 직접 쓰고, 수정할 수 있도록 연습합니다.

학습 목표

  • 클래스와 main 구조 이해
  • print/println 차이 이해
  • 주석 작성 습관

오늘 산출물

  • 자기소개 콘솔 출력
  • 오류 수정 1회 이상
  • 주석 포함 소스

자바 파일 기본 구조

public class Main1 { public static void main(String[] args) { System.out.println("자바 시작"); } }
  1. 클래스 선언: 파일의 큰 틀
  2. main 메서드: 프로그램 시작점
  3. 명령문: 실행할 코드(끝에 세미콜론)

출력문 3가지

println

출력 후 줄바꿈

System.out.println("A"); System.out.println("B");

print

출력 후 줄바꿈 없음

System.out.print("A "); System.out.print("B");

문자열 결합

+ 연산으로 문장 만들기

String name = "민수"; System.out.println("이름: " + name);

주석

코드 설명 기록

// 한 줄 주석 /* 여러 줄 주석 */

실습 A: 그대로 따라쓰기

public class Main2 { public static void main(String[] args) { System.out.println("이름: 홍길동"); System.out.println("희망진로: 개발자"); System.out.println("한 줄 각오: 포기하지 않는다"); } }
  • 코드를 직접 입력해 실행
  • 이름/진로/각오를 본인 정보로 변경
  • 실행 결과 스크린샷 저장

실습 B: 오류 찾고 수정하기

public class Main3 { public static void main(String[] args) { System.out.println("Hello Java") } }

질문: 왜 실행이 안될까요?

  • 문장 끝에 ; 누락 확인
  • 오류 메시지에서 line 번호 확인
  • 수정 후 다시 실행

실습 코드 예제 5개

예제 1: println 연속 출력

정리

  • print와 println은 줄바꿈 차이
