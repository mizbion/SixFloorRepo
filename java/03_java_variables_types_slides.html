변수와 자료형 기초

값을 저장하고 다시 꺼내 쓰는 방법을 익힙니다.

학습 목표

  • 변수 선언/초기화 이해
  • 자료형 구분해 사용
  • 값 변경 결과 예측

오늘 산출물

  • 학생 정보 출력 코드
  • 점수 평균 계산 코드
  • 기초 오류 수정 기록

변수란 무엇인가

변수는 데이터를 담는 이름표입니다. 자료형과 변수명, 값을 함께 써서 만듭니다.

int age = 18; double height = 172.5; char grade = 'A'; boolean isPresent = true; String name = "지민";

먼저 "무슨 데이터인지" 생각하고 자료형을 선택하면 실수가 줄어듭니다.

기본 자료형 + 문자열

int

정수: 1, -3, 100

double

실수: 3.14, 0.5

char

문자 1개: 'A'

boolean

true / false

String

문자열: "안녕하세요"

구분

char는 작은따옴표, String은 큰따옴표

실습 A: 학생 정보 출력

public class Main1 { public static void main(String[] args) { String name = "홍길동"; int age = 18; String major = "소프트웨어과"; boolean isPresent = true; System.out.println("이름: " + name); System.out.println("나이: " + age); System.out.println("전공: " + major); System.out.println("출석여부: " + isPresent); } }
  • 자신의 정보로 값 바꾸기
  • 출력 순서 바꿔보기
  • 한 줄 추가해 취미 출력하기

실습 B: 점수 평균 계산

int kor = 85; int eng = 92; int math = 78; int total = kor + eng + math; double avg = total / 3.0; System.out.println("총점: " + total); System.out.println("평균: " + avg);

정수 나눗셈 실수를 줄이려면 3.0처럼 실수를 사용합니다.

int avg = total / 3; 처럼 쓰면 소수점이 사라집니다.

실습 코드 예제 5개

예제 1: int 변수

public class Main2 { public static void main(String[] args) { int age = 18; System.out.println("나이: " + age); } }

예제 2: double 계산

public class Main3 { public static void main(String[] args) { double h = 172.5; double w = 65.2; System.out.println("합: " + (h + w)); } }

예제 3: char/boolean

public class Main4 { public static void main(String[] args) { char grade = 'A'; boolean pass = true; System.out.println("등급: " + grade); System.out.println("합격: " + pass); } }

예제 4: String 결합

public class Main5 { public static void main(String[] args) { String name = "민지"; int no = 12; System.out.println("3-" + no + " " + name); } }

예제 5: 값 변경

public class Main6 { public static void main(String[] args) { int score = 70; score = 85; System.out.println("최종점수: " + score); } }

정리 + 과제

정리

  • 자료형에 맞는 값 저장
  • 변수값 변경 후 다시 출력

과제

학생 정보 카드 프로그램 작성 (이름, 학번, 전공, 나이, 취미, 출석여부 포함)

과제 코드 예제 5개

과제 예제 1: 학생 카드

public class Main7 { public static void main(String[] args) { String name = "김학생"; String major = "AI과"; System.out.println("이름: " + name); System.out.println("전공: " + major); } }

public class Main8 { public static void main(String[] args) { boolean isPresent = true; int lateCount = 1; System.out.println("출석: " + isPresent); System.out.println("지각: " + lateCount); } }

과제 예제 3: 성적 합/평균

public class Main9 { public static void main(String[] args) { int kor = 90, eng = 80, math = 85; int total = kor + eng + math; double avg = total / 3.0; System.out.println("총점: " + total); System.out.println("평균: " + avg); } }
