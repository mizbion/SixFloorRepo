JAVA PROGRAMMING · LESSON 04

연산자와 형변환

숫자 계산, 조건 비교, 논리 판단을 코드로 정확하게 표현합니다.

학습 목표

  • 산술/비교/논리 연산자 구분
  • 형변환이 필요한 상황 판단
  • 연산 결과 예측 후 검증

오늘 산출물

  • 주문 금액 계산 코드
  • 조건 판단 코드
  • 연산 실수 체크리스트

연산자 핵심 정리

  • 산술: +, -, *, /, %
  • 비교: ==, !=, >, <, >=, <=
  • 논리: &&, ||, !

조건문에 들어가는 식은 최종적으로 true/false가 되어야 합니다.

실습 A: 주문 금액 계산

public class Main1 { public static void main(String[] args) { int ramen = 4500; int kimbap = 3500; int qty = 2; int total = ramen + (kimbap * qty); System.out.println("총금액: " + total); } }

괄호를 사용하면 연산 우선순위를 명확히 할 수 있습니다.

실습 B: 형변환과 비교

public class Main2 { public static void main(String[] args) { int a = 7, b = 2; double div = (double) a / b; boolean pass = div >= 3.5; System.out.println("나눗셈 결과: " + div); System.out.println("기준 통과: " + pass); } }

int / int 는 정수 결과가 되므로 소수점이 사라집니다.

실습 코드 예제 5개

예제 1: 나머지 판정

public class Main3 { public static void main(String[] args) { int n = 17; System.out.println(n % 2); } }

예제 2: 증가 연산

public class Main4 { public static void main(String[] args) { int x = 5; x++; System.out.println(x); } }

예제 3: 비교 결과

public class Main5 { public static void main(String[] args) { int a = 10, b = 7; System.out.println(a > b); System.out.println(a == b); } }

예제 4: 논리 결합

public class Main6 { public static void main(String[] args) { int temp = 26; boolean rain = false; System.out.println(temp > 25 && !rain); } }

예제 5: 우선순위

public class Main7 { public static void main(String[] args) { int r1 = 10 + 2 * 3; int r2 = (10 + 2) * 3; System.out.println(r1); System.out.println(r2); } }

정리 + 과제

정리

  • 연산자 종류에 맞는 문법을 사용한다.
  • 형변환이 필요한 지점을 확인한다.
  • 조건식 결과를 예측하고 실행으로 검증한다.

과제

쇼핑 계산기 작성: 상품 3개 가격 합, 할인 적용, 결제 가능 여부 출력

과제 코드 예제 5개

과제 예제 1: 평균 계산

public class Main8 { public static void main(String[] args) { int kor = 80, eng = 90, math = 70; double avg = (kor + eng + math) / 3.0; System.out.println(avg); } }

과제 예제 2: 할인 적용

public class Main9 { public static void main(String[] args) { int price = 12000; int discount = 1500; System.out.println(price - discount); } }

과제 예제 3: 성인 판정

public class Main10 { public static void main(String[] args) { int age = 20; System.out.println(age >= 19); } }

과제 예제 4: 복합 조건

public class Main11 { public static void main(String[] args) { int money = 8000; boolean open = true; System.out.println(money >= 7000 && open); } }

과제 예제 5: 최종 계산

public class Main12 { public static void main(String[] args) { int a = 5, b = 4, c = 3; System.out.println((a + b) * c); } }
