switch 조건문

정해진 선택지에서 분기할 때 switch를 사용합니다.

학습 목표

  • switch-case-default 구조 이해
  • break 사용 이유 이해
  • 메뉴 분기 코드 작성

오늘 산출물

  • 카페 메뉴 코드
  • 요일 분기 코드
  • switch 과제 5개

핵심 개념

  • switch(값) { case 값: ... break; }
  • break가 없으면 다음 case까지 실행됩니다.
  • default는 어떤 case도 맞지 않을 때 실행됩니다.

실습 A: 카페 메뉴 선택

public class Main1 { public static void main(String[] args) { int menu = 2; switch (menu) { case 1: System.out.println("아메리카노"); break; case 2: System.out.println("카페라떼"); break; case 3: System.out.println("초코라떼"); break; default: System.out.println("메뉴 없음"); } } }

실습 B: 요일 분기

public class Main2 { public static void main(String[] args) { String day = "SAT"; switch (day) { case "MON": case "TUE": case "WED": case "THU": case "FRI": System.out.println("평일"); break; case "SAT": case "SUN": System.out.println("주말"); break; default: System.out.println("입력 오류"); } } }

실습 코드 예제 5개

예제 1: 등급 분기

public class Main3 { public static void main(String[] args) { int grade = 1; switch (grade) { case 1: System.out.println("VIP"); break; case 2: System.out.println("GOLD"); break; default: System.out.println("BASIC"); } } }

예제 2: 월별 시즌

public class Main4 { public static void main(String[] args) { int month = 12; switch (month) { case 12: case 1: case 2: System.out.println("겨울"); break; default: System.out.println("기타"); } } }

예제 3: break 누락 비교

public class Main5 { public static void main(String[] args) { int n = 2; switch (n) { case 1: System.out.println("one"); case 2: System.out.println("two"); case 3: System.out.println("three"); } } }

예제 4: 문자 switch

public class Main6 { public static void main(String[] args) { char c = 'B'; switch (c) { case 'A': System.out.println("90+"); break; case 'B': System.out.println("80+"); break; default: System.out.println("80 미만"); } } }

예제 5: default 처리

public class Main7 { public static void main(String[] args) { int menu = 99; switch (menu) { case 1: System.out.println("조회"); break; default: System.out.println("잘못된 선택"); } } }

정리 + 과제

정리

  • switch는 선택형 분기에 유리하다.
  • break/default를 빠뜨리지 않는다.
  • if와 switch의 용도를 구분한다.

과제

키오스크 메뉴 프로그램 작성: 번호별 상품명/가격 출력

과제 코드 예제 5개

과제 1: 버스 노선

public class Main8 { public static void main(String[] args) { int line = 2; switch (line) { case 1: System.out.println("시청"); break; case 2: System.out.println("강남"); break; case 3: System.out.println("잠실"); break; default: System.out.println("없음"); } } }

과제 2: 학점 메시지

public class Main9 { public static void main(String[] args) { String g = "A"; switch (g) { case "A": System.out.println("우수"); break; case "B": System.out.println("양호"); break; default: System.out.println("보완필요"); } } }

과제 3: 앱 탭 이동

public class Main10 { public static void main(String[] args) { int tab = 3; switch (tab) { case 1: System.out.println("홈"); break; case 2: System.out.println("검색"); break; case 3: System.out.println("마이"); break; default: System.out.println("기본"); } } }

과제 4: 사칙 선택

public class Main11 { public static void main(String[] args) { int op = 4; int a = 8, b = 2; switch (op) { case 1: System.out.println(a+b); break; case 2: System.out.println(a-b); break; case 3: System.out.println(a*b); break; case 4: System.out.println(a/b); break; default: System.out.println("none"); } } }
