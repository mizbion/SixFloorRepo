JAVA PROGRAMMING · LESSON 01
1회차

오리엔테이션 + 개발환경 설치

오늘 목표는 "내 컴퓨터에서 자바 코드가 실제로 실행되는 경험"을 만드는 것입니다.

수업 목표

  • 과목 운영 방식 이해
  • JDK/IDE 설치 완료
  • 첫 실행 성공

오늘 결과물

  • Hello Java 출력
  • 실행 화면 캡처
  • 설치 체크리스트

개발환경 설치 순서

  1. JDK 설치
  2. IDE 설치 (Eclipse 또는 IntelliJ)
  3. 새 프로젝트 만들기
  4. 실행 버튼으로 콘솔 출력 확인

설치 중 경로/권한 문제로 지연될 수 있습니다. 에러가 나면 메시지를 읽고 함께 해결합니다.

public class Main1 { public static void main(String[] args) { System.out.println("Hello Java"); } }

실습 미션

미션 A

위 코드를 직접 입력해 실행하기

미션 B

문구를 자신의 이름으로 바꿔 재실행

미션 C

오타를 일부러 넣고 에러 원인 찾기

미션 D

정상 실행 화면 캡처 제출

실습 코드 예제 5개

예제 1: 기본 출력

public class Main2 { public static void main(String[] args) { System.out.println("Hello Java"); } }

예제 2: 이름 출력

public class Main3 { public static void main(String[] args) { System.out.println("이름: 김자바"); } }

예제 3: 두 줄 출력

public class Main4 { public static void main(String[] args) { System.out.println("학과: 소프트웨어과"); System.out.println("목표: 정보처리산업기사"); } }

예제 4: print + println

public class Main5 { public static void main(String[] args) { System.out.print("JAVA "); System.out.println("START"); } }

예제 5: 이스케이프 문자

public class Main6 { public static void main(String[] args) { System.out.println("\"자바\" 수업 시작"); System.out.println("C:\\Java\\workspace"); } }

자주 발생하는 오류와 대응

1) 클래스 이름/파일 이름 불일치

파일명과 public class 이름을 동일하게 맞춥니다.

2) 세미콜론 누락

자바 문장 끝에는 대부분 ; 가 필요합니다.

3) main 메서드 오타

메서드 시그니처를 샘플 그대로 확인합니다.

정리 + 과제

  • 설치 성공 + 첫 실행 성공
  • 체크 포인트: 실행 버튼, 콘솔, 수정 후 재실행

과제

자기소개 3줄 출력 프로그램 작성 후 실행 화면 제출

예) 이름 / 희망진로 / 한 줄 각오

과제 코드 예제 5개

과제 예제 1: 자기소개 3줄

public class Main7 { public static void main(String[] args) { System.out.println("이름: 박코드"); System.out.println("희망직무: 백엔드"); System.out.println("각오: 매일 30분 코딩"); } }

과제 예제 2: 학교 정보

public class Main8 { public static void main(String[] args) { System.out.println("학교: OO직업고"); System.out.println("학년: 3학년"); System.out.println("반: 2반"); } }

과제 예제 3: 시간표 안내

public class Main9 { public static void main(String[] args) { System.out.println("1교시: Java"); System.out.println("2교시: DB"); System.out.println("3교시: 프로젝트"); } }

과제 예제 4: 진로 목표

public class Main10 { public static void main(String[] args) { System.out.print("단기목표: "); System.out.println("포트폴리오 3개 완성"); System.out.println("장기목표: 개발자 취업"); } }

과제 예제 5: 오류 수정 후 실행

public class Main11 { public static void main(String[] args) { // 아래 문장을 수정해서 실행해보기 System.out.println("오류 없는 자바 실행!"); } }
