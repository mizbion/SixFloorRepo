조건문 if

상황에 따라 실행 경로를 나누는 분기 로직을 작성합니다.

학습 목표

  • if / else if / else 구조 이해
  • 조건식 설계 능력 강화
  • 중첩 분기 작성

오늘 산출물

  • 등급 판정 코드
  • 로그인 조건 코드
  • 조건문 과제 5개

조건문 핵심

  • if(조건) { ... } : 조건이 true면 실행
  • else if : 추가 조건 분기
  • else : 모든 조건이 false일 때 실행

조건 순서를 잘못 배치하면 의도와 다른 분기가 실행될 수 있습니다.

실습 A: 점수 등급 판정

public class Main1 { public static void main(String[] args) { int score = 86; if (score >= 90) { System.out.println("A"); } else if (score >= 80) { System.out.println("B"); } else if (score >= 70) { System.out.println("C"); } else { System.out.println("재시험"); } } }

범위 분기는 큰 값 조건부터 작성하는 습관이 안전합니다.

실습 B: 로그인 분기

public class Main2 { public static void main(String[] args) { boolean idOk = true; boolean pwOk = false; if (idOk && pwOk) { System.out.println("로그인 성공"); } else { System.out.println("로그인 실패"); } } }

논리 연산자(&&, ||)를 잘못 쓰면 보안 로직 오류가 발생할 수 있습니다.

실습 코드 예제 5개

예제 1: 단일 if

public class Main3 { public static void main(String[] args) { int temp = 31; if (temp >= 30) System.out.println("더움"); } }

예제 2: if-else

public class Main4 { public static void main(String[] args) { int n = 12; if (n % 2 == 0) System.out.println("짝수"); else System.out.println("홀수"); } }

예제 3: else if

public class Main5 { public static void main(String[] args) { int dust = 85; if (dust >= 150) System.out.println("매우나쁨"); else if (dust >= 80) System.out.println("나쁨"); else System.out.println("보통"); } }

예제 4: 중첩 if

public class Main6 { public static void main(String[] args) { int age = 22; boolean student = true; if (age >= 19) { if (student) System.out.println("학생요금"); } } }

예제 5: 복합 조건

public class Main7 { public static void main(String[] args) { int money = 8000; boolean open = true; if (money >= 7000 && open) System.out.println("주문가능"); } }

정리 + 과제

정리

  • 조건식은 true/false 결과가 나와야 한다.
  • 분기 순서를 논리적으로 설계한다.
  • 복합조건은 괄호로 명확히 표현한다.

과제

영화관 입장 판정 프로그램: 나이, 보호자 동반, 상영등급 조건 처리

과제 코드 예제 5개

과제 1: 출석 판정

public class Main8 { public static void main(String[] args) { int late = 2; if (late == 0) System.out.println("정시"); else System.out.println("지각"); } }

과제 2: 합격/불합격

public class Main9 { public static void main(String[] args) { int score = 59; if (score >= 60) System.out.println("PASS"); else System.out.println("FAIL"); } }

과제 3: 배송비

public class Main10 { public static void main(String[] args) { int price = 18000; if (price >= 20000) System.out.println("무료배송"); else System.out.println("배송비 3000원"); } }

과제 4: 시간대

public class Main11 { public static void main(String[] args) { int hour = 14; if (hour < 12) System.out.println("오전"); else if (hour < 18) System.out.println("오후"); else System.out.println("저녁"); } }

과제 5: 권한 분기

public class Main12 { public static void main(String[] args) { boolean admin = false; if (admin) System.out.println("관리자"); else System.out.println("일반 사용자"); } }
