02

프롬프트란 뭔가요?

AI에게 보내는 질문 또는 명령
얼마나 잘 쓰느냐에 따라 결과가 완전히 달라집니다
❌ 나쁜 프롬프트
📝 "코드 짜줘"
📝 "이미지 만들어줘"
📝 "설명해줘"
📝 "뭔가 써줘"
VS
✅ 좋은 프롬프트
✅ "파이썬 초보자용으로 성적 계산기 만들어줘."
✅ "일본 거리 사진 느낌, 밤, 네온사인, 영화적 분위기"
✅ "변수가 뭔지 중학생도 이해할 수 있게 비유로 설명해줘"

좋은 프롬프트 4가지 공식

01
역할을 줘라
"파이썬 강사처럼 설명해줘"
"친절한 선배처럼 조언해줘"
02
대상을 명시해라
"코딩을 처음 배우는 학생에게 설명하듯이"
"초등학생도 이해하게"
03
형식을 요청해라
"번호 목록으로 정리해줘"
"표 형식으로 비교해줘"
"코드에 주석 달아줘"
04
구체적으로 말해라
"계산기 코드" → "두 수를 입력받아 +,-,*,/ 결과를 출력하는 계산기"

AI랑 대화처럼 이어가면 됩니다

대화 예시 — 점점 구체화하기
👤
파이썬 함수가 뭔지 설명해줘
🌿
함수는 특정 작업을 묶어둔 코드 블록입니다. def 키워드로 만들고...
👤
더 쉽게, 요리 비유로 설명해줘 🍳
🌿
요리 레시피랑 같아요! 함수 = 레시피, 재료 = 매개변수, 완성된 요리 = 반환값...
👤
그럼 실제 코드 예시도 보여줘 💻
🔑
AI는 기억을 해요. 이전 대화를 참고하면서 점점 내가 원하는 방향으로 답변이 좁혀집니다. 카카오톡 대화하듯 자연스럽게!

03

AI로 프로그래밍 공부하는 흐름

1
🤔 "이게 뭔지 모르겠다" → AI에게 개념 질문
"파이썬에서 리스트가 뭐야? 실생활 비유로 쉽게 설명해줘"
2
💻 AI가 만들어준 코드를 직접 실행
Replit.com 또는 구글 Colab에서 코드 붙여넣기 → 실행 → 결과 확인
3
🔍 "이 줄이 왜 이렇게 쓰여있어?" → 코드 설명 요청
"3번째 줄 for i in range(5) 가 뭔 뜻이야?"
4
🐛 에러가 나면 → 에러 메시지 그대로 붙여넣기
"이런 에러가 나는데 왜 그런지, 어떻게 고치는지 알려줘"
5
✏️ 코드를 내 방식으로 조금씩 바꿔보기
숫자, 텍스트, 조건을 바꿔서 결과가 어떻게 달라지는지 실험

실제 예시 ① 개념 이해

📌
이렇게 질문하세요
# 좋은 질문 예시

"파이썬 변수가 뭔지
처음 배우는 학생한테
설명하듯이 알려줘.
예시 코드도 같이 보여줘"
✅
포인트: 내 수준(처음 배우는) + 형식(예시 코드 포함)
Claude 답변 예시
🌿
변수는 값을 저장하는 상자예요!

상자에 이름표(변수명)를 붙이고
그 안에 값을 넣는다고 생각하세요.

name = "김철수" # 상자이름 = 담을값
age = 20
print(name, "은", age, "살")

결과: 김철수 은 20 살

이런 에러가 나는데 왜그래?

SyntaxError: invalid syntax
if score >= 90
            ^
🌿
콜론(:)이 빠졌어요! 파이썬은 if 조건문 끝에 반드시 콜론이 있어야 해요.

❌ if score >= 90
✅ if score >= 90:

콜론은 "이 다음에 할 일 목록이 시작된다"는 신호예요!

AI 쓸 때 꼭 알아야 할 것

⚠️
AI가 틀릴 수 있어요
AI는 완벽하지 않습니다. 중요한 정보는 반드시 다른 곳에서 확인하세요. 특히 최신 정보나 사실 관계는 검색으로 검증 필요.
🔐
개인정보는 입력하지 마세요
주민번호, 비밀번호, 전화번호 등 민감한 정보는 AI에게 절대 입력하지 마세요. 입력한 내용이 학습에 사용될 수 있습니다.
🧠
AI 답변을 "이해"하고 써야 해요
코드를 그냥 복붙하면 실력이 안 늘어요. AI의 설명을 읽고 왜 그렇게 작성했는지 이해하는 것이 핵심입니다.
📜
저작권을 생각하세요
AI가 만든 이미지·글을 상업적으로 사용할 때는 각 도구의 이용약관을 확인하세요. 학습 목적은 대부분 OK.
