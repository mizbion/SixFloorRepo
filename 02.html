예제 01

🎮 게임 닉네임 생성기

이름과 생년월일로 나만의 닉네임을 만들어봐요 — 문자열 슬라이싱 활용!

🎮 닉네임 생성기
내 이름 + 숫자의 조합으로 유니크한 닉네임을!
이름 (한글 or 영문)
생년월일 8자리
좋아하는 숫자
🐍 이게 파이썬 코드예요!
# 문자열 슬라이싱 + 인덱싱 + f-string 활용 name = "홍길동" birth = "20070315" num = 7 year = birth[2:4] # "07" ← 슬라이싱! month = birth[4:6] # "03" init = name[0] # "홍" ← 인덱싱! nick = f"{init}{year}{month}_{num:02d}" print(nick) # → 홍0703_07
사용 개념: 슬라이싱 [2:4] · 인덱싱 [0] · f-string · :02d 포맷

# % 나머지 연산으로 점수를 0~99 범위로 조절 name = "홍길동" birth = "20070315" name_val = len(name) * ord(name[0]) # 이름 수치화 birth_val = int(birth[4:8]) # MMDD 부분 today_val = 18 # 오늘 날짜 score = (name_val + birth_val + today_val) % 100 print(f"오늘의 운: {score}점")

# ** 제곱 연산자 + 실수(float) 연산 height = 172 # cm weight = 65 # kg age = 18 h_m = height / 100 # cm → m 변환 bmi = weight / (h_m ** 2) # BMI = kg / m² ideal = (height - 100) * 0.9 # 표준체중 공식 print(f"BMI: {bmi:.1f}") # :.1f → 소수 1자리 print(f"표준체중: {ideal:.1f}kg")

예제 04

🎲 RPG 주사위 굴리기

나머지 연산과 f-string으로 만드는 간단한 RPG 전투!

🎲 RPG 주사위
주사위를 굴려서 몬스터를 처치해봐요!
주사위 수: 2 면수:

🐍 이게 파이썬 코드예요!
# random 모듈 + sum() + f-string import random dice_count = 2 dice_face = 6 results = [random.randint(1, dice_face) for _ in range(dice_count)] total = sum(results) print(f"결과: {results}") print(f"합계: {total}") print(f"평균: {total / dice_count:.1f}")
사용 개념: randint() · sum() · / 나눗셈 · :.1f

⌨️ 타이핑 속도 측정기

# 문자열 비교 + 나눗셈으로 WPM 계산 import time target = "파이썬으로 무엇이든 만들 수 있다!" typed = "파이썬으로 무엇이든 만들 수 있다!" elapsed = 5.2 # 경과 시간(초) # 정확도: 맞는 글자 수 / 전체 글자 수 correct = sum(t == s for t, s in zip(target, typed)) accuracy = correct / len(target) * 100 # WPM = (글자수 / 5) / (경과분) wpm = (len(typed) / 5) / (elapsed / 60) print(f"정확도: {accuracy:.1f}% WPM: {wpm:.0f}")
사용 개념: len() · / 나눗셈 · * 곱셈 · 문자열 비교 · :.1f

# 날짜 차이 계산 + 가중 평균 + 정수 나눗셈(//) # ① D-day from datetime import date today = date.today() target = date(2026, 11, 19) diff = (target - today).days print(f"수능까지 D-{diff}") # ② 가중 평균 (단위수 반영) scores = [85, 78, 92] credits = [4, 4, 4] avg = sum(s*c for s,c in zip(scores,credits)) / sum(credits) # ③ 일일 용돈 (// 정수 나눗셈) remain = 98000 remain_days = 13 per_day = remain // remain_days print(f"하루 {per_day:,}원 사용 가능")
사용 개념: // 정수나눗셈 · sum() · zip() · :.2f · :, 천단위
