STEP 21차시 핵심 개념 + 기본 실습

핵심 개념

카드 컴포넌트는 반복 구조를 통일해 가독성을 높입니다.

.product-card { border: 1px solid #d9e8e2; border-radius: 12px; padding: 14px; } .product-name { font-weight: 700; } .product-price { color: #2f7a68; }

실습 순서

  • 현재 코드에서 관련 섹션을 먼저 찾는다.
  • 작은 수정 1개 후 바로 저장/새로고침으로 확인한다.
  • 동작 확인 후 같은 패턴으로 2~3개 확장한다.
한 번에 크게 바꾸기보다 작은 수정을 반복하면 오류를 줄일 수 있습니다.
  • 기본 개념 코드를 직접 적용했다
  • 저장/새로고침 루프로 결과를 확인했다
  • 최소 2개 이상 화면 변화가 생겼다

📝 코드 수정 포인트

카드 3개 추가하는 HTML 구조와 스타일 개선 방법입니다:

수정 전 (기본 상태)

<header>
  <h1>내 가게</h1>
</header>

<main>
  <section>
    소개 텍스트
  </section>
</main>
수정 후 (카드 3개 추가)
<section class="products">
  <h2>추천 상품</h2>
  <div class="product-list">
    <div class="product-card">
      <h3 class="product-name">
        상품명
      </h3>
      <p class="product-desc">
        설명
      </p>
      <span class="product-price">
        가격
      </span>
    </div>
  </div>
</section>
STEP 2-보충카드컴포넌트 + 선택자 집중 실습

아래 실습은 이번 회차 핵심인 카드컴포넌트 구조와 선택자 사용법을 직접 익히기 위한 미션입니다.

실습 목표

학습 요소오늘 할 일완료 기준
카드컴포넌트같은 구조의 상품 카드 3개 만들기제목/설명/가격이 카드마다 동일 위치
클래스 선택자.product-card, .product-price 스타일 분리카드 박스와 가격 강조가 분리 적용
자손 선택자.product-card h3, .product-card p 적용카드 내부 텍스트 위계가 보임

시작 코드

<section class="products"> <h2>추천 상품</h2> <div class="product-card"> <h3>딸기 라떼</h3> <p>상큼한 딸기와 우유의 조합</p> <span class="product-price">5,800원</span> </div> <div class="product-card"> <h3>바닐라 쿠키</h3> <p>겉은 바삭, 속은 촉촉한 쿠키</p> <span class="product-price">3,500원</span> </div> <div class="product-card"> <h3>초코 머핀</h3> <p>진한 초코향이 나는 촉촉한 머핀</p> <span class="product-price">4,200원</span> </div> </section> <style> .product-card { border: 1px solid #d9e8e2; border-radius: 12px; padding: 14px; margin-bottom: 10px; } .product-card h3 { font-size: 1.1rem; margin-bottom: 4px; } .product-card p { color: #4f6c63; margin-bottom: 6px; } .product-price { color: #2f7a68; font-weight: 700; } </style>

실습 미션

  • 미션 1: .product-card에 배경색과 그림자를 추가해 카드 느낌을 강화하세요.
  • 미션 2: .product-card h3 글자 크기를 키우고 색상을 브랜드 톤으로 바꾸세요.
  • 미션 3: .product-card p의 줄간격을 조정해서 설명을 읽기 쉽게 만드세요.
  • 미션 4: .product-price에 배경색 또는 배지 스타일을 적용해 가격을 더 눈에 띄게 만드세요.
  • 미션 5: 카드 하나에 class="product-card hot"를 추가하고 .hot 선택자로 추천 배지를 표현하세요.

실습 미션 정답 코드

<section class="products"> <h2>추천 상품</h2> <div class="product-card hot"> <h3>딸기 라떼</h3> <p>상큼한 딸기와 우유의 조합</p> <span class="product-price">5,800원</span> </div> <div class="product-card"> <h3>바닐라 쿠키</h3> <p>겉은 바삭, 속은 촉촉한 쿠키</p> <span class="product-price">3,500원</span> </div> <div class="product-card"> <h3>초코 머핀</h3> <p>진한 초코향이 나는 촉촉한 머핀</p> <span class="product-price">4,200원</span> </div> </section> <style> .product-card { border: 1px solid #d9e8e2; border-radius: 12px; padding: 14px; margin-bottom: 10px; background: #ffffff; box-shadow: 0 6px 14px rgba(31, 90, 77, 0.08); } .product-card h3 { font-size: 1.15rem; color: #1f5a4d; margin-bottom: 4px; } .product-card p { color: #4f6c63; line-height: 1.75; margin-bottom: 6px; } .product-price { display: inline-block; color: #1f5a4d; background: #e8f5ef; border-radius: 999px; padding: 3px 10px; font-weight: 700; } .hot { border: 2px solid #2f7a68; position: relative; } .hot::before { content: "추천"; position: absolute; top: -10px; right: 10px; background: #2f7a68; color: #fff; font-size: 0.72rem; border-radius: 999px; padding: 2px 8px; } </style>
선택자 팁같은 태그라도 .product-card h3처럼 범위를 좁히면 원하는 영역만 정확하게 스타일링할 수 있습니다.

선택자 퀵체크

선택자의미예시 결과
