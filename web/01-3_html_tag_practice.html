기본 태그

h1~h6 · p · br · strong · em · a · img · ul/ol · div · span
예제 1-1 — 제목·단락·강조
<h1>~<h3>로 제목 계층을 만들고, <p>로 단락을 쓰고, <strong>·<em>으로 강조해보세요.
 ✏️ 코드 수정 후 ▶ 실행
🌐 결과 미리보기
💡
<strong>은 "중요한 내용", <em>은 "강조·뉘앙스" — 둘 다 의미를 담습니다. 단순히 굵게/기울임만 원하면 CSS를 씁니다.
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>나의 버킷리스트</title>
</head>
<body>

  <h1>나의 버킷리스트</h1>
  <h2>올해 안에 꼭 해보고 싶은 것들</h2>
  <h3>여행 편</h3>

  <p>
    <strong>제주도</strong>에 혼자 여행 가기.
    한라산 등반은 <em>선택 사항</em>이지만
    꼭 도전해보고 싶다.
  </p>

  <p>
    첫 줄 작성.<br>
    br 태그로 줄이 바뀐다.
  </p>

</body>
</html>
예제 1-2 — 링크 · 이미지
<a href="…">로 링크를, <img src="…" alt="…">로 이미지를 삽입합니다. target="_blank"는 새 탭에서 열기.
 ✏️ 코드 수정 후 ▶ 실행
🌐 결과 미리보기
속성설명예시
href이동할 주소https://naver.com
target="_blank"새 탭에서 열기
src이미지 파일 경로photo.jpg
alt이미지 설명 (필수!)"내 사진"
width가로 크기(px)300
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>링크와 이미지</title>
</head>
<body>

  <p>
    <a href="https://www.naver.com" target="_blank">
      네이버 바로가기
    </a>
  </p>

  <img
    src="https://picsum.photos/seed/nature/280/160"
    alt="자연 풍경 사진"
    width="280"
  >

  <p>
    <a href="mailto:test@example.com">이메일 보내기</a>
  </p>

</body>
</html>
예제 1-3 — 목록 · div · span
<ul>은 불릿 목록, <ol>은 번호 목록. <div>는 블록(줄 전체), <span>은 인라인(줄 안).
 ✏️ 코드 수정 후 ▶ 실행
🌐 결과 미리보기
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>목록과 컨테이너</title>
</head>
<body>

  <h2>좋아하는 음식</h2>
  <ul>
    <li>🍗 치킨</li>
    <li>🍕 피자</li>
    <li>🍜 라멘</li>
  </ul>

  <h2>웹 배우는 순서</h2>
  <ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
  </ol>

  <div style="background:lightblue; padding:8px;">div 박스</div>
  <div style="background:lightgreen; padding:8px;">또 다른 div</div>

  <p>날씨: <span style="color:red">맑음 ☀️</span></p>

</body>
</html>

시맨틱 레이아웃 태그

header · nav · main · section · article · aside · footer
시맨틱(Semantic) = "의미가 있는". <div>만 쓰는 것보다 용도에 맞는 태그를 쓰면 코드를 읽기 쉽고 CSS 선택자도 깔끔해집니다.
예제 2-1 — 시맨틱 페이지 뼈대
실제 페이지에서 <header>, <nav>, <main>, <section>, <article>, <aside>, <footer>가 어떻게 배치되는지 확인해보세요.
 ✏️ 코드 수정 후 ▶ 실행
🌐 결과 미리보기
태그의미주로 쓰는 곳
<header>머리말로고, 사이트 제목, 상단 소개
<nav>이동 메뉴메뉴 링크 묶음
<main>핵심 본문페이지마다 바뀌는 콘텐츠
<section>주제별 구획소개·공지·후기 등 덩어리
<article>독립적인 글게시글, 뉴스 카드, 리뷰
<aside>부가 정보광고, 관련 링크, 사이드 정보
<footer>꼬리말저작권, 연락처, 하단 메뉴
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>오늘의 레시피</title>
</head>
<body>

  <header>
    <h1>오늘의 레시피 🍳</h1>
  </header>

  <nav>
    <a href="#soup">국물요리</a>
    <a href="#rice">밥요리</a>
  </nav>

  <main>
    <section id="soup">
      <h2>국물요리</h2>
      <article>
        <h3>된장찌개</h3>
        <p>간단한 집밥 메뉴</p>
      </article>
    </section>
    <aside>
      💡 오늘의 팁: 육수는 다시마를 넣으면 깊은 맛!
    </aside>
  </main>

  <footer>
    © 2026 Cooking Class
  </footer>

</body>
</html>

텍스트 의미 태그

mark · small · time · abbr · blockquote · q · code · pre
예제 3-1 — 텍스트 의미 태그 모음
각 태그의 시각적 결과와 의미를 같이 확인해보세요. 브라우저 기본 스타일이 적용됩니다.
 ✏️ 코드 수정 후 ▶ 실행
🌐 결과 미리보기
💡
<abbr title="풀네임">는 마우스를 올리면 풀네임이 툴팁으로 보입니다. <time datetime="YYYY-MM-DD">의 datetime 속성은 기계(검색엔진 등)가 읽는 표준 형식이에요.
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>텍스트 의미 태그</title>
</head>
<body>

  <p>오늘의 키워드: <mark>Semantic HTML</mark></p>

  <p><small>* 실습 파일은 수업 종료 후 삭제됩니다.</small></p>

  <p>개강일: 
    <time datetime="2026-04-05">2026년 4월 5일</time>
  </p>

  <p>
    <abbr title="HyperText Markup Language">HTML</abbr>
    은 웹 언어입니다.
  </p>

  <blockquote>
    좋은 구조는 좋은 스타일의 출발점이다.
  </blockquote>

  <p>선생님이 말했어요: 
    <q>태그 의미부터 생각하자.</q>
  </p>

  <p>인라인 코드: <code>color: red;</code></p>

  <pre>
pre 안에서는
  공백과 줄바꿈이
    그대로 유지됩니다!
  </pre>

</body>
</html>

표(Table)

table · caption · thead · tbody · tr · th · td · colspan
예제 4-1 — 주간 학습 계획표
<caption>으로 표 제목을, <thead>로 헤더 행을, <tbody>로 데이터 행을 구분합니다. colspan으로 셀을 가로로 합칩니다.
 ✏️ 코드 수정 후 ▶ 실행
🌐 결과 미리보기
⚠️
border="1"은 임시로 선을 보이게 하는 HTML 속성입니다. 나중에 CSS의 border-collapse: collapse와 border로 교체합니다.
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>주간 학습 계획</title>
</head>
<body>

  <table border="1">
    <caption>주간 학습 계획</caption>

    <thead>
      <tr>
        <th>요일</th>
        <th>오전</th>
        <th>오후</th>
      </tr>
    </thead>

    <tbody>
      <tr>
        <td>월요일</td>
        <td>HTML 복습</td>
        <td>CSS 선택자</td>
      </tr>
      <tr>
        <td>화요일</td>
        <td>박스모델</td>
        <td>Flexbox</td>
      </tr>
      <tr>
        <td>수요일</td>
        <td colspan="2">
          미니 프로젝트 (오전+오후 합반)
        </td>
      </tr>
    </tbody>
  </table>

</body>
</html>

폼(Form)

form · fieldset · legend · label · input · textarea · select · button
예제 5-1 — 수강 신청 폼
<label for="…">의 for 값과 <input id="…">의 id 값을 같게 연결합니다. 클릭 영역이 넓어지고 접근성이 좋아집니다.
 ✏️ 코드 수정 후 ▶ 실행
🌐 결과 미리보기
태그핵심 역할주요 속성
<form>입력 묶음 전체action, method
<fieldset> + <legend>관련 입력 그룹화
<label>입력칸 설명 연결for ← id 와 일치!
<input>한 줄 입력type, id, placeholder
<textarea>여러 줄 입력rows, cols
<select> + <option>선택 목록
<button>동작 실행type="submit"
💡
type="text" 외에도 type="email"(이메일 형식 검사), type="password"(별표 표시), type="number", type="checkbox" 등 다양합니다.
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>수강 신청</title>
</head>
<body>

  <form>
    <fieldset>
      <legend>수강 신청</legend>

      <p>
        <label for="name">이름</label><br>
        <input id="name" type="text" placeholder="홍길동">
      </p>

      <p>
        <label for="email">이메일</label><br>
        <input id="email" type="email" placeholder="test@example.com">
      </p>

      <p>
        <label for="track">트랙 선택</label><br>
        <select id="track">
          <option>프론트엔드</option>
          <option>백엔드</option>
          <option>풀스택</option>
        </select>
      </p>

      <p>
        <label for="memo">지원 동기</label><br>
        <textarea id="memo" rows="3"
          placeholder="간단히 작성해주세요"></textarea>
      </p>

      <button type="submit">제출하기</button>
    </fieldset>
  </form>

</body>
</html>

종합 실습

배운 태그를 모두 사용해 완성하기
🏆 나의 수업 소개 페이지 만들기
지금까지 배운 태그를 모두 써서 하나의 완성된 HTML 파일을 만들어보세요. 시맨틱 구조 + 텍스트 의미 태그 + 표 + 폼을 모두 포함해야 합니다.
 ✏️ 완성하고 ▶ 실행
🌐 결과 미리보기
✅
완성 체크리스트
☐ header / nav / main / section / footer 사용
☐ abbr, mark, time, blockquote 중 2개 이상
☐ table에 caption + thead + tbody 포함
☐ form에 label-input 연결(for/id) 2개 이상
☐ button + textarea 포함 
<!-- 종합 실습 완성 답안 —— 전체 파일 -->
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>웹개발 입문 수업 소개</title>
</head>
<body>

  <header>
    <h1>웹개발 입문 수업 소개</h1>
    <p>개강일: 
      <time datetime="2026-04-05">2026년 4월 5일</time>
    </p>
  </header>

  <nav>
    <a href="#info">수업 정보</a> |
    <a href="#plan">커리큘럼</a> |
    <a href="#apply">수강 신청</a>
  </nav>

  <main>

    <section id="info">
      <h2>수업 소개</h2>
      <p>
        <abbr title="HyperText Markup Language">HTML</abbr>
        과 <mark>CSS</mark>를 처음부터 배우는 입문 과정입니다.
      </p>
      <blockquote>
        구조를 먼저 잡으면 디자인이 쉬워진다.
      </blockquote>
    </section>

    <section id="plan">
      <h2>커리큘럼</h2>
      <table border="1">
        <caption>주차별 학습 계획</caption>
        <thead>
          <tr><th>주차</th><th>내용</th></tr>
        </thead>
        <tbody>
          <tr><td>1주</td><td>HTML 기초</td></tr>
          <tr><td>2주</td><td>CSS 기초</td></tr>
          <tr><td>3주</td><td>Flexbox</td></tr>
        </tbody>
      </table>
    </section>

    <section id="apply">
      <h2>수강 신청</h2>
      <form>
        <label for="sname">이름</label><br>
        <input id="sname" type="text"><br><br>
        <label for="smemo">각오 한마디</label><br>
        <textarea id="smemo" rows="2"></textarea><br><br>
        <button type="submit">신청하기</button>
      </form>
    </section>

  </main>

  <footer>
    <small>© 2026 웹개발 수업. All rights reserved.</small>
  </footer>

</body>
</html>
