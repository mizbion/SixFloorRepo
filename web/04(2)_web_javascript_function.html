2단계 · 가장 단순한 함수 만들기

버튼을 누르면 인사하는 함수, 코드로 직접 만들어봐요

📝 함수의 기본 모양

함수 정의 문법 
function 함수이름() {
  // 실행할 코드
}
function = "함수를 만든다"는 약속된 단어 (키워드)
함수이름 = 내가 마음대로 짓는 이름 (영어, 의미 있게)
() = 함수 표시. 지금은 비어있음
{ } = 중괄호 안에 실행할 코드를 적음

🚀 그럼 코드는 어떻게 생겼을까?

위 버튼을 눌렀을 때 "안녕!"이 뜨게 만드는 코드입니다.

<script>
function sayHello() {
  document.getElementById("result").innerHTML = "안녕!";
}
</script>

📖 한 줄씩 뜯어보기

1줄: <button onclick="sayHello()">
버튼을 만들고, "클릭하면 sayHello() 함수를 호출해라"는 명령을 답니다.
⚠️ 여기서 sayHello()는 함수를 부르는 것(호출)입니다. 괄호 ()가 "실행해!"라는 신호예요.
2줄: <div id="result"></div>
결과를 보여줄 빈 칸. id="result"는 자바스크립트에서 이 div를 찾을 때 쓰는 이름표입니다.
4~6줄: function sayHello() { ... }
sayHello라는 이름의 함수를 정의합니다. 아직 실행되지는 않아요. 누군가 부를 때까지 기다립니다.
5줄: document.getElementById("result").innerHTML = "안녕!"
id가 "result"인 div를 찾아서, 그 안의 내용을 "안녕!"으로 바꿉니다.

🔑 가장 중요한 개념: 정의 vs 호출

함수 정의 함수 호출
function sayHello() { ... } sayHello()
"이런 일을 하는 함수가 있다"

✏️ 도전! 위 버튼을 5번 눌러보세요. 5번 다 "안녕!"이 나오죠? 함수는 한 번 정의하고 여러 번 부를 수 있다는 게 핵심입니다.

3단계 · 매개변수 — 함수에 값 넣기

함수에 재료를 넣어서 더 똑똑하게 만들어요

😕 문제 상황

2단계에서 만든 sayHello()는 항상 "안녕!"만 출력합니다. 그런데 만약 "안녕, 민수!", "안녕, 지영!"처럼 이름을 다르게 넣고 싶다면 어떡할까요?

이름마다 함수를 따로 만든다면...

비효율의 끝판왕 ❌ 
function sayHelloMinsu() { /* "안녕 민수!" */ }
function sayHelloJiyoung() { /* "안녕 지영!" */ }
function sayHelloChulsoo() { /* "안녕 철수!" */ }
// ... 반 학생 30명? 함수 30개? 😱

이걸 한 번에 해결하는 게 바로 매개변수(parameter)입니다.

📝 매개변수가 있는 함수

매개변수 문법 
function 함수이름(매개변수) {
  // 매개변수를 활용한 코드
}
괄호 () 안에 받을 값의 이름을 적어두면, 함수를 호출할 때 그 자리에 값을 넣어줄 수 있어요. 이걸 매개변수라고 합니다.

🚀 그럼 코드는 어떻게 생겼을까?

위처럼 동작하는 코드입니다. 매개변수가 어떻게 쓰이는지 잘 보세요.

hello-name.html 
<input id="nameInput" value="민수">
<button onclick="callHello()">인사하기</button>
<div id="result"></div>

<script>
function sayHello(name) {
  document.getElementById("result").innerHTML = "안녕, " + name + "!";
}

function callHello() {
  const userName = document.getElementById("nameInput").value;
  sayHello(userName);
}
</script>

📖 한 줄씩 뜯어보기

6줄: function sayHello(name)
괄호 안에 name이 생겼어요. 이게 매개변수입니다. "이 함수는 name이라는 값을 받아서 일할 거야"라는 뜻이에요.
7줄: "안녕, " + name + "!"
문자열 "안녕, "과 name 변수를 +로 연결합니다. name이 "민수"면 결과는 "안녕, 민수!"가 돼요.
10~13줄: callHello() 함수
버튼이 누르면 실행되는 함수. input 칸의 값을 읽어서 userName에 담고, 그걸 sayHello(userName)으로 전달합니다.
12줄: sayHello(userName)
⭐ 여기가 가장 중요해요! 함수를 호출할 때 괄호 안에 값을 넣어줍니다. userName이 "민수"라면, 그 값이 sayHello의 매개변수 name에 들어갑니다.

🔑 매개변수(parameter) vs 인자(argument)

이 두 단어는 헷갈리기 쉬워요. 비유로 기억하세요.

매개변수 (parameter) 인자 (argument)
function sayHello(name) sayHello("민수")
함수를 정의할 때 적는 변수 이름 함수를 호출할 때 실제로 넘기는 값
📦 받을 그릇 🍎 그릇에 담는 내용물
✏️ 도전! 이름 칸을 본인 이름, 친구 이름, "안녕하세요" 같은 인사말 등으로 바꿔보세요. 같은 함수가 매번 다른 결과를 내는 게 매개변수의 힘입니다.

4단계 · return — 결과를 돌려받기

함수가 만든 결과를 변수에 저장해서 또 쓸 수 있게!

🤔 지금까지의 함수는?

지금까지 만든 함수는 화면에 출력만 했어요. 함수 안에서 일이 끝나버립니다.

그런데 만약 함수의 결과를 변수에 저장해서 또 사용하고 싶다면?

예를 들어, 1~6 사이 숫자를 뽑는 함수가 있다고 해봐요. 그 숫자를 화면에 출력만 할 게 아니라, 다른 계산에 쓰고 싶다면?

이때 사용하는 게 return입니다.

📝 return 사용법

return 문법 
function 함수이름() {
  return 돌려줄_값;
}

// 호출하면 그 값이 돌아옴
const 결과 = 함수이름();
return 뒤에 적은 값이 함수를 호출한 자리로 돌아옵니다. 그래서 그 값을 변수에 저장하거나 다시 활용할 수 있어요.

🎮 먼저 결과부터 확인해봐요!

주사위 2개를 굴려서 합을 구해봅시다. 여러 번 눌러보세요!

결과 버튼을 눌러주세요

👇 매번 다른 숫자가 나오는 비밀! return이 어떻게 일하는지 코드에서 찾아봐요.

🚀 그럼 코드는 어떻게 생겼을까?

주사위 굴리는 함수와 두 개를 합하는 함수, 두 개가 협력합니다.

dice.html 
<button onclick="rollAll()">주사위 굴리기</button>
<div id="result"></div>

<script>
function rollDice() {
  return Math.floor(Math.random() * 6) + 1;
}

function rollAll() {
  const a = rollDice();
  const b = rollDice();
  const sum = a + b;
  document.getElementById("result").innerHTML =
    "주사위: " + a + ", " + b + " / 합: " + sum;
}
</script>

📖 한 줄씩 뜯어보기

5~7줄: function rollDice()
주사위 한 번 굴리는 함수. return으로 1~6 사이의 정수를 돌려줍니다. 화면에 출력하지 않아요! 그냥 값만 돌려줍니다.
6줄: Math.floor(Math.random() * 6) + 1
• Math.random() → 0 이상 1 미만의 소수 (예: 0.7234...)
• × 6 → 0 이상 6 미만 (예: 4.34)
• Math.floor() → 소수점 버리기 (예: 4)
• + 1 → 1부터 시작하게 (예: 5)
결과: 1~6 사이 정수
10~11줄: const a = rollDice();
⭐ 여기가 return의 마법! rollDice()를 호출하면 1~6 중 한 값이 돌아오는데, 그걸 변수 a에 저장합니다. 한 번 더 호출해서 b에도 저장.
12줄: const sum = a + b;
return으로 받은 값들을 자유롭게 계산에 활용할 수 있어요. 이게 핵심입니다.

👇 이 마법은 어떻게 일어날까요? 함수 2개의 조합으로 만들어집니다. 코드를 살펴봅시다.

🚀 그럼 코드는 어떻게 생겼을까?

지금까지 배운 함수, 매개변수, return을 모두 사용합니다.

lotto.html 
<button onclick="generateLotto()">로또 번호 뽑기</button>
<div id="lotto"></div>

<script>
// 1~max 사이 정수 하나 뽑는 함수 (4단계 응용)
function pickNumber(max) {
  return Math.floor(Math.random() * max) + 1;
}

// 6개 모을 때까지 반복하는 함수
function generateLotto() {
  const numbers = [];

  while (numbers.length < 6) {
    const num = pickNumber(45);
    if (!numbers.includes(num)) {
      numbers.push(num);
    }
  }

  numbers.sort((a, b) => a - b);

  document.getElementById("lotto").innerHTML =
    "🎰 로또 번호: " + numbers.join(", ");
}
</script>

📖 한 줄씩 뜯어보기

6~8줄: function pickNumber(max)
4단계의 rollDice()를 발전시킨 함수. 매개변수 max를 받아서 1~max 사이 정수를 return합니다. pickNumber(45)를 호출하면 1~45 중 하나가 돌아와요.
12줄: const numbers = [];
뽑힌 번호를 담을 빈 배열을 만듭니다. []는 빈 배열이에요. 여기에 6개를 차곡차곡 담을 예정.
14줄: while (numbers.length < 6)
⭐ 핵심 반복문! "배열의 길이가 6보다 작은 동안 계속 반복하라". 즉 6개가 모일 때까지 멈추지 않습니다.
15줄: const num = pickNumber(45);
4단계에서 배운 패턴! pickNumber(45)를 호출해서 돌아온 값을 num에 저장. return의 활용이에요.
16줄: if (!numbers.includes(num))
• numbers.includes(num) → 배열에 이미 그 숫자가 있으면 true
• ! → "아니다"라는 부정 연산자
합치면 "배열에 그 숫자가 없으면"이라는 뜻. 새로운 숫자만 추가하기 위한 조건입니다.
17줄: numbers.push(num);
push는 배열 끝에 값을 추가하는 함수. 6개가 될 때까지 계속 쌓여요.
21줄: numbers.sort((a, b) => a - b);
배열을 오름차순으로 정렬합니다. 작은 수부터 큰 수 순서로 정리해줘요. (이건 그냥 외우세요. 자세한 건 나중에 배웁니다.)
24줄: numbers.join(", ")
배열을 문자열로 합칩니다. [3, 7, 15] → "3, 7, 15". 쉼표로 구분하면서 한 줄로 만들어줘요.

🔑 정리: 1단계부터 5단계까지

단계 배운 내용 사용한 코드
1 함수는 동작 묶음 (개념)
2 함수 정의 + 호출 sayHello()
3 매개변수로 값 전달 sayHello(name)
