표 기본 연습

caption · thead · tbody · tr · th · td
표는 <table> 안에서 행은 <tr>, 제목 칸은 <th>, 내용 칸은 <td>로 만듭니다. 제목이 있는 표라면 <caption>, <thead>, <tbody>까지 같이 써보는 연습이 좋습니다.
예제 1-1. 간식 가격표
기본 표 구조를 가장 단순하게 연습하는 예제입니다. 항목을 바꾸거나 행을 1개 더 추가해 보세요.
✏️ 코드 수정 후 실행
🌐 결과 화면
태그역할포인트
caption표 제목표가 무엇을 나타내는지 먼저 알려줍니다.
thead표 머리글 영역보통 제목 행을 넣습니다.
tbody표 본문 영역실제 데이터 행을 넣습니다.
💡
th는 제목 칸이라 기본적으로 굵게 보이고, td는 일반 데이터 칸입니다.

폼 기본 연습

form · label · input · select · textarea
폼은 사용자 입력을 받는 영역입니다. 입력칸 이름을 알려주는 <label>을 같이 쓰면 훨씬 읽기 좋은 구조가 됩니다.
예제 3-1. 상담 신청 폼
텍스트 입력, 날짜 선택, 드롭다운, 긴 글 입력을 한 번에 연습합니다. placeholder나 option 값을 바꿔보세요.
✏️ 코드 수정 후 실행
🌐 결과 화면
태그언제 쓰나예시
label입력칸 이름 붙일 때<label for="student">
input짧은 입력 받을 때type="text", type="date"
select목록에서 하나 고를 때<option>과 함께 사용
textarea여러 줄 입력 받을 때문의 내용, 자기소개
