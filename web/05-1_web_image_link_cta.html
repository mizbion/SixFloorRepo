STEP 2핵심 개념 설명

① <img> 태그 — 이미지 삽입

img 태그 속성 3가지
  • src: 이미지 파일 경로. "store.jpg" 처럼 파일명 또는 URL을 씁니다.
  • alt: 이미지 설명 텍스트. 이미지가 깨졌을 때 대신 표시됩니다. 접근성에도 중요합니다.
  • width: 너비. CSS로 조절하는 것이 더 유연합니다.
img 태그 기본
<img src="store.jpg" alt="가게 대표 이미지">

/* CSS - 이미지 비율 유지 */
img {
  width: 100%;           /* 부모 너비에 맞춤 */
  height: 220px;        /* 고정 높이 */
  object-fit: cover;  /* 비율 유지하며 꽉 채움 */
}
⚠️ object-fit: cover 가 왜 필요한가? 이 속성이 없으면 이미지가 찌그러집니다. cover는 이미지 비율을 유지하면서 지정한 영역을 꽉 채웁니다. 카페 메뉴판처럼 틀 안에 사진이 예쁘게 들어가는 효과입니다.

② <a href="#id"> — 앵커 링크

같은 페이지 내 이동 원리 이동하고 싶은 섹션에 id를 붙이고, 버튼에 href="#그id"를 연결하면 클릭 시 그 위치로 자동 스크롤됩니다.
앵커 링크 예시
<!-- 버튼: href="#menu" 연결 -->
<a href="#menu" class="cta-btn">메뉴 보기</a>

<!-- 이동 목적지: id="menu" -->
<section id="menu">
  <h2>대표 메뉴</h2>
</section>

/* CSS - 부드러운 스크롤 */
html { scroll-behavior: smooth; }

③ CTA 버튼 — Primary / Secondary 구분

버튼 계층 구조가 중요한 이유 방문자는 버튼이 여러 개면 잠깐 고민합니다. Primary(주요)는 진한 색, Secondary(보조)는 연한 색으로 구분하면 눈이 중요한 버튼으로 먼저 갑니다.

④ transition — hover 부드럽게

transition 원리 transition: 0.2s ease 한 줄이면 hover 시 색이 0.2초에 걸쳐 자연스럽게 변합니다. 없으면 색이 뚝 바뀌어 부자연스럽습니다.
버튼 스타일 전체
.cta-btn {
  display: inline-block;
  text-decoration: none;   /* 밑줄 제거 필수! */
  padding: 10px 18px;
  border-radius: 10px;
  font-weight: 700;
  transition: 0.2s ease;   /* 부드러운 hover */
}
.primary  { background: #2f7a68; color: #fff; }
.secondary{ background: #ebf8f3; color: #1f5a4d; border: 1px solid #9fd6c2; }

.primary:hover {
  background: #1f5a4d;
  transform: translateY(-2px);          /* 살짝 위로 */
  box-shadow: 0 6px 14px rgba(31,90,77,.22);
}
.secondary:hover { background: #dff4ec; }

/* 모바일: 버튼 세로 정렬 */
@media (max-width: 768px) {
  .cta-buttons { flex-direction: column; }
}

📝 수정 전/후 코드 비교

❌ 수정 전 (이미지·버튼 없음)
before
<section class="hero">
  <h1>내 가게</h1>
  <p>가게 소개</p>
</section>
✅ 수정 후 (이미지+버튼)
after
<section class="hero">
  <img src="store.jpg"
       alt="가게"
       class="hero-img">
  <h1>내 가게</h1>
  <p>가게 소개</p>
  <div class="cta-buttons">
    <a href="#menu"
       class="cta-btn primary">
      메뉴 보기
    </a>
    <a href="#contact"
       class="cta-btn secondary">
      문의하기
    </a>
  </div>
</section>
  • img의 src / alt / object-fit 역할을 이해했다
  • href="#id" 앵커 링크 원리를 이해했다
  • text-decoration:none 이 왜 필요한지 알았다
  • transition 속성의 역할을 이해했다
STEP 3실습 미션
요소기능이론
대표 이미지첫 화면에서 가게 정체성 전달시각 계층에서 가장 큰 요소가 첫 시선을 잡습니다.
CTA 주요 버튼방문자가 가장 먼저 눌러야 할 행동 유도버튼 계층(Primary/Secondary)으로 의사결정이 빨라집니다.
hover 상태클릭 가능 요소임을 즉시 인지상태 변화 피드백이 인터랙션 신뢰도를 높입니다.
링크 연결메뉴/문의 구역으로 빠른 이동앵커 이동은 탐색 비용을 줄여 전환율에 긍정적입니다.

미션 목록

  • 미션 1: .hero-img 추가 후 object-fit:cover로 이미지 비율 유지
  • 미션 2: 버튼 2개를 Primary / Secondary 클래스로 분리
  • 미션 3: :hover에서 색상·그림자·transform 변화 추가
  • 미션 4: 버튼 클릭 시 #menu, #contact 섹션으로 이동 연결
  • 미션 5: 모바일(768px 이하)에서 버튼을 세로로 정렬 (flex-direction:column)

🟠 버튼에 밑줄이 생김

증상: <a> 태그 버튼에 파란 밑줄이 그어짐

원인: text-decoration 미제거

.cta-btn { text-decoration: none; }

🟠 hover가 아무 반응 없음

증상: 버튼에 마우스를 올려도 변화 없음

원인: 선택자 오타 또는 transition 누락

.primary:Hover { } ❌
.primary:hover { } ✅ (소문자)

문제 해결 3단계 루틴

① 증상 정리화면에서 무엇이 안 되는지 문장으로 먼저 적는다. (예: "버튼 클릭 시 이동 안 됨")
② 원인 좁히기HTML 구조 문제인지, CSS 스타일 문제인지 구분한다. 개발자 도구(F12)를 열어 확인한다.
③ 수정 후 검증수정 → 저장(Ctrl+S) → 새로고침(F5) → 결과 확인. 이 3단계를 반드시 완료한다.
  • 이미지 경로 오류를 직접 재현하고 해결해봤다
  • text-decoration:none 의 효과를 확인했다
  • 개발자 도구(F12)를 열어서 CSS를 확인해봤다
