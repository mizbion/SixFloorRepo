조건문 — 흐름을 갈래로

if · else if · 논리 연산자 — "만약 ~이면" 코드의 첫 분기점
if / else else if && || ! 삼항 연산자 BMI 측정기
오늘의 학습목표
  1. if / else와 비교 연산자로 조건에 따라 다른 코드를 실행할 수 있다.

2
if / else — 두 갈래의 길
조건이 맞으면 A, 아니면 B

가장 단순한 형태

if_basic.js 
const score = 85;

if (score >= 60) {
    console.log("합격!");
} else {
    console.log("불합격...");
}
// → 합격!
구조:
if (조건) { 참일 때 실행 } else { 거짓일 때 실행 }

비교 연산자 — 결과는 항상 true 또는 false

compare.js 
a === b      // 같다 (값+타입)
a !== b      // 같지 않다
a > b        // 크다
a >= b       // 크거나 같다
a < b        // 작다
a <= b       // 작거나 같다
=== 와 ==의 차이: == 는 타입을 무시해서 헷갈림. (예: 1 == "1" → true). 우린 무조건 ===.

중괄호 빼먹지 마

braces.js 
// 한 줄짜리도 중괄호 쓰는 습관
if (hp <= 0) {
    console.log("게임 오버");
}

// 권장하지 않음 — 나중에 줄 추가할 때 버그 위험
if (hp <= 0) console.log("게임 오버");
점수 입력 (0-100)
합격 기준
결과 위 값을 입력하고 눌러보세요
3
else if — 갈래 늘리기
A / B / C / D / F 같은 다단계 분기

합격/불합격은 두 갈래라 if/else로 충분. 그런데 점수 → 등급(A,B,C,D,F) 처럼 갈래가 많으면?

grade.js 
const score = 85;
let grade;

if (score >= 90) {
    grade = "A";
} else if (score >= 80) {
    grade = "B";
} else if (score >= 70) {
    grade = "C";
} else if (score >= 60) {
    grade = "D";
} else {
    grade = "F";
}

console.log(`등급: ${grade}`);  // → 등급: B
핵심 규칙: 위에서부터 조건을 검사하고, 처음 만족하는 가지 하나만 실행하고 나머지는 건너뛴다.
점수 (0-100)
등급 점수를 입력하고 눌러보세요
4
조건 순서의 함정
왜 90점이 D 등급으로 나오지?

이 코드의 결과를 예측해봐. 95점인 학생을 넣으면?

trap.js 
const score = 95;

if (score >= 60) {
    console.log("D");
} else if (score >= 90) {
    console.log("A");
}
// → D  (왜?)
이유: 95는 60 이상도 만족! 위 조건이 먼저 걸려서 D가 출력된다. else if는 큰 조건부터 작은 조건 순서로 써야 한다.
해결: 위 코드를 90 이상 → 60 이상 순서로 바꾸면 정상 작동. 등급 판정은 항상 큰 점수부터!
5
논리 연산자 — 조건 합치기
&& (그리고), || (또는), ! (아님)

3가지 기호

logic.js 
A && B    // A 그리고 B (둘 다 true여야 true)
A || B    // A 또는 B (하나만 true면 true)
!A         // A의 반대 (true면 false, false면 true)

실전 예제 — 놀이공원 입장 조건

park.js 
const age = 15;
const height = 160;
const hasGuardian = true;

// 14세 이상 그리고 키 150 이상
if (age >= 14 && height >= 150) {
    console.log("바이킹 탑승 가능");
}

// 14세 이상이거나 보호자 동반이면
if (age >= 14 || hasGuardian) {
    console.log("입장 가능");
}

! 의 활용

not.js 
const isLogin = false;

if (!isLogin) {     // 로그인 안 했으면
    console.log("로그인이 필요합니다");
}
읽는 법: !isLogin = "isLogin이 아니다" = "로그인하지 않은 상태"

삼항 연산자 — 한 줄 if
조건 ? 참일때값 : 거짓일때값

간단한 if/else는 한 줄로 줄일 수 있어. 변수에 값을 할당할 때 특히 자주 씀.

ternary.js 
// 기존 방식 — 4줄
let result;
if (score >= 60) {
    result = "합격";
} else {
    result = "불합격";
}

// 삼항 연산자 — 1줄
const result2 = score >= 60 ? "합격" : "불합격";
//                  ↑조건       ↑참일때    ↑거짓일때

console.log(result2);  // → 합격
가장 흔한 사용처: 화면에 보여줄 텍스트 결정 — isStudent ? "학생" : "직장인"
주의: 조건이 복잡해지면 (else if가 3개 이상) 삼항 연산자보다 if/else if가 읽기 좋다. 한 줄에 다 욱여넣지 말 것.

실습: BMI 측정기
조건문 풀세트 + 화면 출력

BMI 계산 공식과 기준

BMI = 몸무게(kg) ÷ 키(m)²

· 18.5 미만 → 저체중
· 18.5 이상 23 미만 → 정상
· 23 이상 25 미만 → 과체중
· 25 이상 → 비만

전체 코드

bmi.html 
<div id="result"></div>

<script>
    const height = 170;   // cm
    const weight = 65;    // kg

    // 1단계: BMI 계산 (cm → m로 변환)
    const heightM = height / 100;
    const bmi = weight / (heightM * heightM);

    // 2단계: 등급 판정
    let grade;
    if (bmi < 18.5) {
        grade = "저체중";
    } else if (bmi < 23) {
        grade = "정상";
    } else if (bmi < 25) {
        grade = "과체중";
    } else {
        grade = "비만";
    }

    // 3단계: 화면에 출력
    const html = `
        <h1>BMI ${bmi.toFixed(1)}</h1>
        <p>키: ${height}cm / 몸무게: ${weight}kg</p>
        <p>상태: ${grade}</p>
    `;
    document.getElementById("result").innerHTML = html;
</script>
toFixed(1): 소수점 첫째 자리까지만 표시. 22.4912... → "22.5"

AI에게 CSS 디자인 부탁하기
결과 화면을 의료 앱 느낌으로

BMI 결과 화면을 좀 더 건강·의료 앱 느낌으로 만들고 싶어. 1일차에 배운 방식으로 AI에게 부탁하자.

예시 프롬프트 — 그대로 복사해서 AI에게 보내봐

아래 HTML BMI 결과 카드에 CSS를 적용해줘.

[HTML]
<div id="result">
    <h1>BMI 22.5</h1>
    <p>키: 170cm / 몸무게: 65kg</p>
    <p>상태: 정상</p>
</div>

[요구사항]
- 분위기: 건강·의료 앱, 깔끔하고 신뢰감 있게
- 메인 컬러: 민트/녹색 계열
- 너비: 최대 360px, 가운데 정렬
- BMI 숫자는 크게 강조 (40px 이상)
- 카드 모양: 라운드 + 옅은 그림자
- 상태 글자에 따라 색을 바꾸고 싶다면 "정상=초록"으로

CSS만 <style> 태그 안에 작성해서 답변해줘.

실습 미션 — 너만의 분위기로 변형

① 위 프롬프트의 분위기·메인 컬러를 바꿔봐 (다크모드 / 핑크 / 레트로 게임풍 등)
② 받은 CSS를 BMI 측정기 HTML <head> 안에 붙여넣기
③ 친구와 결과를 비교 — 같은 데이터인데 어떻게 다르게 보이는지
심화: AI에게 "상태에 따라 카드 배경색이 자동으로 바뀌게 해줘"라고 추가 요청하면, 자바스크립트와 CSS를 연결한 더 멋진 코드를 받을 수 있다. (코드 그대로 이해 안 돼도 일단 붙여보고 동작 확인!)
