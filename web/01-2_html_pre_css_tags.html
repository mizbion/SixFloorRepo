왜 이 태그들을 먼저 배울까?

구조를 먼저 잡으면 CSS가 쉬워지는 이유

CSS는 "무엇을 꾸밀지"를 선택해서 적용합니다. HTML 구조가 어설프면 원하는 요소만 선택하기 어려워요. 그래서 시맨틱 태그 와 폼/표 기본 태그를 먼저 알아두면 이후 CSS 선택자, 레이아웃, 반응형을 훨씬 쉽게 배울 수 있습니다.
  • header/nav/main/section 같은 구조 태그는 CSS 타겟을 명확하게 만듭니다.
  • label-input 연결을 알면 폼 디자인 전에 접근성을 확보할 수 있습니다.
  • table의 thead/tbody를 구분하면 표 스타일링이 훨씬 깔끔해집니다.
2

시맨틱 레이아웃 태그

div만 쓰지 말고 의미 태그를 함께 쓰기

태그 의미 언제 사용?
<header> 문서/섹션의 머리말 사이트 제목, 로고, 상단 소개
<nav> 주요 이동 메뉴 메뉴 링크 묶음
<main> 문서의 핵심 본문 페이지마다 바뀌는 핵심 콘텐츠
<section> 주제별 구획 소개, 공지, 후기 등 덩어리 분리
<article> 독립적으로 읽히는 글 게시글, 뉴스 카드, 리뷰 항목
<aside> 부가 정보 영역 광고, 관련 링크, 사이드 정보
<footer> 문서/섹션의 꼬리말 저작권, 연락처, 하단 메뉴
팁: div를 완전히 버리는 게 아니라, 의미가 분명할 때는 시맨틱 태그를 우선 사용합니다.
<body>
  <header>
    <h1>오늘의 레시피</h1>
  </header>

  <nav>
    <a href="#soup">국물요리</a>
    <a href="#rice">밥요리</a>
  </nav>

  <main>
    <section id="soup">
      <article>
        <h2>된장찌개</h2>
        <p>간단한 집밥 메뉴</p>
      </article>
    </section>
  </main>

  <footer>2026 Cooking Class</footer>
</body>

텍스트 의미 태그

보이기보다 의미 전달이 중요한 태그

태그 포인트
<mark> 하이라이트 표시
<small> 보조/주의 문구
<time> 날짜/시간 정보
<abbr> 약어와 풀네임 제공
<blockquote> 긴 인용문
<q> 짧은 인용문
<code> 코드 조각
<pre> 공백/줄바꿈 유지 
<p>오늘의 키워드: <mark>Semantic HTML</mark></p>
<p><small>실습 파일은 수업 종료 후 삭제됩니다.</small></p>
<p>개강일: <time datetime="2026-04-05">2026년 4월 5일</time></p>
<p><abbr title="HyperText Markup Language">HTML</abbr>은 웹 문서 언어입니다.</p>
<blockquote>좋은 구조는 좋은 스타일의 출발점이다.</blockquote>
<p>선생님이 말했어요: <q>태그 의미부터 생각하자.</q></p>
<p><code>&lt;section&gt;</code> 태그를 기억하세요.</p>

표(Table) 기초 태그

표를 만들 때 최소한 이 구조는 기억하기

<table> 안에 제목은 <caption>, 헤더 행은 <thead>, 데이터 본문은 <tbody>로 나누면 CSS에서 스타일을 주기 훨씬 쉽습니다. 
<table>
  <caption>주간 학습 계획</caption>
  <thead>
    <tr>
      <th>요일</th>
      <th>학습 내용</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>월</td>
      <td>HTML 복습</td>
    </tr>
    <tr>
      <td>화</td>
      <td>CSS 선택자 시작</td>
    </tr>
  </tbody>
</table>

폼(Form) 기초 태그

CSS 전에 꼭 잡아야 하는 폼 구조

태그 핵심 역할
<form> 입력 묶음 전체
<label> 입력칸 설명 연결
<input> 한 줄 입력
<textarea> 여러 줄 입력
<select> + <option> 선택 목록
<button> 동작 실행 버튼
<fieldset> + <legend> 관련 입력 그룹화 
<form>
  <fieldset>
    <legend>수강 신청</legend>

    <label for="name">이름</label>
    <input id="name" type="text" />

    <label for="track">트랙</label>
    <select id="track">
      <option>프론트엔드</option>
      <option>백엔드</option>
    </select>

    <label for="memo">메모</label>
    <textarea id="memo" rows="3"></textarea>

    <button type="submit">제출</button>
  </fieldset>
</form>
팁: label의 for 값과 input의 id 값을 맞추면 클릭 영역이 넓어져 사용성이 좋아집니다.

CSS 전 최소 실습 과제

아래 조건을 만족하는 HTML만 먼저 작성해보기

  • header, nav, main, section, footer를 각각 1회 이상 사용
  • 글 안에 mark, time, abbr 중 2개 이상 사용
  • table에 caption, thead, tbody를 포함
  • form에 label-input 연결(for/id) 최소 2개 이상
  • button 1개와 textarea 1개 포함
<!-- 목표: CSS 없이도 구조가 읽히는 HTML 만들기 -->
<header>...</header>
<nav>...</nav>
<main>
  <section>...</section>
  <section>
    <table>...</table>
  </section>
  <section>
    <form>...</form>
  </section>
</main>
<footer>...</footer>
다음 단계: 이 구조를 바탕으로 CSS에서 선택자(tag, class, id)를 적용해 레이아웃과 디자인을 입혀봅시다.
