메모장 vs VS Code

왜 VS Code를 써야 할까?

🤔 코딩 도구가 왜 중요할까?

HTML 파일은 사실 메모장으로도 만들 수 있습니다.
하지만 공사할 때 맨손과 전동공구 중 어느 쪽이 나을까요?
VS Code는 코딩을 위해 만들어진 전문 도구입니다.
항목 📝 메모장 💻 VS Code
색상 구분 전부 검정색 태그·속성·값을 색으로 구분 ✅
자동완성 없음 태그 이름 몇 글자만 치면 자동 완성 ✅
오류 표시 모름 잘못된 코드에 빨간 밑줄 표시 ✅
실시간 미리보기 직접 브라우저 열어야 함 저장하면 바로 브라우저에 반영 ✅
가격 무료 무료 ✅
💡
VS Code는 Microsoft가 만든 무료 에디터로, 전 세계 개발자의 70% 이상이 사용합니다.

VS Code 설치하기

공식 사이트에서 무료로 다운로드

📦 설치 순서

1
브라우저에서 code.visualstudio.com 접속
또는 구글에서 "VS Code 다운로드" 검색
2
Windows용 다운로드 버튼 클릭 → .exe 파일 실행
3
설치 옵션에서 아래 두 가지 반드시 체크
바탕화면에 아이콘 추가   PATH에 추가 (code 명령어 사용)
4
설치 완료 후 VS Code 실행 → 초록색 시작 화면 확인
⚠️
설치 중 "PATH에 추가" 옵션을 꼭 체크하세요. 나중에 터미널에서 code . 명령어로 폴더를 바로 열 수 있습니다.
3

기본 환경 설정

한국어 팩 & 테마 적용

🌏 한국어 팩 설치

1
왼쪽 사이드바에서 블록 모양 아이콘(확장) 클릭
또는 단축키 Ctrl + Shift + X
2
검색창에 "Korean" 입력
Korean Language Pack for VS Code → Install 클릭
3
우측 하단 팝업에서 "Restart and Switch to Korean" 클릭

🎨 테마(배경색) 바꾸기

테마는 에디터의 색 배경을 바꿔요. 눈이 편한 테마를 골라보세요.
1
단축키 Ctrl + K → Ctrl + T
2
목록에서 원하는 테마 선택
추천: Dark+(기본 다크) · One Dark Pro(인기) · GitHub Light(밝은 테마)
💡
확장 프로그램에서 One Dark Pro나 Dracula 같은 유명 테마를 추가로 설치할 수도 있어요.

필수 확장 프로그램

웹개발을 10배 편하게 만들어주는 도구들

🔌 꼭 설치할 확장 4가지

🌐
Live Preview 필수
저장할 때마다 브라우저 화면이 자동으로 새로고침됩니다. 웹개발 필수 도구.
🎨
Prettier 필수
저장 시 코드 들여쓰기·띄어쓰기를 자동으로 정리해 줍니다. 코드가 항상 깔끔하게 유지돼요.
🌈
Auto Rename Tag
여는 태그 이름을 바꾸면 닫는 태그도 자동으로 같이 바뀝니다.
💡
HTML CSS Support
HTML 파일에서 CSS 클래스 이름을 자동완성해 줍니다.
✅
Live Preview 설치 후 사용법: HTML 파일을 열고 우측 상단의 미리보기 아이콘 클릭 → 오른쪽에 브라우저 화면이 나타납니다. 이제 코드를 저장(Ctrl+S)할 때마다 자동으로 반영돼요!

첫 HTML 파일 만들기

Emmet으로 5초 만에 기본 구조 완성

📁 폴더 & 파일 만들기

1
바탕화면에 web-class 폴더 생성
2
VS Code 실행 → 파일 → 폴더 열기 → web-class 폴더 선택
3
왼쪽 탐색기 패널에서 새 파일 아이콘 클릭 → 파일명 index.html 입력

⚡ Emmet — 느낌표 하나로 기본 구조 완성

! 를 입력하고 Tab 키를 누르면 HTML 기본 구조가 자동으로 완성됩니다.
이게 바로 Emmet — VS Code에 내장된 HTML 단축 문법이에요.
입력
! + Tab 
!
자동 완성 결과
index.html 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Document</title>
</head>
<body>

</body>
</html>
⚠️
lang="en" 부분을 lang="ko"로 바꿔주세요. 우리 페이지는 한국어로 만들 거니까요!

✍️ Hello World 작성 & Live Preview 확인

index.html — 첫 작성 
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>나의 첫 웹페이지</title>
</head>
<body>

  <h1>안녕하세요! 👋</h1>
  <p>제 첫 번째 웹페이지입니다.</p>

</body>
</html>
1
위 코드를 입력하고 Ctrl + S로 저장
2
우측 상단 🌐 미리보기 아이콘 클릭 (Live Preview)
3
오른쪽에 "안녕하세요! 👋" 가 보이면 성공!
4
h1 안의 텍스트를 내 이름으로 바꾸고 저장 → 미리보기가 자동으로 바뀌는지 확인
🎉
축하해요! VS Code에서 HTML 파일을 만들고 브라우저에 띄우는 데 성공했습니다.
