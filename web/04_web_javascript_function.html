왜 함수가 필요한가?
3일차 주사위 코드, 다시 본다

3일차에 만든 주사위 굴리는 코드를 떠올려봐.

repeat.js 
// 주사위 1번 굴리기
const dice1 = Math.floor(Math.random() * 6) + 1;
// 주사위 또 1번 굴리기
const dice2 = Math.floor(Math.random() * 6) + 1;
// 또 한 번...
const dice3 = Math.floor(Math.random() * 6) + 1;

같은 코드를 또 쓰고, 또 쓰고… 만약 주사위 범위를 1~10으로 바꾸려면? 모든 자리를 다 찾아 고쳐야 해. 한 군데만 빠뜨려도 버그.

with_function.js 
// 한 번만 정의해두면 — 이름으로 부르기만 하면 끝
function rollDice() {
    return Math.floor(Math.random() * 6) + 1;
}

const dice1 = rollDice();
const dice2 = rollDice();
const dice3 = rollDice();
함수(function) = 코드 묶음에 이름을 붙인 것. 한 번 만들어두면 그 이름으로 몇 번이고 부를 수 있다. 수정도 한 곳에서만.
비유: 함수는 전자레인지. "재료 넣고 → 버튼 누르고 → 결과 받기". 매번 회로를 새로 만들 필요 없이 버튼 한 번이면 끝.

함수 선언과 호출
만들기 vs 부르기 — 둘은 다르다

가장 단순한 함수

declare.js 
// 1단계: 선언 (만드는 단계 — 아직 실행 안 됨!)
function sayHello() {
    console.log("안녕하세요!");
}

// 2단계: 호출 (실제로 부르는 단계 — 이제 실행)
sayHello();    // → 안녕하세요!
sayHello();    // → 안녕하세요!
sayHello();    // → 안녕하세요!
꼭 외울 것: 함수 이름 뒤에 괄호 ()가 있어야 호출. 괄호 빼면? 함수 자체를 가리킬 뿐 실행 안 됨.

함수 이름 짓기 규칙

naming.js 
// ✅ 좋은 이름 — 동사로 시작, 무엇을 하는지 명확
function rollDice() { ... }
function getStudentName() { ... }
function calculateTotal() { ... }

// ❌ 나쁜 이름 — 추상적, 줄임말, 동사 아님
function do1() { ... }       // 뭐 하는지 모름
function data() { ... }      // 동사 아님
function 한글이름() { ... }    // 가능은 하지만 권장 안 함
관례: 함수 이름은 소문자로 시작 + 두 단어 이상이면 첫 글자만 대문자(camelCase). getStudentName처럼.

매개변수 — 함수에 값 넣기
parameter (받는 자리) vs argument (넣는 값)

인사 메시지가 매번 똑같으면 재미없어. 이름을 받아서 다른 메시지를 출력해보자.

parameter.js 
// 괄호 안 name = "매개변수" (값을 받을 자리)
function greet(name) {
    console.log(`안녕, ${name}!`);
}

// 호출할 때 넣는 값 = "인자"
greet("길동");    // → 안녕, 길동!
greet("영희");    // → 안녕, 영희!
greet("철수");    // → 안녕, 철수!

"길동"
→
매개변수 (받는 자리)
name

매개변수 여러 개

multiple_params.js 
function introduce(name, age, hobby) {
    console.log(`${name}, ${age}살, 취미는 ${hobby}`);
}

introduce("길동", 19, "롤");
// → 길동, 19살, 취미는 롤

// 순서가 중요!

return — 함수가 값을 돌려준다
결과를 변수에 담을 수 있게 됨

지금까지 함수는 출력만 했어. 그런데 함수의 진짜 힘은 결과를 돌려받는 것이야.

return.js 
function add(a, b) {
    return a + b;     // 결과를 "돌려준다"
}

// 돌려받은 값을 변수에 담을 수 있다
const result = add(3, 5);
console.log(result);    // → 8

// 또 다른 계산에 바로 쓸 수도 있다
const total = add(10, 20) + add(5, 7);
console.log(total);     // → 42
입력 (인자)
3, 5
→
처리
a + b
→
출력 (return)

return의 또 다른 효과 — 함수 종료

early_return.js 
function checkAge(age) {
    if (age < 0) {
        return "잘못된 나이";   // 여기서 함수 종료
    }
    if (age < 19) {
        return "미성년자";
    }
    return "성인";
}

console.log(checkAge(-5));   // → 잘못된 나이
console.log(checkAge(15));   // → 미성년자
console.log(checkAge(25));   // → 성인
return 만나면 끝! 그 줄 뒤로 함수 안의 코드는 실행되지 않는다. 조건에 따라 빨리 빠져나오는 데 유용.
숫자 a
숫자 b
return 두 값을 입력하고 눌러보세요
5
console.log vs return
학생들이 가장 많이 헷갈리는 부분

둘 다 함수 안에서 자주 쓰이지만 전혀 다른 일을 한다.

log_vs_return.js 
// A: console.log만 쓰는 함수
function addLog(a, b) {
    console.log(a + b);    // 화면에 보여주기만
}

const x = addLog(3, 5);
// 콘솔: 8 (출력됨)
console.log(x);            // → undefined  (받을 게 없음!)

// B: return을 쓰는 함수
function addReturn(a, b) {
    return a + b;            // 결과를 돌려주기
}

const y = addReturn(3, 5);
// 콘솔: 아무것도 안 찍힘
console.log(y);            // → 8  (변수에 담겨 있음!)
핵심 차이:
· console.log → 화면(콘솔)에 보여주고 끝. 변수에 담을 수 없음.
· return → 화면엔 안 보이지만 결과를 돌려준다. 변수에 담거나 다른 계산에 쓸 수 있음.
팁: 함수 안에서 계산 결과를 다른 코드에서 또 쓸 거면 return, 그냥 보여주기만 할 거면 console.log. 보통은 return을 쓰고, 받은 값을 밖에서 console.log하는 게 정석.
6
화살표 함수 — 짧고 간결한 ES6
앞으로 우리는 이걸 메인으로 쓴다

똑같은 함수를 화살표 함수(arrow function)로 쓰면 훨씬 짧아져. 모던 JS의 표준이야.

arrow.js 
// 기존 방식 (function 선언식)
function add(a, b) {
    return a + b;
}

// 화살표 함수 (변수에 담기)
const add = (a, b) => {
    return a + b;
};

// 한 줄짜리는 더 짧게! (return 생략 + 중괄호 생략)
const add = (a, b) => a + b;

// 호출 방법은 동일
add(3, 5);    // → 8

화살표 함수 변형 패턴

arrow_patterns.js 
// 1. 매개변수 없을 때 — 빈 괄호
const sayHi = () => console.log("안녕");

// 2. 매개변수 1개일 때 — 괄호 생략 가능
const double = n => n * 2;
// 또는: const double = (n) => n * 2;  ← 같은 코드

// 3. 매개변수 2개 이상 — 괄호 필수
const mul = (a, b) => a * b;

// 4. 본문이 여러 줄 — 중괄호 + return
const grade = (score) => {
    if (score >= 90) return "A";
    if (score >= 80) return "B";
    return "C";
};
외울 패턴: const 함수이름 = (매개변수) => 결과식
한 줄로 끝나는 작은 함수에 특히 잘 어울린다.
왜 화살표 함수? ① 짧다 ② 모던 JS의 표준 ③ 다음 차시 배열 메서드(map/filter)에서 빛을 발한다. 지금부터 친해져 두자.

기본값 매개변수 — 빠뜨려도 안전하게
인자를 안 넣어도 동작하는 함수

인자를 안 주면 어떻게 될까?

missing_arg.js 
const greet = (name) => console.log(`안녕, ${name}!`);

greet();    // → 안녕, undefined!  (어색...)

매개변수에 기본값을 정해주면 인자 없이 호출해도 안전해.

default_param.js 
// 매개변수 옆에 = 기본값
const greet = (name = "손님") =>
    console.log(`안녕, ${name}!`);

greet();              // → 안녕, 손님!
greet("길동");        // → 안녕, 길동!  (인자 있으면 그게 우선)

// 여러 매개변수도 각각 기본값 가능
const rollDice = (max = 6) =>
    Math.floor(Math.random() * max) + 1;

rollDice();      // → 1~6  (기본값 사용)
rollDice(10);    // → 1~10 (10면 주사위)
rollDice(100);   // → 1~100
실전: 자주 쓰는 값을 기본으로 정해두면 코드가 깔끔. 사용자 정원 = 100명, 페이지당 항목 = 10개 등.
8
실습: 랜덤 이름 뽑기
발표자 정하기 / 조 짜기에 진짜 쓰는 도구

요구사항

① 학생 이름 배열을 입력 (예: 길동, 영희, 철수, 민지...)
② 함수 pickOne()이 그중 한 명을 무작위로 뽑아 return
③ 함수 showResult()가 화면에 큰 글씨로 표시
④ "다시 뽑기" 버튼으로 또 굴리기

전체 코드

name_picker.html 
<div id="result"></div>
<button onclick="pick()">다시 뽑기</button>

<script>
    // 학생 명단 (배열은 다음 차시에 자세히!)
    const students = ["길동", "영희", "철수", "민지", "준호"];

    // 함수 ① 한 명 뽑기 (return으로 결과 돌려주기)
    const pickOne = (list) => {
        const idx = Math.floor(Math.random() * list.length);
        return list[idx];
    };

    // 함수 ② 화면에 표시
    const showResult = (name) => {
        document.getElementById("result").innerHTML =
            `<h1>🎉 ${name} </h1>`;
    };

    // 함수 ③ 두 함수를 묶어서 한 번에 실행 (button onclick에서 호출)
    const pick = () => {
        const picked = pickOne(students);
        showResult(picked);
    };

    // 페이지 열리자마자 한 번 뽑기
    pick();
</script>
학습 흐름 종합: 함수 3개로 역할을 나눴어. pickOne(뽑기), showResult(보여주기), pick(둘을 합치기). 함수 하나당 한 가지 일만 — 깔끔한 코드의 시작.
배열 미리보기: students[idx]로 배열의 idx번째 값을 꺼낼 수 있다. list.length는 배열 길이. 배열은 다음 차시(Day 05)에 본격 학습!

AI에게 CSS 디자인 부탁하기
발표자 발표 화면처럼 두근거리게

이름 뽑기 결과 화면을 좀 더 이벤트 추첨 화면처럼 꾸며보자. 두근두근하게.

예시 프롬프트 — 그대로 복사해서 AI에게 보내봐

아래 HTML 랜덤 이름 뽑기 화면에 CSS를 적용해줘.

[HTML]
<div id="result">
    <h1>🎉 길동 🎉</h1>
</div>
<button onclick="pick()">다시 뽑기</button>

[요구사항]
- 분위기: 이벤트 추첨, 발표 무대 같은 느낌
- 메인 컬러: 보라/핑크 그라데이션 + 살짝 화려하게
- 이름은 매우 크게 표시 (60px 이상)
- 이름이 표시될 때 살짝 튀어오르는 애니메이션 (transform scale + opacity)
- 버튼: 호버 시 색이 변하고 약간 커지는 효과
- 가운데 정렬, 모바일에서도 잘 보이게

CSS만 <style> 태그 안에 작성해서 답변해줘.
