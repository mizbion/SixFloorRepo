CSS란? & 연결 방법

HTML에 스타일을 입히는 언어

🎨 CSS = 웹페이지의 옷

CSS(Cascading Style Sheets)는 HTML 요소의 색상, 크기, 위치, 폰트 등 모양을 정의합니다.
HTML이 "여기에 제목이 있다"고 하면, CSS는 "그 제목은 파란색, 24px, 가운데 정렬"이라고 말해요.
CSS 문법 구조
h1선택자(누구에게)
{ 
color속성(무엇을)
: 
blue값(어떻게)
; 
} 
💡
선택자: 스타일 적용 대상  |  속성: 바꾸고 싶은 것  |  값: 어떻게 바꿀지

🔗 CSS 연결하는 3가지 방법

① 외부 파일 연결 ⭐ 추천
HTML <head> 안에 작성 
<link rel="stylesheet"
     href="style.css">

HTML과 CSS 분리 — 실무 표준

② <style> 태그 (수업에서 주로 사용)
head 안에 직접 작성 
<style>
  h1 {
    color: blue;
  }
</style>
③ 인라인 스타일 — 태그에 직접 (테스트용) 
<h1 style="color: blue; font-size: 24px;">제목</h1>
2

선택자 (Selector)

어떤 요소에 스타일을 적용할지 지정

🎯 3가지 핵심 선택자

선택자 사용법 적용 대상 언제 쓰나?
태그 h1 { } 모든 <h1> 태그 전체 태그에 동일 스타일
클래스 .card { } class="card" 인 요소 여러 요소에 같은 스타일 ⭐ 자주 사용
아이디 #header { } id="header" 인 요소 페이지에서 딱 하나인 요소
선택자 비교 예제 
/* ① 태그 선택자 */
p { color: gray; }

/* ② 클래스 선택자 */
.highlight { background: yellow; }

/* ③ 아이디 선택자 */
#title { font-size: 32px; }
HTML에 클래스·아이디 적용하기 
<p class="highlight">노란 배경이 됩니다</p>
<p class="highlight">이것도 노란 배경</p>
<h1 id="title">32px 제목</h1>
💜
클래스(.)는 여러 요소에 적용 가능, 아이디(#)는 페이지에 딱 하나만. 실무에서는 클래스를 훨씬 많이 씁니다.

색상 & 폰트 & 텍스트

가장 자주 쓰는 CSS 속성들

🌈 색상 지정하는 3가지 방법

색상 표기 방법 
/* ① 색상 이름 */
color: red;        color: skyblue;

/* ② HEX 코드 (가장 많이 씀) */
color: #1d4ed8;    /* 파랑 */
color: #ff5733;    /* 주황 */

/* ③ RGB */
color: rgb(255, 87, 51);

✍️ 폰트 & 텍스트 속성

font-size
글자 크기
font-size: 16px;
font-weight
글자 굵기 (100~900)
font-weight: bold;
font-family
글꼴 종류
font-family: sans-serif;
color
글자 색상
color: #333;
text-align
텍스트 정렬
text-align: center;
line-height
줄 간격
line-height: 1.6;
text-decoration
밑줄, 취소선 등
text-decoration: none;
background-color
배경 색상
background-color: #f0f0f0;
폰트 & 텍스트 예제 
h1 {
  font-size:   32px;
  color:       #1d4ed8;
  text-align:  center;
}
p {
  font-size:   16px;
  line-height: 1.8;
  color:       #374151;
}
a {
  text-decoration: none;  /* 밑줄 제거 */
}

박스모델

CSS의 핵심 — 모든 요소는 박스다

📦 박스모델이란?

HTML의 모든 요소는 사실 네모난 박스입니다.
이 박스는 4개의 레이어로 구성돼요: content → padding → border → margin
margin (바깥 여백)
border (테두리)
padding (안쪽 여백)
content (내용)
📦 content

실제 텍스트·이미지가 들어가는 영역.
width, height로 크기 조절

🟩 padding (안쪽 여백)

content와 border 사이 공간.
배경색이 padding 영역까지 채워짐

🔴 border (테두리)

요소 주위를 감싸는 선.
굵기·스타일·색상 지정 가능

🟡 margin (바깥 여백)

요소와 요소 사이의 공간.
배경색이 margin엔 적용 안 됨

📐 margin / padding / border 사용법

박스모델 속성 예제 
.box {
  width:           300px;
  height:          150px;
  /* 안쪽 여백 — 상하 16px, 좌우 24px */
  padding:         16px 24px;
  /* 바깥 여백 — 위쪽만 20px */
  margin:          20px 0 0 0;
  /* 테두리 — 굵기 스타일 색상 */
  border:          2px solid #3b82f6;
  /* 모서리 둥글게 */
  border-radius:   8px;
  background-color: #eff6ff;
}
💡
padding/margin 단축 표기
값 1개: 상하좌우 모두  |  값 2개: 상하 좌우  |  값 4개: 상 우 하 좌 (시계방향)
border 스타일 종류 
border: 2px solid  #333;  /* 실선 ━━━ */
border: 2px dashed #333;  /* 점선 ╌╌╌ */
border: 2px dotted #333;  /* 점점 ······ */
