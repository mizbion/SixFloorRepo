HTML이란?

웹페이지의 뼈대를 만드는 언어

🌐 HTML = 웹의 뼈대

HTML (HyperText Markup Language)은 웹페이지의 내용과 구조를 정의하는 언어입니다.
집으로 비유하면 HTML은 골조(뼈대), CSS는 인테리어(꾸미기), JavaScript는 전기·수도(동작)입니다.
🏗️ HTML
제목, 단락, 이미지, 링크 등
내용과 구조를 담당
🎨 CSS
색상, 크기, 위치 등
꾸미기를 담당 (다음 차시)
💡
브라우저(크롬, 엣지 등)는 HTML 파일을 읽어서 우리가 보는 웹페이지로 변환해줍니다. VS Code에서 저장한 .html 파일이 곧 웹페이지예요!

태그(Tag) 구조

HTML의 가장 기본 단위

🏷️ 태그란?

태그는 꺾쇠 괄호 < > 안에 이름을 쓴 것입니다.
여는 태그와 닫는 태그가 내용을 감싸는 구조예요.
태그 구조 해부
<h1> 여는 태그
안녕하세요 내용(content)
</h1> 닫는 태그 (/ 포함)
태그 기본 예제 
<!-- 여는태그 + 내용 + 닫는태그 -->
<h1>큰 제목입니다</h1>
<p>단락(문단) 내용이에요</p>
<strong>굵게 표시</strong>

<!-- 속성(attribute)이 있는 태그 -->
<a href="https://google.com">구글로 이동</a>
<img src="photo.jpg" alt="사진 설명">  <!-- 닫는 태그 없음 -->
⚠️
자기 닫힘 태그(Self-closing) — <img>, <br>, <hr>, <input> 은 내용이 없어서 닫는 태그가 필요 없습니다.
💡
속성(attribute)은 태그에 추가 정보를 줍니다. href는 링크 주소, src는 이미지 파일 경로, alt는 이미지 대체 텍스트예요.

head와 body

HTML 파일의 두 가지 영역

📄 HTML 기본 뼈대

<!DOCTYPE html>← HTML5 문서 선언
<html lang="ko">← 문서 시작, 언어 설정
<head>← 브라우저 설정 (화면에 안 보임)
<meta charset="UTF-8">← 한글 깨짐 방지
<title>페이지 제목</title>← 탭에 표시되는 제목
</head>
<body>← 화면에 보이는 내용 전부
<h1>제목</h1>
<p>단락</p>
</body>
</html>

🧠 <head>

  • 브라우저에게 문서 정보를 전달
  • 화면에 직접 표시되지 않음
  • <meta> — 인코딩, 반응형 설정
  • <title> — 탭 제목
  • <link> — CSS 파일 연결

👁️ <body>

  • 실제로 화면에 보이는 모든 것
  • 제목, 글, 이미지, 버튼, 링크
  • 우리가 앞으로 주로 작성할 영역
  • 비어 있으면 흰 화면만 보임
나를 소개하는 첫 페이지 
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width">
  <title>김철수의 소개 페이지</title>
</head>
<body>
  <h1>안녕하세요! 👋</h1>
  <p>저는 김철수입니다. 웹개발을 배우고 있어요.</p>
</body>
</html>

자주 쓰는 태그들

제목 · 단락 · 링크 · 이미지 · 목록

📝 제목 태그 — h1 ~ h6

숫자가 작을수록 더 큰 제목입니다. <h1>이 가장 크고 <h6>이 가장 작아요.
한 페이지에 <h1>은 하나만 쓰는 것이 좋습니다.
제목 태그 
<h1>가장 큰 제목 (페이지 대제목)</h1>
<h2>중간 제목 (섹션 제목)</h2>
<h3>소제목</h3>
<h4>더 작은 소제목</h4>
가장 큰 제목
중간 제목
소제목
더 작은 소제목
↑ 브라우저 렌더링 결과

📝 단락 · 줄바꿈 · 강조

태그 의미 미리보기
<p> 단락 (Paragraph) — 문단을 만들어요
첫 번째 문단입니다.

두 번째 문단입니다.
<br> 줄바꿈 — 닫는 태그 없음
첫 줄
줄바꿈 후 두 번째 줄
<strong> 굵게 강조 (중요한 내용)
이것은 중요합니다
<em> 기울임 강조 (emphasis)
이것은 기울임입니다
⚠️
HTML에서 Enter키를 눌러도 줄바꿈이 안 됩니다. 줄바꿈은 반드시 <br>을, 새 문단은 <p>를 써야 해요.

🔗 링크 · 🖼️ 이미지

링크 태그 
<!-- 외부 링크 -->
<a href="https://naver.com">
  네이버로 이동
</a>

<!-- 새 탭에서 열기 -->
<a href="https://naver.com"
   target="_blank">
  새 탭으로 열기
</a>
이미지 태그 
<!-- 로컬 이미지 -->
<img
  src="photo.jpg"
  alt="내 사진"
  width="300"
>

<!-- 인터넷 이미지 -->
<img
  src="https://..."
  alt="온라인 이미지"
>
💜
alt 속성은 이미지가 안 보일 때 대신 표시되는 텍스트입니다. 시각장애인용 스크린리더도 alt를 읽어줘요 — 항상 작성하는 습관을 들이세요!

div & span

내용을 묶는 컨테이너 태그

📦 div와 span의 차이

<div>와 <span>은 의미 없이 내용을 묶는 태그입니다.
CSS로 꾸밀 때 특정 영역을 구분하기 위해 사용해요.
태그 특징 주로 사용
<div> 블록(block) 요소 — 줄 전체를 차지, 다음 요소는 아래 줄로 레이아웃 구역 나누기, 카드 영역, 섹션 구분
<span> 인라인(inline) 요소 — 내용 크기만큼만 차지, 줄 안에서 나란히 문장 안 일부 텍스트만 꾸밀 때
div & span 비교 
<!-- div: 줄 전체 차지 -->
<div style="background:lightblue">첫 번째 박스</div>
<div style="background:lightgreen">두 번째 박스</div>

<!-- span: 줄 안에서 나란히 -->
<p>오늘 날씨는 
  <span style="color:red">맑음</span>
입니다.</p>
첫 번째 박스
두 번째 박스

오늘 날씨는 맑음입니다.
