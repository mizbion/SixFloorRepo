JavaScript 1

자바스크립트 : 웹페이지의 동작을 만들어요.

HTML = 구조 CSS = 스타일 JavaScript = 동작

관계 도식: 3요소가 합쳐져 웹페이지 완성

동작 흐름: 브라우저에서 실제 실행 순서

1. 수업 목표

  • script 태그의 역할과 실행 흐름을 설명할 수 있다.
  • 변수, 연산자, 조건문, 반복문, 함수를 작성할 수 있다.
  • DOM 선택과 클릭 이벤트를 연결해 화면을 바꿀 수 있다.

3. 단계별 실습 (각 STEP 연습예제 3개)

아래 예제는 모두 복사해 단일 html 파일로 저장 후 바로 실행하세요.

STEP A. script 태그와 출력

연습예제 1: alert 기본

<!DOCTYPE html> <html> <head> <title>JS Test</title> </head> <body> <script> alert("자바스크립트 실행 확인"); </script> </body> </html>

연습예제 2: console.log 기본

<!DOCTYPE html> <html> <head> <title>JS Test</title> </head> <body> <script> console.log("콘솔 출력 테스트"); console.log("두 번째 줄 출력"); </script> </body> </html>

연습예제 3: body 끝 script 위치

<!DOCTYPE html> <html> <head> <title>JS Test</title> </head> <body> <h1>문서 로딩 테스트</h1> <script> document.body.style.backgroundColor = "#f0f9ff"; </script> </body> </html>

STEP B. 변수와 자료형

연습예제 1: 문자열/숫자/불리언

<!DOCTYPE html> <html> <head> <title>JS Test</title> </head> <body> <script> let shopName = "모모 디저트랩"; let menuPrice = 5800; let isOpen = true; console.log(shopName, menuPrice, isOpen); </script> </body> </html>

연습예제 2: 변수 값 변경

<!DOCTYPE html> <html> <head> <title>JS Test</title> </head> <body> <script> let stock = 10; console.log("변경 전:", stock); stock = 7; console.log("변경 후:", stock); </script> </body> </html>

연습예제 3: typeof 확인

<!DOCTYPE html> <html> <head> <title>JS Test</title> </head> <body> <script> let name = "준호"; let age = 17; let active = false; console.log(typeof name); console.log(typeof age); console.log(typeof active); </script> </body> </html>

STEP C. 연산자와 조건문

연습예제 1: 산술연산

<!DOCTYPE html> <html> <head> <title>JS Test</title> </head> <body> <script> let price = 4500; let count = 3; let total = price * count; console.log("총 금액:", total); </script> </body> </html>

연습예제 2: if / else 분기

<!DOCTYPE html> <html> <head> <title>JS Test</title> </head> <body> <script> let score = 78; if (score >= 80) { console.log("합격"); } else { console.log("보충 필요"); } </script> </body> </html>

연습예제 3: else if 분기

<!DOCTYPE html> <html> <head> <title>JS Test</title> </head> <body> <script> let temp = 27; if (temp >= 30) { console.log("덥다"); } else if (temp >= 20) { console.log("적당하다"); } else { console.log("쌀쌀하다"); } </script> </body> </html>

STEP D. 반복문과 함수

연습예제 1: for 반복문

<!DOCTYPE html> <html> <head> <title>JS Test</title> </head> <body> <script> for (let i = 1; i <= 5; i++) { console.log(i + "번째 출력"); } </script> </body> </html>

연습예제 2: 매개변수 함수

<!DOCTYPE html> <html> <head> <title>JS Test</title> </head> <body> <script> function greet(name) { console.log(name + "님 환영합니다."); } greet("민지"); greet("준호"); </script> </body> </html>

연습예제 3: return 함수

<!DOCTYPE html> <html> <head> <title>JS Test</title> </head> <body> <script> function add(a, b) { return a + b; } let result = add(3, 5); console.log("합계:", result); </script> </body> </html>

STEP E. 이벤트와 DOM

연습예제 1: 버튼 클릭 시 문구 변경

<!DOCTYPE html> <html> <head> <title>JS Test</title> </head> <body> <button id="btn">실행</button> <p id="text">대기중</p> <script> const btn = document.getElementById("btn"); const text = document.getElementById("text"); btn.addEventListener("click", function () { text.textContent = "실행 완료"; }); </script> </body> </html>

연습예제 2: 버튼 클릭 시 색상 변경

<!DOCTYPE html> <html> <head> <title>JS Test</title> </head> <body> <button id="color-btn">배경 변경</button> <script> const colorBtn = document.getElementById("color-btn"); colorBtn.addEventListener("click", function () { document.body.style.backgroundColor = "#ecfeff"; }); </script> </body> </html>

연습예제 3: 입력값 읽어 화면에 출력

<!DOCTYPE html> <html> <head> <title>JS Test</title> </head> <body> <input id="name-input" placeholder="이름 입력" /> <button id="show-btn">확인</button> <p id="msg"></p> <script> const input = document.getElementById("name-input"); const showBtn = document.getElementById("show-btn"); const msg = document.getElementById("msg"); showBtn.addEventListener("click", function () { msg.textContent = input.value + "님, 반갑습니다."; }); </script> </body> </html>

진행 팁: 각 예제마다 "문구 변경 1개 + 숫자 변경 1개 + 기능 추가 1개"를 반드시 수행하면 학습 효과가 큽니다.

2) 이 코드에 적용할 JS 코드 (별도 입력)

<script> const form = document.querySelector(".order-form"); const item = document.getElementById("item"); const buyerName = document.getElementById("buyer-name"); const buyerEmail = document.getElementById("buyer-email"); const buyerRequest = document.getElementById("buyer-request"); form.addEventListener("submit", function (e) { e.preventDefault(); if (!item.value || !buyerName.value.trim() || !buyerEmail.value.trim()) { alert("필수 항목(상품, 이름, 이메일)을 모두 입력하세요."); return; } const summary = "주문 접수: " + item.options[item.selectedIndex].text + " / 이름: " + buyerName.value.trim() + " / 이메일: " + buyerEmail.value.trim(); let feedback = document.getElementById("js-feedback"); if (!feedback) { feedback = document.createElement("p"); feedback.id = "js-feedback"; feedback.style.marginTop = "10px"; feedback.style.fontWeight = "700"; feedback.style.color = "#0b5c56"; form.appendChild(feedback); } feedback.textContent = summary; console.log("요청사항:", buyerRequest.value.trim()); form.reset(); }); </script>

체크 포인트: JS 추가 전에는 제출 버튼이 새로고침만 발생하지만, JS 추가 후에는 필수검사 + 주문요약 문구 출력이 동작합니다.
