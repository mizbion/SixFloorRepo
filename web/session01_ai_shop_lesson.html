AI와 함께 미래의 내 가게 소개페이지 만들기

카페, 디저트샵, 게임샵, 향수 브랜드, 굿즈 스토어처럼 내가 운영하고 싶은 가게를 상상하고, AI로 초안을 만든 뒤 직접 수정해 한 장짜리 소개페이지로 완성합니다.

도구: VS Code + AI + 브라우저 산출물: index.html 1개 핵심: 생성보다 분석·수정
STEP 1 가게 콘셉트 정하고 파일 준비하기
  1. 바탕화면에 폴더를 만들고 이름을 my-shop으로 변경
  2. VS Code → 파일 → 폴더 열기 → my-shop 선택
  3. 새 파일 만들기 → 이름을 index.html로 저장
  4. 가게 이름, 업종, 대표 상품 2개, 원하는 분위기 1개를 적어두기
카페/디저트샵 따뜻한 색, 메뉴 카드, 감성 소개 문구가 잘 어울립니다.
게임/굿즈 스토어 진한 색상, 버튼, 배너 구성 연습에 좋습니다.
향수/패션 브랜드 분위기 있는 소개 문장과 상품 카드 연습에 좋습니다.
⚠ 시작 전에 정할 4가지 가게 이름, 업종, 대표 상품, 분위기를 먼저 적어두면 AI 결과가 훨씬 구체적으로 나옵니다.
  • my-shop 폴더를 만들었다
  • index.html 파일이 폴더 안에 있다
  • 가게 이름, 업종, 대표 상품을 정했다
STEP 2 딱 3가지만 알고 시작하기

① 가게 소개페이지 기본 구조

가게 소개페이지는 제목 영역, 소개 영역, 대표 상품 영역, 하단 정보 영역으로 나누면 시작하기 쉽습니다.

<header>가게 이름, 한 줄 소개</header> <main> <section>가게 소개</section> <section>대표 상품</section> <section>방문 안내 또는 문의</section> </main> <footer>운영 시간, 위치, 제작일</footer>
처음부터 쇼핑몰 전체를 만들 필요는 없습니다. 오늘은 한 장짜리 소개페이지 하나만 완성하면 됩니다.

② 가게 페이지에 꼭 들어갈 정보

내용이 길기보다, 첫 화면에서 바로 보이는 핵심 정보가 중요합니다.

가게 이름: 모모 디저트랩 한 줄 소개: 기분이 좋아지는 작은 디저트 가게 대표 상품: 딸기 케이크, 바닐라 쿠키 분위기: 따뜻함, 귀여움, 밝은 느낌 버튼 문구: 메뉴 보기 / 문의하기
AI는 재료를 줘야 잘 만듭니다. "예쁘게"보다 "우드톤 카페 느낌"처럼 구체적으로 말하세요.

STEP 4 코드 직접 고쳐보기

AI가 만든 초안을 그대로 제출하지 말고, 내 가게답게 최소 3군데 이상 수정합니다.

수정 포인트 ① 가게 내용 바꾸기

가게 이름, 소개 문구, 상품 이름을 내 아이디어로 바꿉니다.

❌ 그대로 두기
<h1>모모 디저트랩</h1>
✅ 내 가게로 바꾸기
<h1>네온 게임 스토어</h1>

수정 포인트 ② 색과 버튼 바꾸기

배경색, 제목색, 버튼 문구 중 하나씩 바꾸면 분위기가 확 달라집니다.

body { background-color: #fff7ef; } h1 { color: #8a4a19; } button { background: #c26a2d; color: white; border-radius: 10px; }

STEP 5 완성하고 제출하기

아래 항목이 보이면 1회차 목표는 충분히 달성한 것입니다.

A. 가게 콘셉트 완성

가게 이름, 업종, 한 줄 소개가 화면에 보입니다.

가게 이름 1개 · 소개 문장 1개 · 대표 상품 2개 이상

B. 구조 완성

header, main, section, footer로 페이지가 나뉘어 있어야 합니다.

section 제목(h2) 포함 · footer에 간단한 하단 정보 표시

C. 직접 수정 기록

AI 코드를 그대로 쓰지 않고 직접 바꾼 내용을 남깁니다.

수정 전 1줄 / 수정 후 1줄 / 이유 1문장 — 3세트 이상

D. 프롬프트 개선

처음 프롬프트와 더 구체적으로 바꾼 프롬프트를 함께 제출합니다.

역할 · 목표 · 입력 · 제약 · 출력형식 5요소 포함

E. 화면 캡처

브라우저에서 보이는 결과 화면을 캡처합니다.

가게 이름과 대표 상품 영역이 함께 보이게 캡처

F. 다음 주 준비

다음 주에는 CSS로 더 예쁘게 꾸밀 예정이므로 원하는 색상 테마를 정합니다.

예: 우드톤, 네온톤, 민트톤, 블랙톤 중 1개 선택
  • 브라우저에서 가게 소개페이지가 깨지지 않고 잘 보인다
  • 대표 상품 또는 대표 서비스가 2개 이상 보인다
  • 직접 수정 기록 3세트를 작성했다
  • 화면 캡처를 저장했다
다음 단계 예고 2회차에는 CSS로 색상, 여백, 카드 디자인을 다듬어서 정말 가게 사이트 같은 느낌이 나게 만듭니다.
