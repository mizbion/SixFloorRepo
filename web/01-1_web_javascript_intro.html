1
JS는 뭐 하는 애?
HTML은 뼈대, CSS는 옷, JS는…?

너네가 만든 카페 웹사이트가 있다고 하자. HTML로 글자랑 이미지 자리를 잡았고, CSS로 색이랑 모양을 예쁘게 꾸몄어. 근데… 버튼을 눌러도 아무 일도 안 일어나.

JavaScript는 웹페이지의 "동작"을 담당한다. 버튼 클릭 시 메뉴가 펼쳐지고, 입력값을 검사하고, 화면이 바뀌는 모든 것 — JS의 영역.

오늘은 그 첫걸음이야. 화려한 동작은 다음 시간부터. 오늘은 JS가 데이터(숫자·글자)를 어떻게 다루는지부터 배운다.

비유: HTML = 사람의 뼈대, CSS = 옷과 화장, JS = 움직임과 말과 행동. 셋이 합쳐져야 살아있는 웹페이지가 된다.

코드는 어디서 실행하지?
브라우저 콘솔 + script 태그

방법 1. 브라우저 콘솔 (가장 빠름)

크롬에서 F12 누르거나 우클릭 → "검사" → 상단의 Console 탭. 여기에 코드 한 줄씩 쳐서 바로 실행 가능.

콘솔에 입력 
console.log("안녕, 자바스크립트!");  // → 안녕, 자바스크립트!

방법 2. HTML 파일에 script 태그

실제 웹페이지에서 동작하려면 HTML에 연결해야 해.

index.html 
<!DOCTYPE html>
<html>
<body>
    <h1>내 첫 페이지</h1>

    <script>
        console.log("페이지가 열렸어요!");
    </script>
</body>
</html>
위치가 중요! </body> 바로 위에 <script>를 두는 게 정석. 이유는 다음 차시에 DOM 배울 때.

변수: 데이터를 담는 상자
let과 const, 둘 중 뭘 쓸까?

게임에서 캐릭터의 HP가 100이라고 하자. 이걸 코드로 어떻게 기억하지? → 변수에 담는다.

variables.js 
let hp = 100;        // 변할 수 있는 값 → let
const name = "용사";  // 변하지 않는 값 → const

console.log(hp);    // → 100
console.log(name);  // → 용사

hp = 80;            // let은 재할당 OK
// name = "마법사";   ← const는 에러!
고르는 법: 일단 const부터. 값이 바뀌어야 할 때만 let으로 바꾼다. (실수 줄이는 습관)
var는 잊어라. 옛날 키워드. 인터넷에서 var를 봐도 따라 쓰지 마. 우리는 let / const만 쓴다.

데이터 타입 3종 세트
숫자(Number) · 문자열(String) · 불리언(Boolean)
types.js 
// 1. 숫자 — 따옴표 없음
const age = 19;
const price = 2500.5;

// 2. 문자열 — 따옴표 필수 (", ', ` 셋 다 OK)
const name = "홍길동";
const hobby = '게임';

// 3. 불리언 — true / false 둘 중 하나
const isStudent = true;
const isAdult = false;

console.log(typeof age);        // → "number"
console.log(typeof name);       // → "string"
console.log(typeof isStudent);  // → "boolean"
typeof는 변수의 타입을 알려주는 명령어. 헷갈릴 때 콘솔에서 한 번 찍어보면 끝.
따옴표를 빼먹으면 어떻게 될까? const name = 홍길동; → 에러. 컴퓨터는 "홍길동"이라는 변수를 찾으려다 없어서 멈춘다.
값을 입력해서 타입 확인
typeof 위 값을 입력하고 눌러보세요
힌트: 숫자만 입력하면 number, "안녕"처럼 따옴표로 감싸면 string, true/false면 boolean.

연산자와 형변환
+ 가 늘 더하기는 아니다

산술 연산자

arithmetic.js 
console.log(10 + 3);   // → 13
console.log(10 - 3);   // → 7
console.log(10 * 3);   // → 30
console.log(10 / 3);   // → 3.333...
console.log(10 % 3);   // → 1  (나머지)

문자열에서 + 의 함정

trap.js 
console.log(10 + 3);       // → 13   (숫자+숫자=덧셈)
console.log("10" + 3);     // → "103" (문자열+숫자=이어붙이기!)
console.log("안녕" + " 길동"); // → "안녕 길동"
입력창에서 받은 값은 무조건 문자열이다. input.value로 받은 "10"과 3을 더하면 "103". 계산하려면 Number()로 변환!

형변환

convert.js 
const a = "10";
const b = 3;

console.log(Number(a) + b);  // → 13  (문자열을 숫자로)
console.log(a + String(b));  // → "103" (숫자를 문자열로)

비교 연산자 — 결과는 불리언

compare.js 
console.log(10 > 5);    // → true
console.log(10 === 10);  // → true  (값 + 타입 비교)
console.log(10 === "10"); // → false (타입 다름)
=== 를 써라. == 도 있지만 헷갈리는 결과를 만든다. JS는 무조건 ===, !==.

템플릿 리터럴 — 백틱의 마법
변수랑 글자, 깔끔하게 합치기

"내 이름은 길동이고 나이는 19살" 같은 문장을 만들고 싶어. + 로 이어붙이는 방법은… 솔직히 보기 싫어.

old_way.js 
const name = "길동";
const age = 19;

// 옛날 방식 — 따옴표와 + 가 너무 많음
const msg1 = "내 이름은 " + name + "이고 나이는 " + age + "살";
new_way.js 
// 템플릿 리터럴 — 백틱(`) + ${변수}
const msg2 = `내 이름은 ${name}이고 나이는 ${age}살`;

console.log(msg2);  // → 내 이름은 길동이고 나이는 19살

백틱이 대체 뭔데?

JS에서 문자열을 감싸는 방법은 3가지. 그런데 이 셋이 다 다르게 생겼고 역할도 미묘하게 달라.

three_quotes.js 
const a = "큰따옴표";     // " "  Shift + '
const b = '작은따옴표';    // ' '  엔터 키 왼쪽 두 번째
const c = `백틱`;          // ` `  숫자 1 왼쪽, ESC 아래
백틱(`) 위치 찾기: 키보드 왼쪽 위 구석, 숫자 1 왼쪽이자 ESC 키 바로 아래. 한영 키 옆에도 있음. Shift 안 누르고 그냥 누르면 ` 가 나와야 정상. (안 나오면 한/영 키 확인!)
가장 흔한 실수: 백틱(`)을 작은따옴표(')로 잘못 쓰는 것. 모양이 비슷해서 글자 하나만 봐서는 헷갈려. '안녕 ${name}' 이렇게 작은따옴표를 쓰면 ${name}이 그대로 글자로 나온다 (변수로 안 바뀜).

백틱만 가능한 3가지 마법

① ${변수}로 값 끼워넣기

interpolation.js 
const name = "길동";

// ${ } 안에 변수 이름을 넣으면 → 그 자리에 값이 들어간다
console.log(`안녕, ${name}!`);   // → 안녕, 길동!

// 작은따옴표로 쓰면? 변환 안 됨!
console.log('안녕, ${name}!');   // → 안녕, ${name}!  (그대로 글자)

② ${ } 안에 계산식도 OK

expression.js 
const price = 15000;
const qty = 3;

// ${ } 안에는 변수뿐 아니라 계산식, 함수 호출도 가능
console.log(`총액: ${price * qty}원`);          // → 총액: 45000원
console.log(`평균: ${(85 + 90 + 75) / 3}점`);   // → 평균: 83.33...점

③ 줄바꿈도 그대로 살아있음

multiline.js 
// 백틱은 여러 줄 OK
const letter = `안녕하세요.
오늘 날씨가 좋네요.
- 길동 드림`;

console.log(letter);
// → 안녕하세요.
//   오늘 날씨가 좋네요.
//   - 길동 드림

// 큰따옴표는? → 줄바꿈하면 에러!
// const x = "한 줄
//           두 줄";   ❌ SyntaxError
특히 유용한 곳: 이따 만들 자기소개 카드처럼 HTML 코드를 변수에 담을 때. 여러 줄 HTML을 따옴표 + 줄바꿈 \n으로 연결하면 지옥이지만, 백틱으로는 그냥 보이는 그대로 쓰면 끝.

한눈에 비교

기능 " " ' ' ` ` (백틱)
기본 문자열 ✅ ✅ ✅
${변수} 끼워넣기 ❌ ❌ ✅
여러 줄 작성 ❌ ❌ ✅
계산식 ${a + b} ❌ ❌ ✅
결론: 변수가 들어갈 일이 조금이라도 있으면 무조건 백틱. 단순한 글자만 있어도 백틱 써도 문제 없음. "기본은 백틱"으로 외우자.

실습: 자기소개 카드 만들기
오늘 배운 거 다 모아서 한 번에

오늘의 종합 실습. 너의 정보를 변수에 담고, 템플릿 리터럴로 한 문단을 만들어 화면에 띄워보자.

1단계 — HTML 준비

profile.html 
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>자기소개</title>
</head>
<body>
    <div id="card"></div>

    <script>
        // 여기에 JS 코드
    </script>
</body>
</html>

2단계 — JS로 데이터 만들기

script 안에 작성 
// 자기 정보 (자유롭게 바꿔!)
const name = "홍길동";
const age = 19;
const hobby = "롤";
const dream = "프론트엔드 개발자";
const isStudent = true;

// 템플릿 리터럴로 카드 내용 만들기
const cardHTML = `
    <h1>${name}</h1>
    <p>${age}살 · ${isStudent ? "학생" : "직장인"}</p>
    <p>취미: ${hobby}</p>
    <p>꿈: ${dream}</p>
`;

// 화면에 표시
document.getElementById("card").innerHTML = cardHTML;
마지막 줄의 document.getElementById는 다음 차시에 자세히 배운다. 오늘은 "이렇게 쓰면 화면에 보이는구나" 정도만!

AI에게 CSS 디자인 부탁하기
JS는 우리가, 디자인은 AI가

위에서 만든 자기소개 카드, HTML 구조와 데이터는 우리가 JS로 만들었다. 이제 멋진 디자인이 필요해. CSS 잘 모른다고? AI에게 부탁하자.

이게 바로 AI 시대 개발자의 방식. 핵심 로직(JS)은 직접 짜고, 디자인이나 반복 작업은 AI에게 맡긴다. 단, AI에게 잘 설명해야 좋은 결과가 나옴.

좋은 프롬프트의 3요소

① 무엇을 (대상) ② 어떻게 (스타일/분위기) ③ 어떤 형식으로 (CSS만? 인라인? 파일?)

예시 프롬프트 — 그대로 복사해서 AI에게 보내봐

아래 HTML 자기소개 카드에 CSS를 적용해줘.

[HTML]
<div id="card">
    <h1>홍길동</h1>
    <p>19살 · 학생</p>
    <p>취미: 롤</p>
    <p>꿈: 프론트엔드 개발자</p>
</div>

[요구사항]
- 분위기: 깔끔하고 모던, 핑크 계열
- 너비: 최대 320px, 가운데 정렬
- 카드 모양: 라운드 코너 + 옅은 그림자
- 폰트: 한글이 잘 보이는 sans-serif
- 모바일에서도 깨지지 않게

CSS만 <style> 태그 안에 작성해서 답변해줘.

AI가 이렇게 답해줄 거야 (예시)

style.css (AI 응답 예시) 
/* AI가 만들어준 CSS — 그대로 붙여넣기 */
#card {
    max-width: 320px;
    margin: 40px auto;
    padding: 28px;
    background: #fff1f3;
    border-radius: 16px;
    box-shadow: 0 4px 12px rgba(190,18,60,0.1);
    font-family: 'Noto Sans KR', sans-serif;
}
#card h1 {
    color: #be123c;
    margin-bottom: 12px;
}
#card p {
    color: #7a6068;
    margin: 6px 0;
}

실습 미션 — 너만의 CSS 받기

해야 할 일:
① 위 7번 실습에서 만든 카드를 그대로 사용
② 위 프롬프트를 너만의 분위기로 수정 (예: 핑크 → 네온 / 모던 → 레트로 / 그림자 → 굵은 테두리)
③ AI(Claude, ChatGPT 등)에 보내고 받은 CSS를 HTML <head> 안에 붙여넣기
④ 같은 데이터인데 카드 모습이 어떻게 달라졌는지 친구와 비교해보기
주의! AI가 준 코드를 그대로 받지 말고 한 줄씩 읽으면서 "이게 무슨 뜻이지?" 생각해. CSS는 다음 학기에 더 깊이 배우니까, 오늘은 "이런 게 있구나" 수준이면 충분.
프로 팁: AI에게 다시 부탁할 때 — "방금 그 CSS에서 카드 배경을 그라데이션으로 바꿔줘" / "h1 폰트를 더 크고 굵게 해줘" / "다크 모드 버전도 만들어줘". 이렇게 이어가는 대화가 효과적.
