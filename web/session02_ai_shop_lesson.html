색상, 크기, 여백 적용

STEP 2 1차시: CSS 핵심 3요소 익히기

① 색상 테마 3색 규칙

브랜드색, 배경색, 글자색 3개만 먼저 고정하면 화면이 안정됩니다.

:root { --brand: #2f7a68; --bg: #f7faf8; --ink: #1d2a26; } body { background: var(--bg); color: var(--ink); } button { background: var(--brand); color: #fff; }

② 가독성 우선 타이포

제목 크기와 본문 크기를 분리해 읽는 흐름을 만듭니다.

h1 { font-size: 2rem; } h2 { font-size: 1.35rem; } p, li { font-size: 1rem; line-height: 1.7; }

③ 카드와 버튼으로 정보 구분하기

소개글은 카드, 행동 유도는 버튼으로 시선 흐름을 설계합니다.

.card { background: #ffffff; border: 1px solid #d9e8e2; border-radius: 12px; padding: 16px; } button { border: 0; border-radius: 10px; padding: 10px 14px; cursor: pointer; }
1차시 완료 기준 배경색, 제목 크기, 카드 스타일, 버튼 스타일이 모두 바뀌어야 합니다.
  • CSS 변수 3개(브랜드/배경/글자)를 적용했다
  • 제목과 본문의 글자 크기를 분리했다
  • 카드와 버튼 스타일을 추가했다

📝 CSS 스타일 적용 포인트

CSS 변수와 기본 스타일 추가로 완성도 있는 페이지가 만들어집니다:

수정 전 (기본 스타일)
<style>
body {
  background: white;
  color: black;
}
h1 { font-size: 1rem; }
button {
  background: gray;
}
</style>
수정 후 (CSS 변수+스타일)
<style>
:root {
  --brand: #2f7a68;
  --bg: #f7faf8;
  --ink: #1d2a26;
}
body {
  background: var(--bg);
  color: var(--ink);
}
h1 { font-size: 2rem; }
button {
  background: var(--brand);
  color: white;
  border-radius: 10px;
}
.card {
  border: 1px solid #d9e8e2;
  border-radius: 12px;
  padding: 16px;
}
</style>

STEP 5 2회차 제출 패키지

2회차는 "스타일 완성도"가 핵심입니다. 아래 항목을 모두 준비해 제출합니다.

A. 스타일 테마 정의

브랜드색/배경색/텍스트색 3가지를 확정합니다.

CSS 변수 또는 코드로 3색이 코드에 명시되어야 함

B. 가독성 개선

제목과 본문의 크기, 줄간격을 조정합니다.

h1/h2/p 스타일 구분 + 읽기 가능한 줄간격

C. 카드와 버튼 정리

카드 테두리/여백, 버튼 시각 강조를 적용합니다.

카드 스타일 1세트 + 버튼 스타일 1세트 필수

D. 직접 수정 기록

AI 결과에서 직접 손본 항목을 기록합니다.

수정 전 1줄 / 수정 후 1줄 / 이유 1문장 - 3세트

E. 비교 캡처

수정 전 화면과 수정 후 화면을 각각 캡처합니다.

같은 위치 화면 전/후 2장

F. 다음 회차 준비

3회차 카드 레이아웃을 위해 대표 상품 3개 정보를 준비합니다.

상품명/설명/가격(또는 대표문구) 3세트
  • 브랜드 색상 3개가 화면 전체에 일관되게 보인다
  • 카드와 버튼이 시각적으로 구분된다
  • 직접 수정 기록 3세트를 작성했다
  • 수정 전/후 화면 캡처를 저장했다
다음 단계 예고 3회차에서는 대표 상품 3개를 카드 컴포넌트로 구성하고, 카드 간격과 배치를 더 전문적으로 다룹니다.
