GitHub가 뭔가요?

코드를 저장하고 공유하는 세계 최대 플랫폼

🐙 GitHub = 코드의 구글 드라이브

GitHub는 코드 파일을 인터넷에 저장하고 관리하는 서비스입니다.
구글 드라이브에 문서를 저장하듯, GitHub에는 코드를 저장해요.
그리고 GitHub Pages 기능을 켜면 저장한 HTML 파일이 바로 웹사이트가 됩니다!
📁 일반 파일 저장
구글 드라이브 → 문서 저장
GitHub → 코드 저장
🌐 GitHub Pages
저장한 HTML 파일을
웹사이트로 자동 변환
🐙
GitHub는 전 세계 1억 명 이상의 개발자가 사용하는 서비스입니다.
취업 후에도 매일 사용하게 될 도구이니, 지금 익혀두면 큰 자산이 됩니다!

🎯 오늘 수업이 끝나면

내 웹사이트 주소 (예시)
https://홍길동123.github.io/web-class
이 주소로 전 세계 어디서나 내 페이지를 볼 수 있어요!
✅
앞으로 수업에서 만드는 모든 결과물을 이 주소 하나로 올릴 거예요. 부모님께도 자랑할 수 있습니다!

GitHub 계정 만들기

딱 5분이면 완료!

👤 회원가입 전 준비

GitHub 계정을 만들기 전에 아이디를 미리 정해두세요.
이 아이디가 나중에 내 웹사이트 주소의 일부가 됩니다!
✏️ 아이디 규칙
  • 영어 소문자, 숫자, 하이픈(-)만 사용 가능
  • 한글, 특수문자, 띄어쓰기 불가
  • 예시: gildong-hong / kim2025 / student-chulsoo
  • 나중에 변경 가능하지만, URL도 같이 바뀌므로 신중하게 정하기
⚠️
아이디에 본명 전체나 전화번호를 넣지 마세요. 공개 프로필이라 누구나 볼 수 있어요.

📝 회원가입 순서

1
github.com 접속
크롬 브라우저를 열고 주소창에 github.com 을 입력하고 Enter를 누르세요.
오른쪽 위의 Sign up 버튼을 클릭합니다.
2
이메일 주소 입력
본인의 이메일 주소를 입력하세요.
학교 이메일이나 개인 이메일 모두 가능합니다.
Enter email 내이메일@gmail.com
3
비밀번호 만들기
영문 + 숫자 + 특수문자 조합으로 15자 이상 또는 숫자 포함 8자 이상으로 만드세요.
⚠️ 비밀번호는 반드시 어딘가에 적어두세요. 잊어버리면 찾기 번거롭습니다!
4
아이디(Username) 입력
미리 정해둔 아이디를 입력합니다.
이미 누군가 쓰고 있으면 빨간 메시지가 뜨니 다른 이름으로 바꿔보세요.
Username gildong-hong ✓
5
이메일 수신 여부 선택
이메일 광고 수신 여부를 묻는 질문입니다.
n을 입력하고 넘어가면 됩니다.
6
로봇 확인 (퍼즐 풀기)
"Verify your account" 화면에서 간단한 퍼즐을 풀어요.
화면에 나오는 그림을 클릭하거나 맞추면 됩니다. 어렵지 않아요!
7
이메일 인증
입력한 이메일로 인증 코드가 발송됩니다.
이메일을 열어서 6자리 숫자를 복사해 붙여넣으세요.
📧
이메일이 안 보이면 스팸함을 확인해보세요. "GitHub" 발신 메일을 찾으면 돼요.
8
설문 화면 건너뛰기
직업, 사용 목적 등을 묻는 화면이 나옵니다.
아무거나 선택하거나, 아래 "Skip personalization"을 클릭해도 됩니다.
🎉 가입 완료!
이제 github.com에서 내 프로필 페이지를 볼 수 있어요.

저장소(Repository) 만들기

코드를 담을 나만의 폴더

📁 저장소(Repository)란?

저장소(레포지토리, Repository)는 GitHub에 만드는 프로젝트 폴더입니다.
컴퓨터의 web-class 폴더처럼, GitHub에도 같은 이름의 저장소를 만들 거예요.

📂 저장소 만드는 순서

1
새 저장소 만들기 클릭
GitHub 메인 화면에서 왼쪽 위의 초록색 Create Repository 버튼을 클릭합니다.
또는 오른쪽 위 + 버튼 → New repository를 선택해도 됩니다.
2
저장소 이름 입력
Repository name 칸에 아래와 같이 입력하세요.
Repository name web-class
⚠️
이름은 반드시 web-class 로 입력하세요. 나중에 URL이 .../web-class 로 만들어집니다. 띄어쓰기 없이, 하이픈(-)으로 연결!
3
Public 선택 확인
Public / Private 중에서 Public이 선택되어 있는지 확인하세요.
Public이어야 나중에 GitHub Pages로 공개 웹사이트가 됩니다.
● Public — 누구나 볼 수 있음 ✅ (이것 선택!)
○ Private — 나만 볼 수 있음
4
README 추가 체크
아래로 스크롤해서 "Add a README file" 항목에 체크를 합니다.
이걸 체크해야 저장소가 빈 상태가 아니라 바로 사용할 수 있어요.
5
Create repository 클릭
맨 아래 초록색 Create repository 버튼을 클릭합니다.
저장소가 만들어지면 이런 화면이 나타납니다 →
github.com / 내아이디 / web-class
📁 web-class Public
─────────────────────────────
📄 README.md Initial commit

HTML 파일 올리기

지난 시간에 만든 index.html을 업로드

📤 파일 업로드 순서

📂
지난 시간 VS Code에서 만든 index.html 파일이 준비되어 있어야 해요. web-class 폴더 안에 있는 파일입니다.
1
Add file 버튼 클릭
저장소 페이지에서 Add file 버튼을 클릭합니다.
드롭다운 메뉴에서 "Upload files"를 선택하세요.
2
파일 끌어다 놓기 (드래그 앤 드롭)
파일 탐색기에서 index.html 파일을 찾아서
GitHub 업로드 화면의 점선 박스 안으로 끌어다 놓으세요.
또는 "choose your files"를 클릭해서 파일을 선택해도 됩니다.
📄
여기에 index.html을 끌어다 놓으세요
또는 choose your files 클릭
3
Commit changes 클릭
파일이 올라가면 아래쪽에 Commit changes 버튼이 보입니다.
버튼 위의 텍스트는 건드리지 말고, 바로 초록색 버튼을 클릭하세요.
💡
Commit은 "저장하고 기록하기"입니다. 구글 드라이브의 저장 버튼과 같아요. 파일을 바꿀 때마다 Commit을 해야 GitHub에 반영됩니다.
업로드 완료 후 저장소 모습
github.com / 내아이디 / web-class
📄 index.html Upload files
📄 README.md Initial commit

GitHub Pages 켜기

코드를 웹사이트로 변환하는 마법 설정

🌐 Pages 설정 순서

1
Settings 탭 클릭
저장소 페이지 상단 탭 중에서 ⚙️ Settings를 클릭합니다.
주의: 오른쪽 위 계정 설정이 아니라, 저장소 안의 Settings 탭입니다!
2
Pages 메뉴 찾기
Settings 화면에서 왼쪽 메뉴를 보면 Code and automation 섹션 아래에
Pages 항목이 있습니다. 클릭하세요.
3
Branch 설정하기
Source 항목 아래의 드롭다운 버튼을 클릭합니다.
None으로 되어있는 것을 main으로 바꾸세요.
Branch: main ▼ / (root) ▼
4
Save 클릭
Save 버튼을 클릭하면 설정이 저장됩니다.
5
1~2분 기다리기
GitHub가 파일을 웹사이트로 변환하는 데 1~2분 정도 걸립니다.
잠시 기다렸다가 페이지를 새로고침(F5)하면 아래처럼 URL이 나타납니다.
✅ 배포 완료 메시지
🌐 Your site is live at
https://내아이디.github.io/web-class
⏳
메시지가 아직 안 보이면 조금 더 기다렸다가 F5로 새로고침하세요. 최대 5분까지 걸릴 수 있어요.

🔍 내 URL 확인하는 방법

GitHub Pages URL은 항상 이 형식입니다:
https://내 아이디.github.io/저장소이름
예시 — 아이디가 gildong-hong 이고 저장소가 web-class 인 경우
https://gildong-hong.github.io/web-class
이 주소를 크롬 주소창에 붙여넣고 Enter!
❗
주소창에 http://가 아닌 https://로 시작하는지 확인하세요.
404 오류가 뜨면 아직 배포 중이니 1~2분 기다렸다가 다시 시도하세요.
