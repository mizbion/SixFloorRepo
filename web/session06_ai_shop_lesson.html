개념 핵심 개념 — 폼은 연결 정확도가 먼저

폼을 만들 때 디자인보다 먼저 지켜야 할 것이 있습니다.
label의 for 값과 input의 id 값이 정확히 같아야 합니다.
굿즈 샵에서는 "어떤 상품을 주문하고 싶은지"처럼 선택형 입력(<select>)도 자주 씁니다.

① label-for / input-id 연결

두 값이 같아야 라벨 클릭 시 입력칸으로 커서가 이동합니다. 연결이 끊기면 클릭해도 반응이 없습니다.

② required 속성

필수 입력칸에 required를 붙이면 빈 칸 제출 시 브라우저가 자동으로 경고를 표시합니다.

③ select — 상품 선택

굿즈 항목처럼 선택지가 고정될 때 <select>를 씁니다.
<option>으로 선택지를 나열합니다.

④ textarea — 요청사항

"추가 요청사항"처럼 자유 입력이 필요한 칸은 <textarea>를 사용합니다.
rows로 기본 높이를 지정합니다.

속성 / 태그역할예시
for / id라벨↔입력칸 연결 (값 동일 필수)for="buyer-name" ↔ id="buyer-name"
required필수 입력, 빈 값 제출 차단<input required>
type="email"이메일 형식 자동 검증<input type="email">
select / option드롭다운 선택 목록<select><option>키링</option>...</select>
textarea여러 줄 자유 텍스트 입력<textarea rows="3"></textarea>
placeholder입력칸 내부 힌트 텍스트placeholder="예: 홍길동"
STEP 1 AI 요청 프롬프트 — 폼 추가 전 전체 페이지 생성

폼을 추가하기 전, 지금까지 배운 내용이 모두 반영된 굿즈 샵 페이지를 AI에게 먼저 만들어달라고 요청합니다.
1~5회차에서 배운 - 시맨틱 태그, CSS 변수, Flexbox, 반응형, 카드 컴포넌트, CTA 버튼, object-fit - 등을 직접 조건으로 써서 AI가 정확하게 구현하도록 합니다.
이 단계에서는 폼을 넣지 않습니다. #order 섹션에는 연락처 텍스트만 남겨두고, STEP 3에서 직접 폼으로 교체합니다.

🟢 프롬프트 — 굿즈 샵 소개페이지 전체 코드 생성 
너는 HTML/CSS 웹페이지 제작 튜터야.

아래 조건에 맞는 굿즈 샵 소개페이지를 index.html 한 파일로 만들어줘.
주문/문의 폼은 포함하지 않는다.

[가게 정보 — 아래를 내 정보로 바꿔 입력하세요]
- 가게 이름: 블루문 굿즈샵
- 업종: 캐릭터·일러스트 굿즈 판매
- 한 줄 소개: 덕질하는 일상을 더 귀엽게
- 대표 상품 3개: 아크릴 키링 ₩8,000 / 홀로그램 스티커 세트 ₩4,500 / 캔버스 에코백 ₩18,000
- 분위기 키워드: 다크 퍼플, 별빛, 몽환적인 느낌
- 브랜드 컬러: #6c4fd4

[HTML 구조 조건]
- 시맨틱 태그 사용: header, main, section, footer
- header 안에 가게 이름, 한 줄 소개, CTA 버튼 2개 (상품 보기 / 주문 문의)
- main 안에 section 3개:
    · class="about"         : 가게 소개 텍스트
    · id="goods"            : 대표 상품 카드 3개
    · id="order"            : "주문 문의" 제목 + 연락처 텍스트만 (폼 없이)
- footer 안에 운영 안내, SNS 링크, 제작자 정보

[CSS 조건]
- :root에 CSS 변수 선언: --brand(브랜드색), --bg(배경색), --ink(글자색)
- body에 background: var(--bg), color: var(--ink) 적용
- 상품 카드 .product-card:
    · 상품명(.product-name) / 설명(.product-desc) / 가격(.product-price) 구조
    · border, border-radius: 10px, padding 포함
    · 가격은 var(--brand) 색상으로 강조
- <main>에 display: flex, gap 적용해 3열 가로 배치
- 각 section에 flex: 1 적용해 동일 너비 유지
- @media (max-width: 768px) 에서 flex-direction: column 으로 1열 전환
- 대표 이미지 .hero-img: width: 100%, height: 220px, object-fit: cover, border-radius 포함
- CTA 버튼 2개:
    · .cta-primary  : 배경색 채움, 브랜드 컬러 텍스트
    · .cta-secondary: 배경 투명, 흰색 테두리·텍스트
    · 두 버튼 모두 :hover 스타일 포함
- text-decoration: none, display: inline-block 으로 링크를 버튼처럼 표시

[출력 형식]
- 설명 없이 실행 가능한 HTML 코드만 출력
- <!DOCTYPE html>부터 </html>까지 전체 출력

▶ 완성 결과 미리보기 — 라벨 클릭해서 포커스 이동 확인

💡 수정 확인 루틴 Ctrl+S 저장 → F5 새로고침 → 라벨 클릭해서 포커스 이동 확인
드롭다운("상품 선택 *" 라벨)을 클릭했을 때 select 박스에 포커스가 가면 연결이 된 것입니다.
실습 직접 수정해보기 — 미션 5가지

STEP 3 완성본을 참고해서 내 굿즈 샵 정보로 바꿔 완성하세요.
각 미션 후 저장 → 새로고침 → 동작 확인 루프를 반드시 거칩니다.

  • 미션 1 id="order" 섹션 안의 연락처 텍스트를 지우고 <form class="order-form">을 추가하세요. 상품 선택·이름·이메일·요청사항 4개 입력칸이 들어가야 합니다.
  • 미션 2 <select> 안의 <option> 목록을 내 가게의 실제 상품으로 바꾸세요. 상품명과 가격을 함께 적습니다.
  • 미션 3 모든 for/id를 연결하고, 라벨 클릭 시 포커스가 이동하는지 확인하세요. 상품 선택 드롭다운도 포함입니다.
  • 미션 4 제출 버튼 CSS에 var(--brand)를 적용해 브랜드 컬러로 통일하고, :hover 시 색이 진해지도록 추가하세요.
  • 미션 5 각 입력칸의 placeholder를 내 가게에 맞는 힌트 텍스트로 직접 바꾸세요. (예: "원하는 수량과 배송 주소를 적어주세요")
⚠ 흔한 실수 <select>도 id를 붙여야 <label for="...">와 연결됩니다.
<option value="">-- 선택하세요 --</option>을 첫 번째 항목으로 넣지 않으면 required가 동작하지 않을 수 있습니다.
