STEP 21차시 핵심 개념 + 기본 실습

핵심 개념

레이아웃은 flex-direction, gap, flex 속성으로 대부분 제어할 수 있습니다.

.layout { display: flex; gap: 12px; } .layout > section { flex: 1; } @media (max-width: 760px) { .layout { flex-direction: column; } }

실습 순서

  • 현재 코드에서 관련 섹션을 먼저 찾는다.
  • 작은 수정 1개 후 바로 저장/새로고침으로 확인한다.
  • 동작 확인 후 같은 패턴으로 2~3개 확장한다.
한 번에 크게 바꾸기보다 작은 수정을 반복하면 오류를 줄일 수 있습니다.
  • 기본 개념 코드를 직접 적용했다
  • 저장/새로고침 루프로 결과를 확인했다
  • 최소 2개 이상 화면 변화가 생겼다

📝 코드 수정 포인트

섹션을 Flexbox로 정렬하고 반응형으로 전환하는 방법입니다:

수정 전 (고정 레이아웃)
<main>
  <section>소개</section>
  <section>상품</section>
  <section>이벤트</section>
</main>

<style>
section {
  width: 30%;
  float: left;
}
</style>
수정 후 (Flexbox + 반응형)
<main>
  <section>소개</section>
  <section>상품</section>
  <section>이벤트</section>
</main>

<style>
main {
  display: flex;
  gap: 16px;
}

section { flex: 1; }

@media (max-width: 768px) {
  main {
    flex-direction: column;
  }
}
</style>
STEP 2-보충Flexbox + 선택자 집중 실습

이번 보충 실습에서는 레이아웃 선택자와 반응형 Flexbox를 직접 적용해 배치를 완성합니다.

실습 목표

학습 요소오늘 할 일완료 기준
레이아웃 컨테이너.layout에 flex 적용PC에서 3열 배치 확인
자손 선택자.layout > section으로 폭 통일모든 섹션이 같은 비율
미디어쿼리768px 이하에서 1열 전환모바일에서 세로 배치

시작 코드

<main class="layout"> <section class="panel intro"> <h2>가게 소개</h2> <p>우리 가게의 특징을 소개합니다.</p> </section> <section class="panel menu"> <h2>대표 메뉴</h2> <p>시그니처 메뉴를 보여줍니다.</p> </section> <section class="panel contact"> <h2>문의</h2> <p>연락처와 운영시간을 안내합니다.</p> </section> </main> <style> .layout { display: flex; gap: 12px; } .layout > section { flex: 1; } .panel { border: 1px solid #d9e8e2; border-radius: 12px; padding: 14px; } @media (max-width: 768px) { .layout { flex-direction: column; } } </style>

실습 미션

  • 미션 1: .layout의 gap을 조정해서 섹션 간격을 보기 좋게 맞추세요.
  • 미션 2: .layout > section 선택자로 모든 섹션 높이를 비슷하게 보이게 조정하세요.
  • 미션 3: .panel h2 선택자를 사용해 섹션 제목 스타일을 통일하세요.
  • 미션 4: .menu 클래스에만 강조 배경색을 넣어 대표 메뉴를 눈에 띄게 하세요.
  • 미션 5: 768px 이하에서 글자 크기와 패딩이 함께 줄어들도록 미디어쿼리를 보강하세요.

실습 미션 정답 코드

<main class="layout"> <section class="panel intro"> <h2>가게 소개</h2> <p>우리 가게의 특징을 소개합니다.</p> </section> <section class="panel menu"> <h2>대표 메뉴</h2> <p>시그니처 메뉴를 보여줍니다.</p> </section> <section class="panel contact"> <h2>문의</h2> <p>연락처와 운영시간을 안내합니다.</p> </section> </main> <style> .layout { display: flex; gap: 16px; align-items: stretch; } .layout > section { flex: 1; min-height: 150px; } .panel { border: 1px solid #d9e8e2; border-radius: 12px; padding: 16px; background: #ffffff; } .panel h2 { font-size: 1.15rem; color: #1f5a4d; margin-bottom: 6px; } .panel p { color: #4f6c63; line-height: 1.7; } .menu { background: #ebf8f3; border-color: #9fd6c2; } @media (max-width: 768px) { .layout { flex-direction: column; gap: 10px; } .panel { padding: 12px; } .panel h2 { font-size: 1.02rem; } .panel p { font-size: 0.92rem; } } </style>
선택자 팁.layout > section은 layout의 바로 아래 section만 선택하므로, 레이아웃 통일 작업에 매우 유용합니다.
  • PC에서 3열, 모바일에서 1열 전환을 구현했다
  • 자손 선택자(.layout > section)를 적용했다
  • 특정 클래스(.menu)만 강조 스타일을 적용했다
  • 미디어쿼리로 모바일 가독성을 개선했다
