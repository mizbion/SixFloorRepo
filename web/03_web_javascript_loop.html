반복문 — 자동화의 시작

for · while · break · continue — 1부터 100까지 합도, 구구단도, 주사위 100번도
for while break / continue 중첩 반복 주사위 게임
오늘의 학습목표

1
반복이 왜 필요한가?
컴퓨터가 잘하는 일 = 같은 일을 빠르게

"1부터 100까지 더해줘"라고 하면 어떻게 할래?

terrible.js 
// 이렇게? — 100줄을 다 쓸 수는 없잖아
let sum = 0;
sum = sum + 1;
sum = sum + 2;
sum = sum + 3;
// ... 97줄 더 쓰기? 😱
반복문(loop)은 같은 일을 정해진 횟수만큼, 또는 조건이 만족되는 동안 자동으로 반복해주는 도구다. 대표 두 가지: for문과 while문.
오늘부터는 "사람이 할 수 없는 양의 일"을 코드로 처리한다. 반복문 = 자동화의 시작.
2
for문 — 가장 기본 형태
초기값 / 조건 / 증감식, 세 칸의 약속

구조

for_structure.js 
for (초기값; 조건; 증감식) {
    // 반복할 코드
}

// 실제 예시: 1부터 5까지 출력
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
// → 1, 2, 3, 4, 5
세 칸 해석:
① let i = 1 → 시작값. 보통 i를 0이나 1부터
② i <= 5 → 이 조건이 true인 동안 반복. 끝나는 시점
③ i++ → 한 번 돌 때마다 i를 1 증가 (i = i + 1과 같음)

실행 순서를 따라가보자 (i = 1부터 5까지)

trace.js 
① i = 1          ← 시작값 설정 (단 한 번)
② i <= 5 ?       ← 조건 체크 (true)
③ console.log(i)  ← 본문 실행 → 1 출력
④ i++           ← 증감식 → i = 2

② i <= 5 ?       ← true → 2 출력 → i = 3
② i <= 5 ?       ← true → 3 출력 → i = 4
② i <= 5 ?       ← true → 4 출력 → i = 5
② i <= 5 ?       ← true → 5 출력 → i = 6
② i <= 5 ?       ← false → 종료 ✋
외울 패턴: for (let i = 1; i <= N; i++) → "1부터 N까지 N번 반복".
시작값
끝값 (이하)
출력 위 값을 입력하고 눌러보세요
3
for문 다양한 패턴
누적합, 거꾸로, 짝수만

패턴 ① 누적합 — 1부터 100까지의 합

sum.js 
let sum = 0;       // 합을 담을 그릇 (반복 시작 전!)

for (let i = 1; i <= 100; i++) {
    sum += i;       // sum = sum + i (계속 더하기)
}

console.log(sum);  // → 5050
핵심 패턴: 그릇(sum) 만들기 → for문 안에서 계속 더하기 → 끝나면 출력. 평균, 최댓값 찾기에도 같은 구조.

패턴 ② 거꾸로 (카운트다운)

countdown.js 
// 시작: 큰 값, 조건: 작아져도 OK인 한, 증감: 감소
for (let i = 5; i >= 1; i--) {
    console.log(i);
}
// → 5, 4, 3, 2, 1

패턴 ③ 짝수만 (2씩 증가)

even.js 
// 방법 A: 2부터 2씩 증가
for (let i = 2; i <= 10; i += 2) {
    console.log(i);    // → 2, 4, 6, 8, 10
}

// 방법 B: 1씩 증가하면서 짝수만 골라내기 (다음 차시 if문 응용)
for (let i = 1; i <= 10; i++) {
    if (i % 2 === 0) {
        console.log(i);
    }
}
%(나머지) 활용: i % 2 === 0은 짝수, i % 3 === 0은 3의 배수. 자주 쓰는 트릭.
N (1부터 N까지 합)
합계 N을 입력하고 눌러보세요
4
while문 — 조건이 참인 동안 반복
횟수보다 조건이 중요한 경우

구조

while_basic.js 
while (조건) {
    // 반복할 코드
}

// 예시: 1부터 5까지 출력 (for문과 같은 결과)
let i = 1;             // 초기값 (직접 만들어야 함)
while (i <= 5) {
    console.log(i);
    i++;                // 증감식 (직접 써줘야 함!)
}
for vs while: 횟수가 정해져 있으면 for, 조건만 있고 횟수를 모르면 while. 예: "HP가 0이 될 때까지", "정답 맞힐 때까지".

while문이 더 어울리는 예시

half.js 
// 100을 2로 나눠서 1보다 작아질 때까지 — 몇 번 나누면 될까?
let n = 100;
let count = 0;

while (n >= 1) {
    n = n / 2;
    count++;
}

console.log(count);  // → 7번 (100 → 50 → 25 → 12.5 → ...)
무한 루프 주의! 증감식을 빠뜨리면 조건이 영원히 true → 브라우저가 멈춤. // while (i <= 5) { console.log(i); } ← i++ 빠짐, 무한 반복!
비상 탈출: 무한 루프에 빠지면 브라우저 탭을 닫거나, 크롬은 "이 페이지가 응답하지 않습니다 → 페이지 종료"를 클릭. 작업 저장은 평소에 자주!
시작 숫자 (예: 100)
횟수 숫자를 입력하고 눌러보세요
5
break · continue — 흐름 끊기와 건너뛰기
반복 중간에 빠져나오거나, 한 회만 스킵

break — 반복문 자체를 종료

break.js 
// 1부터 10까지 가다가 5를 만나면 멈춰
for (let i = 1; i <= 10; i++) {
    if (i === 5) {
        break;       // for문 통째로 빠져나옴
    }
    console.log(i);
}
// → 1, 2, 3, 4   (5는 출력 안 됨, 그 뒤로 모두 중단)
활용: "찾으면 더 볼 필요 없는" 경우. 사용자 검색, 비밀번호 일치 확인 등.

continue — 이번 한 번만 건너뛰기

continue.js 
// 1부터 5까지 가는데 3만 빼고 출력
for (let i = 1; i <= 5; i++) {
    if (i === 3) {
        continue;    // 이번 회만 건너뛰고 다음으로
    }
    console.log(i);
}
// → 1, 2, 4, 5   (3 빠짐, 나머지는 진행)
break vs continue: break는 전부 끝, continue는 이번 한 번만 스킵. 둘 다 if문과 거의 항상 붙어 다닌다.
6
중첩 반복문 — 구구단 만들기
for 안의 for, 표 형태의 데이터

"2단부터 9단까지 전부 출력해줘"라고 하면? 단(2~9)이 바깥, 곱하는 수(1~9)가 안쪽 — for 안에 for를 넣는다.

코드

gugu.js 
for (let dan = 2; dan <= 9; dan++) {       // 바깥: 단
    console.log(`=== ${dan}단 ===`);
    for (let i = 1; i <= 9; i++) {       // 안쪽: 1~9
        console.log(`${dan} × ${i} = ${dan * i}`);
    }
}
실행 횟수: 바깥이 8번(2~9단), 안쪽이 9번(1~9). 안쪽 본문은 총 8 × 9 = 72번 실행된다.

화면에 그려보기

안쪽 변수 이름: 바깥이 i면 안쪽은 j. 같은 이름으로 두 개 못 만든다. 실수하지 말 것.

Math.random — 무작위 숫자 만들기
주사위 게임의 핵심 도구

주사위 게임을 만들려면 1~6 사이의 무작위 숫자가 필요해. JS는 Math.random()이라는 도구를 준다.

random.js 
// 0 이상 1 미만의 소수 (예: 0.3471, 0.9982, ...)
Math.random();    // → 0.5723...

// 1~6 사이의 정수 (주사위!)
const dice = Math.floor(Math.random() * 6) + 1;
// 분해:
//   Math.random() * 6  → 0~5.999...
//   Math.floor(...)    → 0~5 (소수점 버림)
//   ... + 1            → 1~6
일반 공식: Math.floor(Math.random() * N) + 1 → 1~N 사이의 정수. N에 6 넣으면 주사위, 100 넣으면 1~100 뽑기.

실습: 랜덤 주사위 게임
반복문 + 조건문 + 화면 출력 종합

요구사항

① 사용자가 입력한 횟수만큼 주사위를 굴린다
② 모든 결과를 화면에 표시한다
③ 짝수가 몇 번, 홀수가 몇 번 나왔는지 카운트한다
④ 가장 큰 눈은 몇이 나왔는지 표시한다

전체 코드

dice_game.html 
<div id="result"></div>

<script>
    const times = 10;          // 굴릴 횟수

    // 결과를 담을 그릇들
    let evenCount = 0;       // 짝수 카운트
    let oddCount = 0;        // 홀수 카운트
    let maxValue = 0;        // 최댓값 추적
    let diceList = "";       // 결과 표시용 문자열

    // for문으로 N번 굴리기
    for (let i = 1; i <= times; i++) {
        const dice = Math.floor(Math.random() * 6) + 1;
        diceList += dice + " ";

        // 짝/홀 판정 (Day 02 조건문 응용)
        if (dice % 2 === 0) {
            evenCount++;
        } else {
            oddCount++;
        }

        // 최댓값 갱신
        if (dice > maxValue) {
            maxValue = dice;
        }
    }

    // 화면에 출력 (템플릿 리터럴, Day 01 응용)
    document.getElementById("result").innerHTML = `
        <h2>${times}번 굴린 결과</h2>
        <p>나온 눈: ${diceList}</p>
        <p>짝수: ${evenCount}회 / 홀수: ${oddCount}회</p>
        <p>최고 눈: ${maxValue}</p>
    `;
</script>
학습 흐름 종합: 1일차(변수, 템플릿 리터럴) + 2일차(if문, 비교 연산자) + 3일차(for문, Math.random) — 세 차시가 한 코드에서 만난다.

AI에게 CSS 디자인 부탁하기
결과 화면을 게임 느낌으로

주사위 게임 결과를 좀 더 게임 콘솔 느낌으로 꾸며보자. 어떤 분위기로 갈지는 너의 몫.

예시 프롬프트 — 그대로 복사해서 AI에게 보내봐

아래 HTML 주사위 게임 결과 화면에 CSS를 적용해줘.

[HTML]
<div id="result">
    <h2>10번 굴린 결과</h2>
    <p>나온 눈: 3 1 6 4 2 5 6 1 3 4</p>
    <p>짝수: 5회 / 홀수: 5회</p>
    <p>최고 눈: 6</p>
</div>

[요구사항]
- 분위기: 레트로 게임 콘솔 느낌, 모험적이고 두근거리는
- 메인 컬러: 주황/빨강 계열 + 어두운 배경
- 너비: 최대 400px, 가운데 정렬
- 주사위 결과(숫자들)는 박스로 감싸 강조
- 폰트: 가능하면 픽셀 폰트 또는 두꺼운 sans-serif
- 호버 시 미세한 흔들림 효과(선택)

CSS만 <style> 태그 안에 작성해서 답변해줘.

① 위 프롬프트의 분위기·메인 컬러를 바꿔봐 (네온 사이버펑크 / 카지노 / 보드게임 박스 등)
