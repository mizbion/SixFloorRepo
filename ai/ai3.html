🧩 Part 1 · 알고리즘
🔍 생활 속의 알고리즘

알고리즘은 문제를 해결하는 절차입니다. 절차를 정하는 것, 그리고 절차를 잘 따르는 것은 무척 중요합니다.

알고리즘은 수많은 실패와 성공의 경험을 통해 문제를 해결하는 최적의 과정을 도출한 것입니다. 어떻게 하면 문제를 빠르고 정확하면서도 완성도 높게 해결하느냐를 알려 주는 게 알고리즘의 역할입니다.

💡 우리 일상에도 알고리즘이 가득합니다. 라면 끓이는 순서, 음료 자판기 이용법, 우는 아이를 달래는 방법 — 모두 알고리즘입니다!

주어진 상황에서 문제를 가장 효율적으로 해결하는 것이 최선입니다.
💻 프로그램과 프로그래밍

컴퓨터 언어로 알고리즘을 구현한 것
프로그래밍 언어 language
프로그램을 작성하기 위해 사용하는 특별한 언어
프로그래밍 programming
문제를 설정하고 → 알고리즘을 구성하고 → 프로그램으로 작성해 컴퓨터에 입력하는 전체 과정

🤖 Part 2 · 머신러닝
🤖 전통적인 프로그래밍 vs 머신러닝

💻 전통적인 프로그래밍

  • 데이터 + 알고리즘 → 입력
  • 컴퓨터가 계산 수행
  • 원하는 결과 출력
  • 사람이 규칙을 직접 작성

🧠 머신러닝

  • 데이터 + 원하는 결과 → 입력
  • 컴퓨터가 패턴 학습
  • 최적의 알고리즘 출력
  • 기계가 규칙을 스스로 찾음

프로그래밍이 컴퓨터에 데이터와 알고리즘을 입력해 원하는 결과를 출력하는 것이라면, 머신러닝은 컴퓨터에 데이터와 원하는 결과를 입력해 문제를 해결할 최적의 알고리즘을 찾아내는 것입니다.

📊 기계가 데이터를 학습하는 6단계
1
문제 정의
해결할 문제가 무엇인지 명확하게 정의합니다.
2
데이터 수집
문제를 해결하는 데 필요한 데이터를 수집합니다.
3
데이터 전처리
수집한 데이터를 학습에 사용할 수 있도록 다듬습니다.
4
모델 학습 방법 선택 & 학습
문제 해결에 적합한 모델을 구성하고 주어진 데이터로 학습시킵니다.
5
모델 평가 & 재학습
모델이 잘 학습했는지 평가합니다. 잘 되지 않았다면 데이터를 점검하거나 다른 학습 방법을 시도합니다.
6
머신러닝 모델 제작 & 배포
머신러닝 모델을 제작하고 배포합니다. 실제 데이터를 넣어 분류, 예측 작업 등을 수행합니다.
🗂️ 머신러닝의 종류
🏷️
supervised learning

지도 학습

정답을 아는 상태에서 학습합니다. 꽃이 장미인지 백합인지 나누는 분류, 5년 뒤 몸무게를 예측하는 회귀 작업에 사용합니다.

🔍
unsupervised learning

비지도 학습

목푯값 없이 데이터에서 특성을 뽑아 비슷한 것끼리 분류합니다. 데이터 연관성이나 비정상 데이터를 찾을 때 사용합니다.

🏆
reinforcement learning

강화 학습

어떤 행위에 보상을 주면 결과를 긍정적으로 인식하고 행동을 점점 강화해 나갑니다. 게임 AI 등에 활용됩니다.

🧠 Part 3 · 인공 신경망 & 딥러닝
🧠 인공 신경망

신경망(neural network)이란 인간 뇌의 생물학적 특성인 신경 세포, 즉 뉴런(neuron)의 연결 구조를 말합니다.

인간의 뇌에는 약 천억 개의 뉴런이 있습니다.
하나의 뉴런이 다른 뉴런으로부터 신호를 받으면 또 다른 뉴런에 전달하는 방식으로 문제를 인식하고 처리합니다.
이런 전달 방식을 컴퓨터로 구현한 것이 인공 신경망(artificial neural network)입니다.
퍼셉트론 perceptron
여러 입력을 처리해 하나의 결과로 출력하는 기본 단위
다층 퍼셉트론 MLP
신경망을 3층 이상으로 쌓아 층 구조로 설계한 것
심층 신경망 DNN
여러 층 깊게 쌓여 있다는 의미의 deep neural network
딥러닝 deep learning
은닉층이 2개 이상인 심층 신경망을 학습시키는 것
⚠️ 과적합(overfitting): 은닉층과 뉴런을 너무 많이 두면 계산량이 어마어마해지고, 세세한 요소에 집중해 오히려 쉬운 문제를 풀지 못하는 현상이 발생할 수 있습니다.

⚖️ 가중치와 편향

뉴런에서 다른 뉴런으로 전달되는 신호의 세기는 정보의 중요도에 따라 달라질 수 있습니다.

가중치 weight
중요하지 않은 정보는 낮은 가중치로 전달되거나 소멸됩니다. 가중치가 0이 될 수도 있습니다.
편향 bias
라면의 마지막에 얹는 치즈처럼, 더 좋은 결과가 나오도록 약간 조정해 주는 역할을 합니다.
🔑 가중치와 편향은 사람이 직접 입력하는 값이 아닙니다.
신경망을 학습한다는 것은 결국 가중치와 편향의 값을 찾아가는 과정입니다.
⚡ 활성화 함수

10점이면 가장 맛있는 라면, 1점이면 가장 맛없는 라면이라고 할 때, 8점 이상이면 1, 8점 미만이면 0을 출력하는 활성화 함수를 추가하면 퍼셉트론이 이 함수를 거쳐 결과를 출력합니다.

맛있는 라면 → 1 출력 → 다음 층으로 전달
맛없는 라면 → 0 출력 → 다음 층에 전달되지 않음
💡 활성화 함수는 망을 더 복잡하고 깊게 만들어 더 복잡한 문제를 잘 풀기 위해서 사용합니다.
