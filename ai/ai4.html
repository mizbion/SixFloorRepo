🧠 Part 1 · 만들기 전 알아두기
🔍머신러닝은 세상을 어떻게 '인식'할까?

우리가 눈, 코, 피부 등으로 무언가를 인식하고 판단하는 것처럼 머신러닝도 데이터의 특징을 인식하여 판단을 내릴 수 있습니다.

💡 여기서 '인식한다'는 것은 단지 '사물이 있다', '소리가 난다'와 같은 단순한 인식이 아닙니다. 데이터의 패턴과 특징을 학습해 분류하고 예측하는 것입니다.
🎯문제를 정의한다는 것은?

인공지능을 만드는 과정은 요리할 때 어떤 음식을 만들까 생각하는 것과 비슷합니다. 메뉴를 정하지 못하면 어떤 재료가 필요한지, 어떤 순서로 만들어야 할지도 알 수 없습니다.

우리가 가장 먼저 해야 할 일은 인공지능을 이용해 어떤 문제를 해결하고 싶은지 정의하는 것입니다. 즉, 문제를 정의한다는 것은 목표를 세우는 것과 비슷해요.

📡데이터는 어떻게 수집할까?

이 수업에서 만들 인공지능에 필요한 데이터는 웹캠(또는 이미지 파일)과 마이크(또는 사운드 파일)로 수집합니다.

센서 sensor
데이터를 수집하는 장치. 말소리, 움직임 같은 아날로그 정보를 0과 1의 디지털 정보로 변환합니다.
티처블 머신 Teachable Machine
구글이 만든 시판 모델. 코드 없이도 쉽게 인공지능을 만들 수 있게 해줍니다.

클래스(Class)란 학습에 필요한 정답 레이블을 티처블 머신에서 부르는 이름입니다.

💡 배경 클래스가 필요한 이유

배경 클래스가 없으면 모델은 어떤 이미지든 가위·바위·보 중 하나라고 판단합니다. 아무것도 내지 않은 상태를 인식하려면 배경 사진 약 10장이 필요합니다.

⚠️ 학습 중에는 탭을 닫거나 브라우저를 종료하면 안 됩니다!
🔧 고급 설정 — 더 똑똑한 모델 만들기

[학습 → 고급]에서 아래 값들을 조정해 정확도를 높일 수 있습니다.

에포크 Epoch
데이터셋을 학습에 사용하는 반복 횟수. 책 한 권을 몇 번이나 반복해서 읽느냐와 같습니다.
배치 크기 Batch Size
한 번 학습하는 데 사용하는 데이터의 개수. 묶음의 크기라고 생각하세요.
학습률 Learning Rate
모래사장에서 반지를 찾을 때 보폭을 결정하는 값. 너무 크거나 작으면 학습이 잘 안 됩니다.
📊 정확도·손실 그래프 보기

[학습 → 고급 설정]에서 에포크별 정확도(Accuracy)와 손실(Loss) 그래프를 확인할 수 있습니다. 정확도는 높을수록, 손실은 낮을수록 좋습니다.

🔲 혼동 행렬(Confusion Matrix)이란?

가위를 가위로 올바르게 분류한 수, 가위를 바위로 잘못 분류한 수 등 모델의 성능을 표로 시각화한 도구입니다. [클래스별 정확도 계산] → [혼동 행렬 계산]을 클릭하면 확인할 수 있습니다.

✅Step 5 · 모델 평가

학습 완료 후 화면 오른쪽에 미리 보기 창이 활성화됩니다. 손 모양을 카메라에 보이거나 이미지를 넣어 제대로 분류하는지 확인하세요.

🔁 만족할 만한 결과가 나올 때까지 데이터 수집 → 학습 → 평가를 반복합니다.

📊'학습 모델의 성능이 좋다'의 의미

✅ 좋은 모델의 3가지 조건

  1. 과소 적합이나 과대 적합이 없어야 합니다.
  2. 훈련·테스트 데이터 모두 정확도 → 1, 손실 → 0에 가까워야 합니다.
  3. 훈련·테스트 데이터가 같은 경향성을 띠며 한 방향으로 움직여야 합니다.
📈 그래프 읽는 법

가로축 = 에포크 / 세로축 = 정확도 또는 손실
🔵 파란 선 = 훈련 데이터    🟠 주황 선 = 평가 데이터

⚠️ 이 부분도 놓치지 마세요!

  1. 평가 시 훈련에 사용하지 않은 새 데이터를 반드시 사용하세요.
  2. 성능이 낮을 땐 데이터 재수집 외에 에포크·배치 크기·학습률 조정도 시도하세요.
  3. 잘못된 데이터가 전체 데이터를 왜곡하진 않는지 꼼꼼히 확인하세요.

🦴키포인트란?

포즈 프로젝트에서 AI는 사람의 몸에 있는 키포인트(keypoint)를 감지합니다. 키포인트란 관절, 눈, 코, 귀 등 신체의 주요 위치를 말합니다.

🧠 AI는 이 키포인트들의 위치·각도·거리 관계를 학습해 동작을 분류합니다. 실제 이미지 픽셀이 아닌 키포인트 좌표 데이터로 학습하므로 더 빠르고 가볍습니다.
